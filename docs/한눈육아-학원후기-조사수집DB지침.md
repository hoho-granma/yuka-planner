# 학원 후기 조사·수집·DB 저장 최종 지침

> 적용 순서: 학원별 **기본정보 수집을 먼저 끝낸 뒤**, 이 지침으로 후기 중심 DB 수집을 다시 진행한다.
> 수집·저장 권한은 `학원후기-API-선행검증-20261009.md`(네이버 검색 API 약관: 저장·AI 입력 제한)와 함께 확인한다. 이 지침의 §9가 약관과 충돌하면 약관이 우선한다.

## 1. 조사 목적

특정 학원의 실제 학부모 후기를 폭넓게 수집하여 학원의 특징과 장단점을 객관적으로 비교할 수 있는 데이터를 구축한다.

단순히 학원명과 '후기'를 검색하는 데 그치지 않고, 레벨 테스트, 수업 방식, 숙제량, 강사, 실력 향상, 비용, 퇴원 이유 등 평가 항목별로 검색을 수행한다.

**핵심 원칙**
- 다양한 검색어를 사용해 최대한 폭넓게 자료를 확보한다.
- 검색 결과를 통합한 후 중복 URL과 중복 게시물을 제거한다.
- 원문 게시물과 그 안에서 추출한 세부 평가 의견을 분리 저장한다.
- 검색 건수, 실제 수집 건수, 중복 제거 건수, 분석 완료 건수를 구분한다.
- 확인하지 않은 내용이나 수치를 임의로 만들어 내지 않는다.

## 2. 기본 조사 기준

### 2-1. 조사 기간
- 기본 조사 범위: 조사 기준일로부터 최근 1년.
- 게시물의 실제 작성일을 확인하여 기간 충족 여부를 판정한다.
- 작성일 확인이 불가능한 게시물은 별도로 분류하며, 최근 1년의 실적에 무조건 포함하지 않는다.
- 조사 기준일, 조사 시작일, 조사 종료일을 기록한다.

### 2-2. 조사 대상
- 학원명, 브랜드명, 지점명, 지역명 및 한글·영문 표기 변형을 활용한다.
- 네이버 블로그와 네이버 카페를 주요 조사 대상으로 한다.
- 필요하면 네이버 통합검색 및 외부 검색엔진을 보조적으로 활용한다.
- 검색 결과에 실제 접근할 수 있는 범위에서 원문을 확인한다.
- 검색 결과의 제목과 요약만으로 상세 후기를 분석했다고 판단하지 않는다.

### 2-3. 지점 일치 여부
각 게시물에 다음 중 하나를 부여한다.
- 지점 일치 확인
- 동일 브랜드이나 지점 불명
- 다른 지점
- 학원 식별 불가

다른 지점의 후기는 조사 참고자료로 보관할 수 있지만, 대상 지점의 평가 통계에는 포함하지 않는다.

### 검색 확장 규칙
1. 브랜드의 영문명·한글명·정식 명칭을 바꿔 검색한다.
2. 지점명 검색 결과가 부족하면 지역명과 브랜드명 조합으로 확장한다.
3. 지역명만 일치하거나 다른 지점일 가능성이 있는 게시물은 지점 일치 여부를 별도 검증한다.
4. 새로운 검색어에서 신규 고유 게시물이 발견되면 검색어를 추가한다.
5. 신규 게시물 확보량이 낮은 조합은 후속 조사에서 우선순위를 낮춘다.
6. 검색어별 조사 범위와 중단 사유를 기록한다.

## 4. 검색 결과 수집 절차

다음 순서를 준수한다.

### 1단계. 검색 이력 생성
검색어별로 조사 이력을 생성한다.

기록 항목:
- 조사 ID
- 학원 ID
- 검색 키워드
- 평가 항목
- 검색 일시
- 조사 기준일 및 기간
- 검색 플랫폼
- 확인한 검색 결과 범위
- 화면에 표시된 결과 수(확인 가능한 경우)
- 실제 수집한 결과 수
- 수집 실패 및 제한 사유

검색 화면에 표시된 결과 수와 실제 수집된 게시물 수를 혼동하지 않는다.

### 2단계. 검색 결과 수집
각 검색 결과에서 확인 가능한 다음 정보를 수집한다.
- 게시물 제목
- 원문 URL
- 작성일
- 출처 유형(블로그, 카페 등)
- 작성자 표시명(필요한 경우)
- 검색에 사용한 키워드
- 검색 결과에서 확인한 요약
- 원문 접근 가능 여부

접근할 수 없는 원문은 상세 내용을 추측하거나 생성하지 않는다.

### 3단계. 모든 검색 결과 통합
검색어별 결과를 개별적으로 평가하거나 집계하는 것으로 끝내지 않는다.

모든 검색 결과를 하나의 통합 목록으로 합친다. 동일 게시물이 여러 검색어에서 발견되면 하나의 게시물로 통합하되, 해당 게시물이 발견된 검색어는 모두 보존한다.

### 4단계. 중복 제거
다음 순서로 중복을 판별한다.
1. URL 정규화 후 동일 URL 제거
2. 추적용 쿼리 매개변수 등 불필요한 URL 차이 확인
3. URL이 달라도 제목·본문·작성일 등이 일치하는 복제 게시물 검토
4. 원문을 그대로 복사한 재게시물과 실질적으로 다른 후기 구분

원본 URL은 보존한다. URL이 같다는 이유만으로 별개의 게시물 내용까지 합치거나, URL이 다르다는 이유만으로 무조건 별도 후기로 집계하지 않는다.

### 5단계. 게시물 검증 및 분석
중복 제거된 게시물별로 다음을 확인한다.
- 조사 대상 학원 및 지점 일치 여부
- 작성일과 조사 기간 충족 여부
- 실제 학부모 경험담인지 여부
- 광고·협찬·체험단·공식 홍보 여부
- 후기 원문 확인 여부
- 평가 항목별로 추출 가능한 내용
- 동일 작성자의 반복 게시 또는 복제 가능성

게시물 전체가 광고라는 이유만으로 무조건 삭제하지 않는다. 출처와 광고 여부를 표시하고 일반 후기와 분리하여 분석할 수 있도록 한다.

## 5. DB 설계

검색 이력, 후기 원문, 세부 평가 내용을 분리한다.

### A. 검색 이력 테이블: `review_search_logs`

필수 필드:
- `search_id`
- `academy_id`
- `keyword`
- `evaluation_category`
- `platform`
- `searched_at`
- `period_start`
- `period_end`
- `result_count_displayed`
- `result_count_collected`
- `search_depth`
- `status`
- `failure_reason`

결과 수를 확인할 수 없는 경우 0으로 기록하지 말고 NULL 또는 미확인 상태로 처리한다.

### B. 후기 원문 테이블: `academy_reviews`

필수 필드:
- `review_id`
- `academy_id`
- `original_url`
- `normalized_url`
- `title`
- `published_at`
- `platform`
- `author_id_hash`(필요한 경우, 개인 식별정보는 저장하지 않음)
- `branch_match_status`
- `period_eligible`
- `source_type`
- `ad_disclosure_status`
- `content_access_status`
- `content_text`(수집 및 저장이 허용되는 범위에서만)
- `content_summary`
- `collected_at`
- `analysis_status`

`normalized_url` 및 중복 검증 결과를 활용하여 중복 저장을 방지한다.

`review_id` 하나는 하나의 고유 게시물을 나타낸다. 여러 검색어에서 발견되더라도 후기 원문 레코드는 하나만 생성한다.

### C. 후기 검색 연결 테이블: `review_search_matches`

필수 필드:
- `review_id`
- `search_id`
- `matched_at`
- `match_type`

하나의 후기가 여러 검색어에서 발견될 수 있으므로 후기와 검색 이력은 다대다 관계로 관리한다. 이를 통해 키워드별 신규 발견량과 중복 발견량을 계산할 수 있어야 한다.

### D. 세부 평가 테이블: `review_findings`

필수 필드:
- `finding_id`
- `review_id`
- `evaluation_category`
- `sub_category`
- `evidence_text`
- `finding_summary`
- `sentiment`
- `specificity`
- `confidence`
- `extraction_status`

평가 항목은 최소 다음을 포함한다.
- 전반 만족도
- 레벨 테스트
- 반 배정
- 학습 방식
- 커리큘럼 및 교재
- 숙제량
- 학습 관리 및 피드백
- 강사
- 실력 향상
- 학부모 상담
- 비용
- 장점
- 단점
- 퇴원 및 변경 이유
- 기타

`sentiment`는 긍정·부정·중립·혼합·판단 불가로 구분한다.

하나의 게시물에 숙제와 강사 관련 내용이 모두 있다면 `academy_reviews`에는 한 번만 저장하고 `review_findings`에는 각각 별도 레코드로 저장한다.

실제 원문에 근거가 없는 의견은 추출하지 않는다. 개인의 경험과 객관적으로 확인된 사실을 구분한다.

## 6. 조사 건수 및 통계 산출 규칙

다음 수치를 반드시 분리하여 집계한다.

### 검색어별 통계
- 검색어별 확인 가능한 노출 결과 수
- 실제 수집한 결과 수
- 중복 제거 전 수집 결과 수
- 중복 게시물 수
- 신규 고유 URL 수
- 실제 원문 확인 수
- 최근 1년 조건 충족 수
- 대상 지점 일치 확인 수
- 상세 분석 완료 수

### 평가 항목별 통계
- 해당 항목을 언급한 고유 게시물 수
- 긍정 의견이 확인된 게시물 수
- 부정 의견이 확인된 게시물 수
- 혼합 의견이 확인된 게시물 수
- 구체적인 근거가 확보된 게시물 수

동일 게시물에서 동일 평가 항목이 여러 번 언급되더라도, 게시물 수 통계에서는 1건으로 집계한다. 다만 별도의 문장·의견 건수를 집계할 때는 그 기준을 명시한다.

### 최종 학원별 통계
- 전체 검색 결과 수
- 중복 제거 후 고유 게시물 수
- 최근 1년 내 유효 후기 수
- 대상 지점 확인 후기 수
- 실제 원문 확인 후기 수
- 상세 분석 완료 후기 수
- 평가 항목별 언급 수 및 의견 분포

모든 수치에는 집계 기준과 분모를 명시한다. 검색 결과의 표시 건수를 실제 후기 전체 규모나 학부모 여론의 대표성으로 해석하지 않는다.

## 7. 조사 품질 및 신뢰도 기준

1. 원문에 없는 내용을 추측하여 추가하지 않는다.
2. 제목이나 검색 요약만 확인한 게시물은 원문 분석 완료 건수에 포함하지 않는다.
3. 다른 지점의 경험담을 대상 지점의 경험담으로 처리하지 않는다.
4. 광고·협찬 게시물을 일반 학부모의 자발적 후기와 혼합하지 않는다.
5. 한 건의 후기만으로 학원의 일반적인 특성을 단정하지 않는다.
6. 동일 게시물에서 추출한 여러 의견을 여러 개의 독립 후기처럼 집계하지 않는다.
7. 긍정적인 후기와 부정적인 후기를 모두 수집하며 부정적 키워드만 과도하게 확대하지 않는다.
8. 자료가 부족하면 부족하다고 명시하고, 실제로 조사하지 않은 키워드의 건수를 임의로 채우지 않는다.
9. 검색 결과 접근 제한, 삭제, 로그인 요구 등으로 원문을 확인하지 못한 사유를 기록한다.
10. 검색 결과가 적다는 이유만으로 해당 평가 항목에 문제가 없다고 판단하지 않는다.

## 8. 실행 및 결과 보고

조사 완료 후 다음 결과물을 제공한다.

### 결과물 1. 조사 요약
- 대상 학원 및 지점
- 조사 기준일과 기간
- 사용한 검색 플랫폼
- 총 검색어 수
- 총 검색 결과 수(확인 가능한 범위)
- 중복 제거 전후 게시물 수
- 최근 1년 내 유효 후기 수
- 원문 확인 및 분석 완료 수
- 조사 한계와 미확인 항목

### 결과물 2. 검색어별 조사 현황
각 키워드별 검색 결과 수, 실제 수집 수, 신규 고유 게시물 수, 중복 수, 분석 완료 수를 표로 제공한다.

### 결과물 3. 학원별 후기 DB
고유 게시물과 평가 항목별 분석 내용을 분리하여 저장하고, 각 평가 의견을 원문 근거와 연결한다.

### 결과물 4. 학원 비교용 요약
- 주요 장점
- 주요 단점
- 레벨 테스트 및 반 배정 특징
- 수업 방식과 커리큘럼
- 숙제량과 학습 관리
- 실력 향상 관련 경험담
- 강사 및 학부모 소통
- 비용 관련 정보
- 퇴원 및 변경 이유
- 항목별 근거 후기 수
- 신뢰도와 조사 한계

결론에는 근거가 충분한 내용과 일부 후기에서만 확인된 내용을 구분한다.

## 9. 실행 시 유의사항

- 네이버 검색 결과를 실제로 열람·수집할 수 있는 도구와 권한을 먼저 확인한다.
- 공식 API 또는 허용된 수집 방식을 우선 사용하고, 서비스 약관과 개인정보 보호 요건을 준수한다.
- 접근 제한을 우회하거나 로그인이 필요한 콘텐츠를 무단 수집하지 않는다.
- 후기 원문 전체의 영구 저장·재배포가 허용되는지 확인한다. 허용되지 않는 경우 URL, 메타데이터, 짧은 근거 인용 및 요약 중심으로 저장한다.
- 자동 수집이 불가능한 항목은 수동 조사로 전환하거나 미확인으로 기록한다.
- 조사 진행 상황과 실패 사유를 남겨 다른 학원에도 동일한 방법을 적용할 수 있도록 한다.

**최종 목표:** 특정 키워드의 검색 결과 몇 개를 보고 학원을 평가하는 것이 아니라, 최근 1년간 여러 검색 경로에서 발견한 고유 후기들을 통합하고 검증한 뒤, 각 후기의 근거를 유지하면서 평가 항목별로 비교할 수 있는 재사용 가능한 학원 후기 DB를 구축한다.
