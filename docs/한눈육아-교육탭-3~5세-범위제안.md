- 근거: 사용자 결정 D2(2026-10-05, "36개월 이상은 교육탭이 보이게 해줘. 그때면 어린이집, 유치원, 학원을 다닐때라"), UX지침 §1·§9, 방향설계서 §6·§14, ux-review/05 §2·§3, D9(표본 30/100, 10명 미만 셀 가림, 초기엔 공개·공식 데이터만)

## 1. 3~5세 부모가 이 탭에 들어오는 이유(지침 §1 질문)
| 질문 | 3~5세 답 |
|---|---|
| 왜 들어오나 | "유치원은 언제 어떻게 정하지?", "어린이집 계속 다녀도 되나?", "학원·체험은 언제부터?", "우리 동네엔 어디가 있지?" |
| 먼저 알고 싶은 것 | **내 아이 나이에 지금 정할 것과 그 시기**(유치원 모집·유아학비·반 전환) |
| 한눈이 대신할 것 | 아이 출생연도로 입학 연도·모집 시기 계산, 우리 지역 기관 찾기 링크, 지원 대상 여부 정리 |
| 부모가 직접 할 것 | 기관 비교·상담·방문(앱은 일정으로 연결만) |
| 다음 행동 | 처음학교로 접수일·상담·방문 일정 넣기, 유아학비 신청 |
| 다시 들어오면 | 나이가 바뀌면 블록 순서가 바뀜(만 3세: 기관 선택 → 만 5세: 초등 준비 예고) |

## 2. 화면 블록(같은 탭, 연령별 구성)
초등과 같은 탭(교육)·같은 머리(지역·나이)를 쓰고, **블록 목록만 연령으로 바꾼다**. 3~5세에는 '또래 범위'·'지역·학년 트렌드(학원·과목·영어·수학)' 칸을 숨긴다(D9: 데이터 없음 → 숫자·빈 틀 모두 안 보임).

| # | 블록(한국어 이름) | 보여 주는 것 | 다음 행동 | 필요한 데이터 | 데이터 상태 |
|---|---|---|---|---|---|
| B1 | **올해 정할 것** | 아이 나이 기준 이번 해 결정 1~2개: 유치원 입학(처음학교로 접수 시기 — **확인형 "유치원 보낼 계획이면", 공식 연간 날짜 확보 전 미노출**) / 어린이집 유아반 전환 / 계속 다니기. "왜 지금" 한 줄 | 처음학교로 접수 일정 넣기(AUTO 후보) · 공식 페이지 | ① 출생연도 → 입학 연도 계산(있음: 생년월일) ② 처음학교로 연간 일정(접수·추첨·등록 시기) ③ 어린이집 반 전환 시점(CR 항목: 만3세반 전환 준비) | ① 있음 ② **조사 필요**(교육부·시도교육청 매년 공지, 시기 근거 추가확인 필요 — 05 §3) ③ 있음(data/todos/childcare.json, 정확한 월 근거는 확인 필요) |
| B2 | **받을 수 있는 교육·보육 지원** | 유아학비(누리과정) 대상 여부, 지역 유아 교육 지원 | 신청하기(공식 페이지) · 혜택 탭 | NAT-020 유아학비 / SB-08 / 지역 지원금(서울·부산·경기) | 있음(NAT-020·SB-08, 조건형 CHECK). 지역 유아 교육 지원은 **부분**(3개 시·도만) |
| B3 | **우리 동네 기관 찾기** | 유치원·어린이집을 찾는 공식 경로 2개(링크) + 우리 지역 이름. 줄마다 '상담·방문 일정 넣기' 버튼 | 공식 사이트 열기 / 상담·방문 일정 넣기(줄마다) | 유치원알리미·어린이집 정보공개포털 링크, 사용자 지역(시·군·구) | 링크·지역은 있음(링크 확인 필요). 기관 목록 자체는 **넣지 않음**(공개 데이터 수집·갱신 부담, 1차 범위 밖) |
| B4 | **학원·체험** | 1차: '학원·체험 일정 넣기'(기존 학원 일정 프리셋 재사용) + 담당 지정. '고를 때 볼 점' 문장은 공식 근거 확보 후 | 학원·체험 일정 넣기(담당 지정) · 어디갈까(체험) | 학원 일정 프리셋·담당 지정(있음) / '고를 때 볼 점' 문장 | 1차 범위는 있음. 문장은 **근거 확보 후**(근거 없는 조언 금지) |
| B5 | **우리 아이 현재 상태**(기존 블록 유지) | 등록한 학원·기관 일정 목록 | 학원 일정 추가 | 사용자 일정(있음) | 있음(기존 renderTrend mine) |

- 만 5세(학령 전 1년)는 B1 뒤에 '초등 준비 예고' 한 줄을 붙여 다음 단계(TO_SCHOOL, next-stage.json)로 잇는다.
- 블록 순서: B1 → B2 → B3 → B4 → B5. B1이 비면(정할 것이 없는 시기) 숨기고 B3가 맨 위.
- 초등은 지금 틀(현재 상태·또래 범위·트렌드·다음에 확인할 것) 그대로. 한 렌더러에서 `stage`에 따라 블록 목록만 고른다.

## 3. 만들지 않는 것
- 또래 비교·평균·비율·"많이 다니는 학원 N개" 같은 숫자(D9. 사용자 데이터 집계 전에는 표시하지 않음).
- 기관 순위·추천, 사설 정보 출처 인용.
- 공식 근거가 없는 "몇 살부터 영어 시작" 같은 권고.
