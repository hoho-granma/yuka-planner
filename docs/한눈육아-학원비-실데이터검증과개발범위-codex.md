# 학원비 데이터: 실데이터 검증과 개발 가능 범위

검증일: 2026-10-09. 사용자 요청에 따른 **구현 전 조사·설계 보고**다. 앱 코드·기존 데이터·배포 설정은 변경하지 않았다. 전국 데이터 적재, 학교/학원 적합성 평가, 운영 API 연동 완료를 뜻하지 않는다.

## Aside 브라우저 재검증 결과 — 아래 초기 보고보다 우선

사용자의 도구 지정 이후 웹 열람·다운로드는 Aside 브라우저로 진행했다. 새 조사 창에서 공공데이터포털, 연결된 NEIS Sheet, 서울교육청 게시판과 게시물 본문을 직접 확인했다. 서울교육청 URL의 초기 비브라우저 HTTP 400은 파일 부재가 아니었다. Aside에서는 정상 접속·공식 다운로드가 가능했다.

확인한 [2026년 서울 학원 교습비 게시물](https://buseo.sen.go.kr/buseo/bu14/user/bbs/BD_selectBbs.do?q_bbsSn=1328&q_bbsDocNo=20260130171732114)은 **2026-01-01 기준, 2026-01-30 게시**다. 2026년 자료임과 오늘 기준 최신 비용임은 다르다. 이번에는 첨부 5개 중 강남구1 파일 하나를 다운로드·검증했다. 서울 전체 11개 파일 또는 전국 상세 파일을 확보했다고 주장하지 않는다.

| 실제 XLS 검증 항목 | 결과 |
|---|---:|
| 시트 | 강남구1 |
| 열 수 / 헤더 위치 | 20열 / 5행 |
| 교습비 항목 행 수 | 42,493 |
| 원문 학원명+상세주소의 서로 다른 조합 | 1,278 |
| 교습기간 `1개월 0일` | 30,075행 |
| 교습기간 `0개월 1일` | 7,201행 |
| 교습기간 `0개월 0일` / 공백 | 967행 / 6행 |
| 교습비 공백 / 실제 숫자 0 | 0행 / 71행 |
| 총교습시간 공백 / 실제 숫자 0 | 0행 / 1,206행 |

42,493은 학원 수가 아닌 반·교습비 항목 수다. 1,278도 공식 등록 식별자에 기반한 확정 기관 수가 아니라 원문 이름+주소 조합 수다. 강남구1은 강남구의 일부 파일이므로 강남구 전체 수치로 표시하지 않는다.

**실제 헤더:** 학원명, 학원주소, 설립자-성명, 전화번호, 교습계열, 교습과정, 교습과목(반), 정원, 교습기간, 총교습시간(분), 교습비, 모의고사비, 재료비, 급식비, 기숙사비, 차량비, 피복비, 기타경비합계, 총교습비, 강사수. 학원주소 헤더 끝에 탭 문자가 있어 헤더 정규화가 필요하다. 파일 형식은 XLS이며 초기 포털의 XLSX 표기와 다르다.

**갱신한 개발 판정:** 서울교육청 파일 어댑터를 실제 헤더로 설계할 수 있다. 같은 명시 과목·과정·대상·교습기간끼리 비용 비교를 개발할 수 있고, 양수인 총교습시간이 같은 비용 기간에 대응하는지 확인한 항목만 시간당 파생값을 계산한다. `0개월 1일`을 1회로, `0개월 28일`을 1개월로 자동 변환하지 않는다. 기간 0/공백은 기간 비교에서 제외하고 시간 0은 시간당 계산에서 제외한다. 교습비 0은 원천의 실제 등록 숫자 0이라고 표시하되 무료 운영 확정으로 확대하지 않는다.

파일에는 공식 등록번호·지점 전용 필드·좌표·독립된 정확한 학년 필드가 없다. NEIS와 주소+등록명으로 연결할 때 상세 주소와 기관 종류를 대조하고, 복수 후보는 수동 검토한다. 설립자 이름은 비교 기능에 불필요하므로 공개 가공 데이터와 검증 샘플에서 제외했다. 품질 결과·원문 기간 분포·출처·파일 해시 및 설립자 이름 제외 5행 예시는 `output/학원비데이터검증-codex/seoul-gangnam1-quality.json`에 저장했다. 다운로드 원본은 사용자 Downloads의 공식 XLS를 읽기만 했고 수정하지 않았다.

NEIS Sheet에서도 공식 XLS/CSV/JSON/XML/TXT 및 전체 다운로드 항목과 조회 최대 1만건·전체 다운로드 최대 30만건 안내를 확인했다. 이는 API 무키 5건 제한과 별개다. **운영키가 없으면 공식 데이터 전체 확보가 무조건 불가능하다는 판단은 하지 않는다.** 이번 Sheet 지역 조회·파일 다운로드는 완료하지 못했으므로 파일의 범위·실제 다운로드 성공은 다음 검증 항목이다.

나이스 학원민원서비스 개별 화면 대조, 다른 시도 비용 파일, 서울 나머지 파일, 운영 수집·적재·자동 갱신·실제 비교 화면은 여전히 미완료다. 이하 본문은 이 재검증 이전의 조사 이력과 설계이며, 서울 파일 미확보라는 초기 상태는 위 결과로 갱신한다.

## 1. 판정

**지역·등록 교습과정 기반 탐색과 공개 교습비 원문 표시부터 개발할 수 있다. 전국 월 교습비 순위·정확한 학년 필터·거리순 정렬은 현재 확인한 자료만으로 제공할 수 없다.**

국가 단위 등록 정보는 NEIS API, 비교 가능한 상세 비용은 실제 열람·검증한 교육청 공개 파일을 결합하는 구조가 적절하다. 공개된 금액이라는 사실과 동일 조건으로 비교할 수 있다는 사실을 구분한다. 첫 운영 지역을 정한 뒤, 해당 지역 전체 페이지와 상세 파일을 검증해야 한다.

## 3. 실제 샘플과 품질

공식 안내에 따라 KEY를 생략하고 `Type=json`, `pIndex=1`, `pSize=5`로 요청했다. API 제한을 우회하는 페이지 반복 수집은 하지 않았다.

| 지역 | 요청 교육청 코드 | 받은 행 | 교습비 원문 있음 | 빈 교습비 | API 응답 전체 건수 |
|---|---|---:|---:|---:|---:|
| 서울 구로구 | B10 | 5 | 4 | 1 | 790 |
| 경기 성남시 | J10 | 5 | 4 | 1 | 3,309 |

전체 건수는 응답 당시 해당 조건의 API 기록 수다. 운영 중인 학원 수·비교 가능한 비용 건수·재원생 수를 뜻하지 않는다. 10건은 제한 샘플이며 지역 전체 품질이나 전국 결측률을 대표하지 않는다.

| 실제 사례 | 관찰 | 처리 원칙 |
|---|---|---|
| `J10:3000062478` | 교습비 `초등A:190000, 초등B:240000, ...` | 금액은 원문에 있으나 기간·수학 과목을 비용 항목 자체로 확정하지 못함. 190,000원/월로 변환 금지 |
| `B10:13839` | `보컬(일60분*주2회*4.2주):100000, ...` | 수업 시간 표현이 있지만 '4.2주'를 월로 임의 치환하지 않음. 기간 의미를 검증한 별도 규칙이 있을 때만 계산 |
| `B10:3000041940`, `J10:3000069224` | 공개 여부 Y인데 교습비 문자열은 공백 | 정보 없음. 0원 또는 무료로 해석하지 않음 |
| `J10:3000028710` | `중,고급반:250000` 포함 | 쉼표로 단순 분리하면 반 이름이 깨짐. 원문 보존 및 파싱 실패 구분 |
| 여러 행 | `LOAD_DTM=20231018` 등 과거 연계일자 | 이번 수집일과 원천 연계일을 따로 표시. 최신 비용 확인으로 승격하지 않음 |
| 일부 전화번호 | `02-000-0000`, `00-000-0000`, `02-0000-0000` | 원문 보존, 실제 통화 가능한 연락처로 활성화하지 않음 |
| 일부 휴원 종료일 | `99991231` 및 공백 | 실제 복원일로 해석하지 않음 |

샘플 원본과 SHA-256·요청 조건은 `output/학원비데이터검증-codex/`에 별도로 저장했다. 해당 파일은 개발 검증 자료이며 앱의 운영 학원 목록으로 적재하지 않았다.

| 지역·등록과정·기관명 탐색 | 개발 가능 | 운영 인증키로 선택 지역 전체 페이지 검증 |
| 등록 상태·위치·교습비 원문·출처 표시 | 개발 가능 | 항목별 확인 시점, 빈 값, 과거 연계일 표시 |
| 공식 식별자 기반 중복 방지 | 개발 가능 | 동일 키의 충돌 행을 격리. 이름만 일치하면 자동 병합 금지 |
| 같은 단위·과목·과정의 비용 비교 | 조건부 | 비용 항목별 기간·과목·과정이 실제 자료에서 확정된 경우만 비교 그룹에 포함 |
| 전국 월 교습비 낮은 순 | 현재 불가 | 여러 교육청 상세 자료의 단위 검증·전국 범위 확보 필요 |
| 정확한 학년별 필터 | 현재 미확보 | 명시 학년이 확인된 항목만 포함. 미확인을 해당 학년으로 추정 금지 |
| 시간당 비용 | 조건부 | 비교 금액에 대응하는 동일 기간의 총 교습시간 검증 필요. 계산값 표시 |
| 거리순 | 현재 미확보 | 지오코딩 근거와 기준 위치 필요. 미좌표 항목은 별도 처리 |
| 최신 확인순 | 개발 가능 | 수집 확인일 순임을 명시. 최근 교습비 변경순이라는 의미가 아님 |
| 수정 제보 | 개발 가능 | 사용자의 제보와 공식 원천을 분리, 검토 후 반영 |

공개 등록 정보만으로 우리 아이의 적합성을 자동 확정하지 않는다. 상세의 빈칸은 상담 질문으로 연결하고 상담·체험 일정을 기존 가족 캘린더에서 준비한다.

## 6. 내부 스키마 제안

- `source_registry`: 출처 URL, 제공기관, 파일/API, 주기 안내, 이용조건, 조건 확인일, 어댑터 버전. 전국 API·교육청 파일·민원조회는 서로 다른 어댑터다.
- `ingestion_runs`: 수집 실행 ID, 요청 지역, 시작/완료일, 성공/실패, 페이지/행 수 검증, 오류 코드. 키 포함 요청 URL은 저장·로그 금지.
- `raw_snapshots`: 실행 ID, 원문 파일/응답, 해시, 수집시각. 정규화 데이터와 분리하고 변경 이력을 유지한다.
- `academies`: 내부 ID, 공식 식별자 목록, 등록명, 확인된 지점명, 주소 계층과 추출 근거, 좌표와 근거, 등록 상태, 전화, 최초 수집일, 마지막 확인일.
- `fee_items`: 학원 ID, 원문 항목 ID/행 위치, 명시 과목·과정·대상, 교습비(nullable), 기간/단위(nullable), 총 시간과 기간(nullable), 횟수(nullable), 추가 비용(nullable), 포함 여부(확인/미확인), 기준일(nullable), 연계일, 확인일, 출처, 원문, 파싱 근거/버전.
- `dedup_reviews`: 주소+이름 후보, 지점/과정 근거,자동 병합 금지 여부, 수동 결정과 이력.
- `correction_reports`: 제보 대상과 내용, 증빙, 처리 상태. 공식 데이터 자동 덮어쓰기 금지.

교습비 상태는 사용자 지침의 `확인됨 / 누락 / 갱신 필요 / 비교 불가`만 사용하되 **원문 유무·단위 확인·최신성·비교 가능 여부를 독립 필드로도 저장**한다. 오래되면서 단위도 미확인일 수 있기 때문이다. 화면의 대표 상태와 원인을 함께 표시한다. 갱신 필요의 기간 기준은 출처 주기와 운영 정책을 정해 명시하고, 임의로 모든 자료에 같은 유효기간을 붙이지 않는다.

## 7. 비교·중복·갱신 규칙

1. 비교 키는 명시 과목 + 교습과정 + 비용 단위 + 적용 기간이다. 대상·반 조건이 다르면 함께 표시하고, 확인된 서로 다른 학년/대상은 분리한다. 미확인 단위끼리는 서로 비교 가능한 그룹으로 묶지 않는다.
2. 숫자 0은 실제 원문 0일 때만 저장하고 표기한다. null·빈 문자열·비공개는 금액 미확인이다. 별도 비용의 공백도 0으로 바꾸지 않는다.
3. 시간당 금액은 동일 기간의 교습비 / 확인된 총 교습분 × 60. 공식 금액과 별도 계산값으로 표시한다. 정원·주간 수업시간만으로 월 시간 추정 금지.
4. 공식 식별자가 다르면 동일 이름이라도 별도 학원. 공식 ID 없는 타출처 자료는 주소+등록명으로 후보를 찾되 상세 주소·지점·종류·과정 충돌 시 격리한다. 유사도만으로 자동 병합하지 않는다.
5. 수집은 임시 버전에 적재해 전체 페이지·지역·필수 식별자·충돌 검증 후 현재 버전을 교체한다. 실패·부분 응답·스키마 변경이면 기존 성공 버전 유지. 실패 시 확인일을 성공일로 갱신하지 않는다.
6. 한 번 조회에서 사라졌다고 즉시 삭제/폐원 처리하지 않는다. 공식 상태 변경과 재확인을 구분한다. 새 파일의 기준일이 기존보다 과거면 최신 버전 덮어쓰기를 막는다.
7. 포털 수시와 NEIS 매주 안내는 다른 메타데이터다. 운영 초기 API 갱신은 주간 주기를 후보로 두되 운영키·제한 검증 후 확정한다. 서울 파일은 포털 연간 안내를 기준으로 신규 게시물을 확인하며, 파일을 주간 최신자료로 표시하지 않는다.

## 8. 현재 코드와 차이·구현 순서

현재 `functions/education-directory/directory.js`는 성남시로 고정된 조회, 공개 교습비 원문, 메모리 캐시를 제공한다. 같은 공식 ID를 Map에 넣어 마지막 행으로 덮어쓰므로 충돌 검증이 필요하다. 내구성 있는 원천 스냅샷, 최초 수집일, 비용 항목별 비교 단위, 수집 실패 시 반환할 기존 영속 버전은 아직 이 구조에 없다. 앱에는 기관 탐색·후보 비교와 상담/체험 일정 연결을 재사용할 수 있는 코드가 있다. 기존 작업 중인 파일을 전면 교체하지 않는다.

우선순위:

1. 운영키를 서버에서 실제 호출해 시작 지역 전체 페이지·공식 식별자·건수 검증. 키 값이 아니라 설정 위치/환경변수로 연결한다.
2. 서울교육청 실제 첨부파일 확보 후 헤더·단위·추가 비용·원천 기준일·학원 식별자/주소 매칭 검증. 타 시도도 출처별로 동일 절차 적용.
3. 원천/정규화/이력 스키마와 출처별 어댑터 구현. 원문 중심으로 먼저 적재하고 비교 미확인 항목은 격리.
4. 새 수집 버전 검증·교체, 중복 검토, 지역·과정 필터 구현.
5. 확인된 비용 항목의 비교 화면, 출처·확인일·미확인 항목·정정 제보 구현.
6. 기존 상담·체험 → 가족 일정 흐름 연결, 정기 갱신·실패 회복 검증.

완료 검증은 다른 지점 미병합, 동일 ID 충돌, null/0, 월/회 분리, 과거 원천+최근 수집일, 원문 파싱 실패, 추가 비용 미확인, 페이지 누락, 잘못된 인증·조회 없음, 갱신 실패 후 이전 데이터 유지, 원천 삭제/과거 파일 재등장 사례로 한다.

## 9. 남은 확인

운영 인증키 실제 사용, 선택 지역 전체 수집, 나이스 민원 개별 화면 대조·자동 접근 이용조건, 서울교육청 실제 파일, 다른 시도의 상세 파일, 전체 데이터의 공식 ID 유일성·결측률, 지오코딩 공급자와 근거, 실제 학년 자료는 미검증이다. 이번 조사 결과를 완료 조건 달성이나 운영 출시 가능으로 승격하지 않는다.
