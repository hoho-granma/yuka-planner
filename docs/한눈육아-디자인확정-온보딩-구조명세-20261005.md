## uid 규칙 (정적 분석, g43-screens.html 마크업 기준)
- uid = `화면번호-순번`. 화면번호 0=소개, 1=가입, 2=아이 정보.
- 순번 = 섀도 루트의 `querySelectorAll("*")` 문서 순서(0부터). 루트 맨 앞에 `<style>` 2개(기본 CSS, `#ovr`)가 있어 순번 0·1을 차지하고, `.scr`(화면 전체 배경)가 2번, 그 아래 자손이 깊이 우선 순서로 3번부터 이어짐.
- 아래 표의 요소 대응은 마크업 문자열을 파싱해 구했고 렌더는 못 봄 → 확실도: 높음(순서 규칙이 g42 코드와 같음), 단 사용자가 본 화면과 1:1 일치 여부는 추정.
- 주의: 이 순번은 시안 A 마크업 구조가 바뀌면 어긋남. 이후 수정에서는 시안 A 온보딩 마크업의 요소 순서를 바꾸지 않음.

3. 아이 정보: 짧은 히어로(제목 '아이 정보를 알려 주세요') + 하단 시트(이름 입력 '은찬', 전환 탭 생년월일|출산 예정일, 날짜 '2026. 06. 20', 시·도 '서울특별시', 시·군·구 '구로구', [일정 만들기])

## 해석 메모
- 0-4/0-5, 1-4, 2-4/2-5는 장식 원 1·2: 인디고 #4a45c8 / 와인 #8a1c3d. 1-5(가입 장식 원 2)는 바꾸지 않음.
- 히어로 배경 3곳이 모두 #ffffff → 흰 면 위에 원 2개만 색이 남는 구성. 하단 시트는 #f0f1ff(소프트 인디고).
- 주요 버튼: 소개 [시작하기] 배경 #d8d6ff·글자 #161618·테두리 #f4f3f1, 가입 [다음]·아이 정보 [일정 만들기]는 배경 #4a45c8·글자 #ffffff. 소개 버튼만 소프트인 점은 의도인지 미확인.
- 선택 칩/역할 카드/선택 탭은 노랑 #fff0bd + 테두리 #f9cb34(탭만 #ff6a1a, 글자 #000000).
- 추정: 2-18 글자 #000000은 순수 검정이라 앱 차콜 #24252a 와 다름(그대로 유지).
