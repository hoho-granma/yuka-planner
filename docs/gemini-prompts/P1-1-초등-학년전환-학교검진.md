# P1-1. 초등 학년 전환·학교 건강검진 시기 (1-6 근거)

용도: 다음 단계 카드 '초등 → 다음 학년'의 근거. 근거가 확인된 항목만 앱에 노출합니다.

## 프롬프트
(00-공통규칙.md를 먼저 붙인 뒤 아래를 붙이세요)

한국 초등학교의 학년 전환과 학교 건강검진 시기를 공식 출처로 확인해 주세요. 지역은 서울특별시와 경기도 기준입니다. 학년도는 2026학년도와 2027학년도입니다.

| id | 확인할 것 |
|---|---|
| E-01 | 학년도 시작일(새 학년 시작)의 법령 근거 — 초·중등교육법 시행령 등 학년도 규정 원문 |
| E-02 | 2027학년도 서울 초등 학사일정 중 개학(3월) 관련 교육청 공식 안내가 이미 있는지 |
| E-03 | 학생 건강검사(신체발달상황) 실시 시기 — 학교보건법·학생건강검사 규칙 원문(학년별 대상 포함) |
| E-04 | 건강검진(검진기관 실시) 대상 학년 — 초1·초4 등 대상 학년 원문 |
| E-05 | 학생 구강검진 대상 학년과 시기 원문 |
| E-06 | 초6 → 중1 진학(중학교 배정) 절차의 서울시교육청 공식 안내 페이지 |

학교마다 다른 날짜(개별 학교 학사일정)는 조사하지 않습니다. 법령·교육청 공통 기준만 찾아 주세요.
