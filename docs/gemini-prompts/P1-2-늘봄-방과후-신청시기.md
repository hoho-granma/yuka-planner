# P1-2. 늘봄학교·방과후학교 신청 시기 (1-6 근거)

용도: 6~7세 → 초등 준비 카드, 초등 다음 학년 카드의 돌봄 항목. 근거 확인 전 비노출.

## 프롬프트
(00-공통규칙.md를 먼저 붙인 뒤 아래를 붙이세요)

초등학교 늘봄학교와 방과후학교의 신청 대상·시기·신청처를 공식 출처로 확인해 주세요. 지역은 서울·경기, 기준 학년도는 2026·2027학년도입니다.

| id | 확인할 것 |
|---|---|
| N-01 | 늘봄학교 대상 학년(초1·초2 등)과 2026학년도 운영 기준 — 교육부 공식 발표 원문 |
| N-02 | 늘봄학교(초1 맞춤형 프로그램 등) 신청 시기 — 서울시교육청 공식 안내 |
| N-03 | 늘봄학교 신청 시기 — 경기도교육청 공식 안내 |
| N-04 | 방과후학교 신청 방식(학교별 공지 여부)과 교육청 공통 안내가 있는지 |

"학교마다 다름"이 원문이면 그 문장을 그대로 인용해 주세요. 공통 날짜가 없으면 '공통 날짜 없음'으로 적습니다.
