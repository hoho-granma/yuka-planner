- 작성: hn_design, 2026-10-05 / 사용: hn_test(DOM·computed style 우선, 캡처 최대 3곳)
- 기준: docs/한눈육아-디자인명세-생일계산일정.md, js/child-anniversaries.js, js/app.js 1815~1845행(칸 칩), 4450~4485행(시트·패널), user-schedule-view.js `cellChips`(409행)
- 계정: 은찬 · 2026-06-20생 → **100일 = 2026-09-27**, **돌 = 2027-06-20**, 생일 = 2028-06-20부터. 칩 달력은 가구가 있는 계정에서만 나온다(가구 없으면 점 표식 — 이 경우 2-5 칩은 없음).

## 1. 달력 칸 칩
| # | 확인 | 셀렉터 | 기대값 |
|---|---|---|---|
| 1 | 100일 칩 | 2026-09-27 칸 `.cal-chip.a` | 글자 "은찬 100일"(제목 형식은 child-anniversaries `title`) |
| 2 | 돌 칩 | 2027-06-20 칸 `.cal-chip.a` | "은찬 돌" |
| 3 | 칩 모양 | 위 요소 | 자동 칩 모양(옅은 면 + `--chip-c` 테두리), **새 색 없음** |
| 4 | 칩 색 | `--chip-c` | **명세 차이 확인**: 명세는 '그 아이의 구성원 색'. 코드는 다른 자동 칩과 같은 `autoColor`(가족색 #c9b8ff 또는 `usAutoChipColor()`) → 다르면 차이로 보고(낮음) |
| 5 | **'+1'로 밀리는 경우** | 칸 안 `.cal-chip-more` | 칸당 칩 2개까지. 정렬은 직접 일정(u) 먼저 → 자동(a). 기념일은 자동 목록 **맨 뒤**에 붙음 → 같은 날 직접 일정 1개 + 자동 1개가 있으면 기념일 칩은 안 보이고 **"+1"**. 기대값: `+N`의 N에 기념일이 포함되고, 그날을 누르면 패널에 기념일 줄이 있음 |
| 6 | 같은 날 직접 생일 일정 | 그 칸 | 같은 아이·같은 종류(생일/돌/100일 카테고리)의 직접 일정이 있으면 **기념일 칩 없음**(`hiddenByDirect`). 제목 문자열로는 판단하지 않음 |
| 7 | 임신 중 아이 | 칸 | 기념일 칩 없음 |
| 8 | 2월 29일생(테스트 아이 필요) | 평년 2월 28일 칸 | 칩 있음 + 패널 줄에 "2월 29일생 · 평년은 2월 28일로 표시" |
