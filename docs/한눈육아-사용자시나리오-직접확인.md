# 한눈육아 사용자 시나리오 — 직접 확인 안내 (hn_pm 2026-10-05)

> 기준: 배포본 **v1.12.109(커밋 03e073a)**. 코드 근거는 [agents/dev-note-scenario-facts.md](agents/dev-note-scenario-facts.md)(hn_dev 코드 읽기, 화면은 미확인). **'확인 필요'** 표시는 코드만으로 단정하지 못한 부분이라, 직접 보시고 알려 주시면 됩니다.
> 곧 바뀌는 것: 4-1 A안(D31) — 이전 홈은 그대로 두고 **맨 위에 '꼭 할 것' 2줄**, 아이 2명 이상이면 **아이 칩**이 붙습니다. 이 수정이 배포된 뒤 확인하시면 아래 '홈' 칸에 이 두 가지가 더해집니다.

## 0. 시작 전 (공통)
| 순서 | 할 일 | 메모 |
|---|---|---|
| 1 | 앱을 열고 **로그인 상태**인지 확인(프로필 시트에 '내 프로필'이 보이면 로그인) | 5세 이상 전용 메뉴·교육 탭·아이 칩은 **로그인(계정 모드)에서만** 나옵니다 |
| 2 | 헤더의 버전이 **1.12.109 이상**인지 확인 | 옛 버전이면 새로고침, 홈 화면 앱은 껐다 켜기 |
| 3 | '새 홈 미리보기'는 **끈 상태**로 시작 | 켠 화면은 각 시나리오의 마지막 체크에서만 봅니다 |
| 4 | 시나리오 순서: ① → ② → ③. ②③은 아이를 **추가**해서 봅니다 | 한 계정에 아이를 계속 더하면 아이 칩이 늘어납니다. ③을 '초등 1명 부모'처럼 보려면 ②에서 더한 두 아이를 삭제한 뒤 추가하세요(내가 만든 아이는 삭제할 수 있음) |

## 2. 시나리오별 눌러 볼 것 (기대 결과)
### ① 36개월 미만 (은찬)
| # | 누를 것 | 기대 결과 |
|---|---|---|
| 1 | 홈을 끝까지 스크롤 | 챙길 것 → 가족 일정 순. 접종(예: DTaP 1차 등)이 날짜와 함께 보임 |
| 2 | 캘린더 → 이번 달 날짜 하나 | 날짜 시트에 그날 일정, 자동 일정은 '자동' 표시 |
| 3 | + → 새 일정 → **붙여넣기**로 "다음주 화요일 소아과 3시" | 날짜·시간 후보가 채워지고 **확인 필요** 표시, 저장 전 직접 확인 |
| 4 | 혜택 탭 | 서울·구로구 지원 목록. 마감 있는 것 먼저 |
| 5 | 체크리스트 → '생후 3개월' 그룹 | 지금 월령 할 일, 미래 그룹에 '유치원 입학 신청'이 있어도 정상(30개월부터 홈에 나옴) |
| 6 | 어디갈까 | 장소 목록, 도서관은 '시설 유형 기준' 문구 |
| 7 | 프로필 시트 → '새 홈 미리보기' 켜기 → '이전 홈으로 보기' | 켜면 시트가 닫히고 새 홈, 아래 링크로 원래 홈 복귀 |

### ② 5~6세 아이 2명
| # | 누를 것 | 기대 결과 |
|---|---|---|
| 1 | 아이 추가(첫째) → 홈 | 탭이 홈·캘린더·할 일·어디갈까·교육으로 바뀌고 혜택 탭이 사라짐 |
| 2 | 둘째 추가 → 홈 위 **아이 칩**으로 전환 | 머리 나이가 7세 ↔ 6세로 바뀜, 메뉴는 같음 |
| 3 | 둘째 선택 → 교육 탭 | 3~5세 화면, 처음학교로 '공지 전' 안내 줄(날짜 없음), 기관 링크 3줄 |
| 4 | 첫째 선택 → 교육 탭 | 6~7세 기존 화면(3~5세 블록 없음) |
| 5 | 홈 '놓치기 쉬운 것' 3칸 | 날짜 있는 신청·접종이 먼저, 안내형은 뒤 |
| 6 | 할 일 → 메모 하나 추가 | 홈 할 일 메모 카드에 보임(가족과 공유) |
| 7 | 프로필 시트 → '아이 전환' | 두 아이 목록, 지금 아이에 노랑 '보는 중' 배지 |
| 8 | 새 홈 미리보기 켜기 | 큐레이션 홈, 아이 전환해도 유지 |

### ③ 초등생 1명 (초2)
| # | 누를 것 | 기대 결과 |
|---|---|---|
| 1 | 아이 추가 → 홈 머리 | "이름 · 9세(초2) · 서울특별시 …" |
| 2 | 홈 '놓치기 쉬운 것' | 학교 항목(건강검사·구강검진 등) 중심, 유치원 항목 없음 — 어떤 항목이 3칸에 오는지는 **확인 필요** |
| 3 | 교육 탭 | 초등 기존 화면(3~5세 블록·처음학교로 없음) |
| 4 | 캘린더 3월·4월 | 새 학기 관련 항목(학교 안내 확인 문구, 학교별 날짜 없음) — **확인 필요** |
| 5 | 어디갈까 | 박물관 '만 3세 이상 권장 · 시설 유형 기준' 같은 문구 |
| 6 | 다음 단계 배너 | 없음이 정상(초등 학년 전환 카드는 보류) |

## 3. 알려진 한계·미해결 (지금 보면 '이상'처럼 보일 수 있는 것)

| 혜택 탭 | 36개월 이상 아이를 보면 숨음(G22 결정). 혜택은 홈 위쪽 3칸이 대신함 |
