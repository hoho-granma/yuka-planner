## 1. 목표와 비목표

**목표** 가족 캘린더(B4)에서 "매주 화·목 16:00 피아노" 같은 **주간 반복 일정**을 추가·표시하고, **이 날만**(취소·날짜/시간 이동·완료·되돌리기)과 **전체**(수정·삭제)를 다룬다.

**비목표(B5에서 하지 않음)**
- 월간·연간 반복(규칙이 `freq == WEEKLY`만 허용 → 규칙 재배포가 필요해짐), 공휴일 자동 휴강, 담당자(B6), 알림(B7), 충돌·공백 감지(B8)

- "이 일정 이후 모두 수정"(문서 분할) — §3 결정 D1 참고

## 4. 데이터 형식 (설계서 §6 그대로, 신규 필드 없음)

```jsonc
{ "dateKind":"FIXED", "eventDate":null, "allDay":false, "startTime":"16:00","endTime":"16:50",
  "recurrence":{"freq":"WEEKLY","interval":1,"byDay":["TU","TH"],"startDate":"2026-10-06","until":null},
  "exceptions":{
    "2026-10-08":{"status":"CANCELLED"},
    "2026-10-13":{"status":"RESCHEDULED","movedTo":{"date":"2026-10-14","startTime":"17:00","endTime":"17:50"}},
    "2026-10-15":{"status":"DONE"} } }
```

### 전개 규칙(expandOccurrences, 순수·로컬 날짜 산술만, UTC 금지)
1. 후보일 = `startDate` 이후(until 이하) 중 요일이 `byDay`에 속하고, `startDate`가 속한 **월요일 시작 주**부터 `interval`주 간격인 날.
2. 회차 key = `u:<id>@<originalDate>`(originalDate = 규칙상 날짜). 완료·취소·이동 예외는 originalDate 키.
3. `RESCHEDULED`: 표시 `date = movedTo.date`(시각 있으면 덮어씀). **원래 날짜가 범위 밖이어도 이동 후 날짜가 범위 안이면 포함**, 반대도 처리(예외를 직접 순회).
4. `CANCELLED` 회차는 `status:"CANCELLED"`로 포함(D4), 칸 표식·집계에서 CalendarModel이 제외하고 `days[date].cancelled[]`로 노출.
5. 규칙에 맞지 않는 날짜의 예외는 무시. 범위 상한 400일 유지. `deletedAt` 문서는 `[]`.
6. 반복 문서의 문서 `status`는 쓰지 않는다(규칙 금지) → 완료는 `exceptions[date].status = DONE`.

## 5. 화면 (B4 UX 유지, 한 캘린더)

- **추가 폼**: "반복" 선택(안 함 / 매주 / 격주) → 요일 칩 7개(복수) → 끝나는 날(계속 / 날짜 선택). 날짜는 기존 공유 선택기 사용. 반복을 켜면 "여러 날에 걸쳐요"·"날짜 미정(기간)"은 비활성(PERIOD·endDate와 병용 금지, I3·I4).
- **회차 상세**: 반복 일정에는 "반복 일정" 라벨. 버튼: 완료/되돌리기, **이 날만**(취소·날짜/시간 바꾸기), **전체**(수정·삭제).
- **범위 선택 시트**: 수정·삭제를 누르면 "이 날만 / 전체" 선택(승인 문구).
- 달력 칸: 기존 막대(색=아이 링크 `order`)를 회차마다 그대로 사용. 3개 초과는 기존 "+N".
- 가구 없음 / 플래그 OFF: B4와 동일하게 아무것도 안 바뀜.

## 8. 위험과 대응

- **R1 회차 정체성**: 규칙(요일·간격·시작일) 변경 시 기존 예외가 다른 날을 가리킬 수 있음 → D6 정리 + 전개에서 불일치 예외 무시.
- **R2 오프라인 병합**: 두 기기가 같은 날 예외를 동시에 쓰면 마지막 쓰기가 이김(설계 §11 확정). 서로 다른 날은 dot-path라 충돌 없음. 단 `household-sync`의 "pending-local-wins(스케줄은 로컬 문서 전체)" 병합이 dot-path 큐와 맞는지 **1단계 테스트로 확인**하고, 맞지 않으면 구현하지 않고 보고(범위 확대 금지).
- **R3 예외 200개 상한**: 주 2회×2년 전부 개별 예외를 달 일은 드묾. 180개 이상이면 안내, 200개는 규칙이 거부(경고 문구 승인 필요).
- **R4 표식 과밀**: 반복 일정이 많으면 칸이 "+N"으로 넘침 → 기존 3개 한도 유지, 일 패널에서 모두 확인.
- **R5 AUTO 불변**: 메타모픽 T4에 반복 문서를 추가해 `autoEvents`·`displayDate` 불변을 자동 검증.
