상담 확인 일정에는 기관명, 위치, 공식 URL, 자료 확인일, 대상·시간·총액·체험 조건 질문을 넣는다. 제목을 카테고리 변경으로 덮어쓰지 않도록 처리했다. 기존 시트의 ‘체험’ 범주/ETC 일정으로 시작하며 학원 등록(LESSON)으로 자동 분류하지 않는다. 저장 전 아이·담당·공유 범위와 카테고리도 확인해야 한다.

3~5세의 기존 전용 안내, 기존 등록 일정 안내, 성장기록 진입은 유지했다. 실제 교육정보 메뉴 노출 연령 조건을 변경하지 않았다. 현재 참고용 학년 선택은 조회 상태이며 아이 프로필에 저장하지 않는다.

## 6. 화면 선택 반영 (2026-10-08)

사용자 선택에 따라 교육정보 상단을 또래·지역/교육 선택 2개 탭으로 변경했다. 또래·지역의 큰 설명 카드를 제거하고 지역·학년 선택 줄을 남겼다. 분모는 각 수치에 유지하며 시도 기준이라는 짧은 안내와 접힌 출처·집계 기준을 제공한다. 학년은 여전히 부모의 명시적 선택이며 생일로 확정하지 않는다.

교육 선택은 A 목록형: 짧은 지역 선택, 검색, 분야·구 필터, 기관명·분야·구·도로명 목록이다. 비교 담기와 긴 상단 소개를 제거했다. 기관을 누르면 상세로 이동하고 뒤로 돌아올 때 필터를 유지한다. 실제 주소·대상·기간 미확인 비용·등록자료·확인일·공식 링크·상담 질문·일정 준비는 상세에 유지한다. 이용자 의견 설명과 공공 프로그램 확인 범위는 접어서 제공한다.

로컬 앱 소스에 적용했으며 운영 배포는 하지 않았다. 최신 관련 Node 테스트는 28개 통과. 최종 시안: `design-previews/education-approved/index.html`. 이전 3탭·비교 3곳 설명은 이번 선택으로 변경된 과거 구현 기록이다.
