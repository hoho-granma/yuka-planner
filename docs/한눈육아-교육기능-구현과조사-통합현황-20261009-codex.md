## 2. 교과 이해확인과 인쇄 질문지

목표는 학교에서 **이미 배운 중심 내용을 아이가 설명하고 적용하는지** 관찰하는 것이다. 아직 배우지 않은 내용, 읽어 준 경우, 힌트·연습 후 답변을 독립 수행과 구분한다. 한 번의 답이나 기초 재확인만으로 학년 수준을 정하지 않는다.

2022 개정은 교육과정의 명칭이고 2026은 교재·적용 학년도다. 초3·4는 2025년부터 2022 개정을 적용한다. 인쇄 질문지의 국어·수학·사회·과학은 EBS 만점왕 **2026년판 3-2** 공개 목차를 기준으로 구성했다. 앱의 목차·문항은 미래엔 기반의 별도 후보이며 두 구성을 같은 검사로 표시하지 않는다.

| 인쇄 과목 | 기준 목차·중심 내용 | 활동 수 |
|---|---|---:|
| 국어 | 경험과 관련지으며 이해해요 / 유창하게 읽고 발표해요 / 정확하게 글을 써요 / 서로 존중하며 대화해요 / 사전으로 여는 세상 / 감상과 표현의 즐거움 | 18 |

### 개발 가능 범위와 적용 기준

현재 디렉터리는 공개 교습비 **문자열 표시**까지다. 새 시스템은 NEIS 등록 정보를 중심으로, 실제 검증한 교육청 파일을 별도 어댑터로 결합할 수 있다. 이번 서울 파일을 기존 성남 운영 목록에 대체 적재하지 않았다.

- 내부 기관 ID와 교육청+공식 번호를 보존한다. 번호가 없는 파일은 상세 주소+등록명+기관 종류로 후보를 만들고 불확실하면 수동 검토한다. 같은 브랜드 지점은 별도 관리한다.
- 비용 항목별로 원문·금액·과정·과목·확인 가능한 대상·기간·추가 비용·기준일·출처·마지막 확인일·상태를 저장한다. 제공되지 않은 학년·수업 회수·좌표를 만들지 않는다.
- 동일 과목·과정·명시 대상·비용 단위끼리 비교한다. 양수 총시간이 같은 비용 기간에 대응함을 확인한 경우에만 파생 시간당 금액을 계산한다.
- 누락은 ‘정보 없음’, 단위 불명은 ‘비교 불가’, 오래된 원천은 기준일을 표시한다. 조회일을 비용 기준일로 승격하지 않는다.
- 원천과 가공 데이터를 분리하고 성공한 수집본 검증 후 교체한다. 갱신 실패 시 기존 데이터를 삭제하지 않고 갱신 실패 상태를 표시한다. 서버 비밀 저장소를 이용하며 API 키를 저장소·브라우저로 내보내지 않는다.

## 4. 후기·검색 조사

분당구 공식 학원 조사 명부는 1,503행이며 `data/education/bundang-review-research.json`에 연구 상태와 출처를 기록한다. 이는 확인된 후기 1,503개나 현재 NEIS 전체 기관 수를 뜻하지 않는다. 다른 지점·주소 불일치·미확인 후보를 확정 근거로 집계하지 않는다. 앱에는 알려진 기관과 매칭한 제한된 수동 의견을 표시하고, 원문·시기·상반되는 경험을 보존한다. 광범위한 대표성·추천 순위로 확장하지 않는다.

NAVER API HUB 호출은 블로그·공개 카페 각각 HTTP 200, 3개 검색결과의 실제 필드를 검증했다. 블로그에는 postdate, 카페에는 게시일 필드가 없었다. 원문 내용·해당 지점 후기 여부·광고 여부는 검증하지 않았으므로 ‘확인된 후기 3개’로 표시하지 않는다. 인증값·검색 응답 본문은 검증 출력·파일에 남기지 않는다.

확인한 검색 약관에 따라 검색 데이터를 AI에 넣는 분석·영구 후기 DB 구축은 진행하지 않는다. 검색 표시 연동은 미구현이다. 독립 후기 분석은 별도의 저장·분석 권한을 확보한 자료가 있어야 한다. 기존 수동 의견의 이용 권한도 이번 API 검증만으로 확보됐다고 간주하지 않는다.

이번 저장소 반영 전 교육 관련 Node 테스트 **38개 통과**: 전체 페이지·누락/실패 처리, 식별·기관 종류·비공개 교습비, 관심 저장·비교·지역 필터, 후기 지점 매칭, 프로그램 대상·부분 범위, 문항 버전·독립 수행·원문 보존을 확인했다. 실행 대상은 `test/education-directory.test.js`, `test/education-reference.test.js`, `test/learning-check.test.js`, `test/education-public-programs.test.js`, `test/education-interests.test.js`다. 테스트 통과는 로그인 실기기 검증이나 교사 검토 완료를 대체하지 않는다.
