## 0. 원칙
1. **한 렌더러**: 36개월 전후·계정 모드 구분 없이 `슬롯 입력 → 마크업` 하나로 그린다(지금 home.js 57~195행과 over36-view.js 43~58행, 두 벌).
2. **슬롯 개수는 하드코딩 금지**: 정책 파일 값을 읽는다(`data/policy/curation.json` 신설 예정, hn_data 초안 키 actionType·slots.now/soon/know·thresholds.* 를 따르고 최종 키는 hn_dev 구현 때 확정). 지금 값은 지금 꼭 3 / 곧 2 / 알아두기 1 / 나중 0이고, 1-0 검증 뒤 바뀔 수 있다. 시급성 값(마감 30일·곧 45일·짧은 창 60일)도 같은 파일에 둔다.
3. **판단 결과만 보여 준다**: 개수 요약("이번 달 한눈에 N개")은 넣지 않는다(D16). 숫자는 "N개 더"에만 쓴다. 홈에 혜택 섹션을 따로 두지 않는다(마감 있는 지원은 ①·②로, 상시 혜택은 한 줄로 **이동** — 기능 삭제 아님).
4. 홈 확정 디자인(v1.12.97, `--nd-*` 변수)을 그대로 쓴다. 새 색은 §3-4의 '곧' 배너 2색(#ece8f8·#5536c4)과 §2-2의 '마감 임박' 글자색뿐이다.

## 3. 타임라인 날짜 표현
1. **점**: 영역마다 하나(항목마다 점 X). 맨 위 영역만 채운 점, 나머지는 속 빈 점. 빈 영역은 점까지 숨긴다.
2. **선**: 첫 점부터 마지막 마디까지 이어지는 한 줄. 다음 단계 배너·탐색 줄 옆에는 점이 없다(선은 다음 단계 배너 위에서 끝).
3. **날짜 글자 규칙**(왜 지금 문구 안의 `.hs-date`, 06 §3-3 계층과 연결):

| 계층 | 표현 | 색 | 예 |
|---|---|---|---|
| L1 놓치면 끝 / L2 마감 임박(≤ 정책값 30일) | "D-N · M월 D일까지" 굵게 | **#8a1c3d**(와인, 확정 팔레트 장식 원 2 색, 흰 바탕 대비 약 9:1) | D-13 · 10월 18일까지 |
| L3 늦었지만 가능 | "기한이 지났지만 지금 가능" | #62656b 800 | — |
| L4 지금 기간 안 | "M월 D일까지" | #62656b 800 | 12월 10일까지 |
| L5·L6(곧) | 곧 줄 오른쪽 "M월 D일부터" / "M월 D일 마감" | #24252a | 10월 20일부터 |

   - 색만으로 구분하지 않는다(L1·L2는 'D-N' 글자가 같이 붙는다).
   - 와인 날짜색 + 'D-N'은 **D17로 결정됨**(2026-10-05).
4. **왜 지금 한 줄 + 바로 버튼**: 줄 = [제목(+꼬리표) / 왜 지금 한 줄(분류 · 날짜 · 이유)] 왼쪽 2단 + [행동 버튼] 오른쪽 1개. 이유 문장은 걸린 규칙을 그대로 쓴다(06 §3·§8-2 문장).
