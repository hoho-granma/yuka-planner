# 아이 중심 성장기록과 교육정보 메뉴 시안

2026-10-08 사용자 제안을 반영한 검토 시안입니다. 운영 앱은 변경하지 않고 독립 시안을 추가했습니다.

## 메뉴 경계

| 메뉴 | 탭 | 먼저 보여줄 내용 | 역할 |
|---|---|---|---|
| 성장기록 | 현재 상태 | 아이의 확인된 상태, 미확인 영역, 현재 활동, 근거 | 우리 아이 자체를 이해하기 |
| 성장기록 | 성장 이력 | 기존 활동 나무와 날짜별 원문, 비교 가능한 변화 | 이전의 우리 아이와 비교하기 |
| 교육정보 | 또래·지역 | 아이 참여 현황 → 비교 가능한 공식 또래 통계 → 지역 교육환경 | 외부 환경과 선택 경향 이해하기 |
| 교육정보 | 교육 선택 | 아이와 연결된 기관·활동 → 비교 기준 → 지역 선택지 | 부모의 교육 선택 부담 줄이기 |

기존 이름 ‘성장기록 / 교육정보’를 유지합니다. 성장기록의 ‘현재 상태 / 성장 이력’이 메뉴 의도를 설명합니다. 교육정보의 기존 ‘우리 아이’ 탭은 성장기록 현재 상태에 통합합니다. 이전 3축 중 우리 아이 축은 데이터 관점에서 유지하되 별도 교육정보 탭으로 중복 노출하지 않습니다.

## 연결과 데이터

상태 확인·수행 답변·결과·근거 원문은 성장기록의 아이 범위에서 관리합니다. 교육정보 상단 요약은 이를 참조하며 별도 복제·별도 진단 결과를 만들지 않습니다. 점검의 주요 시작 버튼은 성장기록에만 둡니다. 교육정보에는 ‘현재 상태와 근거 보기’ 연결을 둡니다.

상담·체험을 선택한 경우 가족 일정 → 실제 경험 → 성장기록으로 연결합니다. 교과 점검에는 일정 등록을 필수로 붙이지 않습니다. 기관 비교에서는 관련 경험·피드백을 조회할 수 있습니다.

## 비교의 조건

등록 일정 개수는 실제 교육 참여 기관 수가 아닙니다. KOSIS 참여율과 직접 나란히 수치 비교하지 않습니다. 실제 참여·주당 시간·비용을 같은 정의와 기간으로 확보할 때 비교합니다. 통계의 학년·지역 단위·전체 학생/참여 학생 분모·조사 기간을 표시합니다.

개인 교과 점검에서 확인한 범위는 보여줄 수 있으나 전국·지역 수준 평균과 비교할 데이터는 없습니다. 수준 비교·등급·백분위를 만들지 않습니다. 기관 분포와 실제 이용 선택을 구분합니다. ‘또래가 많이 가는 학원’은 검증된 선택 집계와 표본이 있어야 제공하며 현재는 데이터 없음으로 표시합니다.

수아 시안의 3개는 등록 교육·활동 일정 수입니다. READ101 판교점은 부모 확인 기관이며 ‘영도’와 자동 연결하지 않습니다. 서버 보관 기록 4건은 성장이나 수행 횟수를 뜻하지 않습니다. 실제 수행 답변은 없어 과목별 미점검으로 표시합니다.

## 구현 전 확인

- 현재 상태 요약과 교육정보 요약의 동일 아이·가족·권한 범위
- 기록 정정·삭제 후 요약과 근거 무효화
- 일정과 실제 경험의 분리 및 기관·지점·활동 ID 매핑
- 기존 나무·활동 기록·3~5세 화면의 보존
- 공공 API 실제 응답·지역 단위 검증
- 과목 문항의 교사 검토와 일부 범위라는 결과 표현

3~5세는 경험·놀이·관찰 중심, 6~7세는 준비·경험 중심으로 현재 상태 내용을 바꾸며 초등 점검을 그대로 적용하지 않습니다.

## 기존 성장기록 화면 통합과 교육 선택 개편

기존 `GrowthRecords.treeMarkup`과 실제 성장기록 CSS를 시안에서 직접 재사용합니다. 성장기록 상단에 현재 상태/성장 이력 탭을 두고, 성장 이력은 기존 나무 → 학교/학원/그 외/가정 활동 선택 → 날짜별 기록 → 성장 남기기를 보존합니다. 실제 기록 원문·사진은 이 독립 시안에서 조회하지 않습니다. 현재 상태에는 과목별 확인 결과와 관련 기록 링크를 둡니다. 기록 원문과 상태 요약은 같은 근거를 참조해야 합니다.

교육 선택은 학원을 선택할 때 드는 검색·비교 부담을 줄이는 화면입니다. 유지/보완 설명을 메인으로 두지 않고 다음 순서로 정리합니다.

1. 아이·학년·지역과 현재 연결 기관을 간단히 표시
2. 수학/영어/과학/줄넘기/국어·독서/예체능 분야 선택
3. 이름 검색, 거리·비용·수업 방식·차량 조건
4. 기관·지점 카드: 대상·수업 방식·비용·시간·위치 등 출처별 확인 정보
5. 카드 안에 부모 의견 요약: 진도/숙제/피드백/수업 분위기/차량의 반복 언급과 상반된 의견
6. 후보 담기 → 동일 항목으로 나란히 비교
7. 자세히 보기 → 원문 출처 확인 → 상담·체험 선택 → 가족 일정

시안은 분야 전환, 이름/수업 방식 검색, 후보 담기와 해제, 비교, 상세 보기, 성장 나무 활동 전환을 조작할 수 있습니다. 상세 필터는 조건 설명용이며 실제 필터 데이터 연동은 없습니다. 시안의 5개 기관과 의견은 모두 가상 예시입니다.

실제 의견은 공식정보와 별도로 저장·표시하며 출처, 시점, 기관·지점 일치, 서로 다른 작성자/원문 수, 중복·광고성, 상반된 의견, 요약 버전과 근거 링크를 관리합니다. 로그인 제한 글과 공개 글의 수집 허용 범위를 별도로 검토하며, 출처 확인 전에는 실제 후기라고 표시하지 않습니다. 의견이 없으면 공식정보만 제공하고 검색/상담에서 확인할 항목을 제시합니다. 후기 수는 이용자 수·인기도·교육효과가 아닙니다.

초기 목록 정렬은 검증된 거리 또는 이름 등 설명 가능한 기준으로 설계합니다. 후기 수나 기관 과금으로 아이 적합도·추천 순위를 만들지 않습니다. 교육 유지 여부와 실제 아이 반응은 성장기록에서 확인합니다.

### 이번 검증

Chrome에서 기존 나무 출력, 분야 전환, 수학 후보 2곳 담기와 비교, 줄넘기 카드 전환을 확인했습니다. 운영 앱·DB·수집 API·커밋·push는 변경하지 않았습니다. 실제 모바일 기기, 운영 기록 원문 연동, 후기 수집은 미검증입니다.

## 성장나무 중심 단일 화면으로 변경

2026-10-08 후속 사용자 검토로 성장기록 상단 현재 상태/성장 이력 탭을 제거했습니다. 나무를 먼저 보여주고 선택 활동 기록에 전체/피드백/결과물/교과 확인 필터를 둡니다. 기존 기록은 출처·유형 확인 전 임의로 필터에 분류하지 않습니다. 기록 아래 종이 교과 확인 카드를 두고 과목 선택 → 문제지 보기·인쇄 → 푼 답안 등록 → 부모의 맥락·기준 확인 → 근거와 결과 보존을 연결합니다. 가정에서 수행한 점검은 가정 활동에 연결하고 과목은 별도 영역으로 분류합니다.

이번 시안의 ‘푼 답안 올리기’는 확인 단계 미리보기만 표시하며 실제 사진 업로드·답안 평가·저장은 하지 않습니다. 문제지 보기에서는 기존 5과목 통합 검토본으로 연결합니다. 교과 수준 판정과 나무의 잎 크기는 연결하지 않습니다. 앞선 상단 탭 관련 설명은 이 단일 화면 제안으로 대체하며 운영 코드 통합은 아직 하지 않았습니다.

교육정보 리서치 분담과 세션별 전달문은 `한눈육아-교육정보-리서치세션-전달프롬프트.md`에 정리했습니다.

## 진입 시 접힘과 두 버튼 구성

후속 사용자 요청에 따라 진입 시 활동 기록과 교과 확인 내용을 모두 숨깁니다. 나무 잎을 선택하면 해당 활동 기록이 펼쳐지고, 현재 상태 확인 버튼을 선택하면 교과 이해 확인이 펼쳐집니다. 서로 독립적으로 열 수 있으며 성장기록 메뉴로 재진입하면 다시 접힙니다.

교과 확인에는 공립 교육과정 참고 ‘3학년 2학기’를 표시합니다. 수아 실제 학교 진도나 문항의 학기별 적합성이 확정됐다는 의미는 아니며 학기별 문항 대응은 별도 검토합니다. 과목 선택 아래 ‘기존 측정이력이 없습니다.’를 표시하고, 그 아래 문제지 보기/인쇄 및 결과 등록 두 버튼만 둡니다. 기존 문제지/푼 답안/확인 기록 단계 표시는 제거했습니다. 실제 기록 확보 후에는 수행일·과목·참고 학년/학기·확인 범위·근거 링크를 두 버튼 위에 표시합니다.

Chrome에서 초기 두 영역 숨김, 버튼 선택 후 펼침, 잎 선택 후 활동 기록 펼침, 결과 등록 설명을 확인했습니다. 실제 업로드·결과 저장·운영 앱은 이번에 변경하지 않았습니다. 수정 시안 주소는 http://127.0.0.1:8771/design-previews/child-centered-education/ 입니다.

## 한 줄 접기와 간결한 교과 확인

성장나무 아래 활동기록 상세보기 / 현재 상태 확인 / 기록과 관련된 교육정보를 한 줄 펼침 메뉴로 배치합니다. 각 메뉴는 재클릭하면 접힙니다. 나무의 같은 잎을 다시 선택해도 활동 기록이 접히고, 다른 잎을 선택하면 해당 활동으로 전환해 펼칩니다. 초기에는 세 메뉴 모두 접힙니다.

교과 확인은 제목·학년/학기, 과목, 기존 측정이력 안내, 문제지 보기/인쇄 및 결과 등록 버튼만 우선 표시합니다. 상세한 공립 교육과정 참고 범위·학기 대응 미검증·학년 전체 판단 불가 안내는 확인 기준 안내 안에 접어둡니다.

기록과 관련된 교육정보는 기록에서 관련 활동·수업 방식·피드백 비교 기준으로 넘어가는 연결입니다. 아이 상태 자동 평가나 추가 학원 유도 기능이 아닙니다. 시안에서는 일반 교육 선택 화면으로 연결하며 실제 근거별 개인화 연결은 아직 구현하지 않았습니다.

Chrome에서 같은 잎의 펼침/접힘, 활동 메뉴의 펼침/접힘, 상태 확인 및 관련 교육정보의 펼침/접힘을 확인했습니다. 운영 앱은 변경하지 않았습니다.

## 앱 CSS와 크기 사전 검증

별도 `design-previews/growth-app-theme/index.html`에 index.html의 실제 CSS 로드 순서를 적용하고 신규 요소 색을 앱 토큰으로 연결했습니다. 운영 파일은 수정하지 않았습니다. 로컬 family-theme.css 마지막 선언은 보라색 테마이며 문서의 초기 오렌지/딥포레스트 값보다 현재 CSS를 우선합니다. 배포된 자산과 로컬 자산의 동일성은 이번에 확인하지 않았으므로 이 결과는 현재 작업본 기준입니다.

Chrome 계산값: 배경 #f4f2f7, 본문 #302c3c, 강조 #715697, 버튼 글자 #fff, 앱 최대 폭 480px, 기본 글자 15px, 교과 제목 16px, 한 줄 메뉴 높이 약65px, 주요 버튼 글자14px/높이43px, 바깥 카드 반경16px. 나무는 기존 앱 CSS의 최대390px를 유지합니다. 실제 CSS 390px 모바일 뷰포트에서 가로 넘침 없이 표시됐으며 나무 폭은 약336px입니다. 실제 휴대폰과 로그인된 운영 전체 화면 검증은 남아 있습니다.

기존 독립 시안의 620px 폭·초록 강조색을 그대로 복사하면 앱과 달라집니다. 신규 스타일은 운영 반영 시 성장 메뉴 범위에만 적용하고 앱 토큰을 참조해야 합니다. .card/.primary 등 범용 클래스 전역 덮어쓰기는 기존 메뉴에 영향이 있으므로 시안 스타일을 통째로 운영 CSS에 넣지 않습니다.
