# 메뉴별 UX 검토 종합 — 현황과 우선순위 계획 (초안, 2026-10-05)

기준: docs/한눈육아-서비스방향설계서.md, docs/한눈육아-메뉴별UX지침.md
근거: 01~05 검토 문서(코드·데이터 정적 분석, 화면 미확인 항목은 각 문서에 '추가확인 필요'). 이 문서는 사용자와 계획을 검토하기 위한 초안이며, 확정 전에는 구현을 시작하지 않는다.

## 1. 현재 상황표

평가 5기준 점수: ①검색 ②판단 ③입력 ④기억 ⑤가족 전달 (1~5, 높을수록 부모 수고가 적음). "현재 → 개선 후 예상".

| 메뉴 | 지금 되는 것 | 설계서와 가장 큰 차이 | ① | ② | ③ | ④ | ⑤ |
|---|---|---|---|---|---|---|---|
| 홈 0~35개월 | 월령 항목 자동 선별, 카테고리 줄, 혜택, 곧 배너, 가족 일정 | 대표 고민 선별 없이 카테고리 나열 → 부모가 우선순위 판단 | 3→4 | 2→4 | 4→4 | 3→4 | 3→4 |

## 2. 공통 갭(메뉴를 가로지르는 문제)
1. 대표 고민 선별 층이 없다: 모든 메뉴가 '목록'을 보여 주고 우선순위는 부모가 정한다(홈·월령 정보·지원).
2. 36개월 이상이 얇다: 월령 정보·혜택 탭이 사라지고 홈은 입력 위주. 설계서의 3~5세·6~7세·초등 역할(교육 선택·초등 준비·지역 정보)이 비어 있다.
3. 정보→행동→일정 연결이 일부만: 일정 넣기는 접종·검진·학교·엔진 지원금 위주. 지역 지원금·관찰형·어디갈까·교육에서는 끊긴다.
4. 지역이 약하게 쓰인다: 지원은 3개 시·도만, 어디갈까는 거리 정렬뿐, 교육은 데이터 없음.
5. 가족 전달: 담당 지정·알림 부재로 '엄마가 기억하고 전달'하는 구조가 남아 있다.
6. 입력: 직접 입력뿐(사진·음성 없음), 자동화 가능한 일정 10종을 부모가 입력.

## 3. 우선순위 계획(초안)

### 단계 0 — 설계서 위반·버그성 정리 (S, 병렬 2~3묶음, 약 1~2일)
| 묶음 | 내용 | 메뉴 |
|---|---|---|
| 0-A 지원 | 36+ 지원금이 날짜 필터로 사라지는지 확인·수정 / 같은 제도 중복 4쌍 정리 / 지역 지원금(마감 있는 것) 일정 넣기 허용 / 옛 등급 '확정시행' 32건 재판정(조사) | 지원 |
| 0-B 표시 | 36+ 홈 아이 이름·나이·지역 한 줄 / 학교·어린이집 상세 시트 라벨 오류(관찰 포인트) 수정 / 어디갈까 '○○ 기준·○○구' 한 줄+빈 칩 숨김 / 교육 트렌드 빈 틀·문구 정리 | 홈·정보·어디갈까·교육 |
| 0-C 일정 | 담당 지정 복원(계정 모드 폼·카드) / '예방접종' 칩으로 만든 일정과 자동 항목 연결(같은 날 두 번 보임) / 취학 배너 1월까지 연장 / 초등 학년 전환 다음 단계 | 캘린더·다음 단계 |

### 단계 1 — "먼저 찾아주는" 핵심 경험 (M, 최종 디자인 검토 전 구조 확정)
1. 홈 3단 구조: 지금 꼭 할 것(최대 3) / 곧 / 살펴볼 것(접힘) + 완료·예약 숨김과 7일 전 재노출 규칙을 전 단계 통일
2. 홈 '이번 달 한눈에' 요약: 가족 일정 N·챙길 것 N·갈 만한 곳 N·교육(해당 연령)
3. 월령 정보 '왜 지금' 한 줄 + 5구분(지금 알아야/관찰/해볼/주의/곧 준비) + 36+ '이 시기 정보' 섹션
4. 지원 목록 3단(마감 임박 / 확실히 받는 것 / 조건 확인) + '우리 집 해당' 판단과 '신청 완료' 분리 저장 + 신청처 필드
5. 자동 일정 두 층: 행동형은 달력 칸, 정보·관찰형은 목록(결정 필요) + 홈 가족 카드에 AUTO 예약·마감 포함
6. 다음 단계 확장: '무엇이 달라지나' 정보형 항목, 3~5세 교육 선택 단계, 30개월 시점(결정 필요)

### 단계 2 — 입력 줄이기(W8)
1. 붙여넣기 → 공통 파서 → 확인 화면(서버 없이 먼저 가능)
2. 음성: iOS 홈 화면 웹앱 실기기 확인 → 가능하면 음성, 아니면 키보드 받아쓰기 안내
3. 사진(OCR): 이후. 원칙: 해석→후보→확인→등록

### 단계 3 — 데이터 트랙(조사 선행, L, 단계 0~1과 병렬)
- 어디갈까: 유형별 권장 연령 반영(박물관 36+·놀이시설 36- 성인 동반·도서관 하한 없음) → 개별 재조사, 지역 확장
- 교육 트렌드(W6): 공개 데이터(학교알리미·교육기본통계) 서울·경기 초등부터, 표본 기준 확정 후
- 지원: 13개 시·도 지역 지원 조사(누적), 신청 링크 확대
- 월령: 임신 주차별 검사, 유치원 입학 시기, 늘봄·방과후, 발달 이정표 시점 근거

### 단계 4 — 최종 디자인 검토
단계 1로 홈·메뉴 구조가 정해진 뒤 허브형 홈 시안 → 전체 색·모양 통일(임신 정보 수정 시트 포함). 이후 W9(알림·또래 집계 등).

## 4. 사용자 결정이 필요한 것
1. 36개월 전 안내를 30개월부터(6개월 전) 보여줄지
2. 교육 트렌드 탭 노출 시점: 3세부터(3~5세 내용 신설) vs 초1부터
3. 정보·관찰형 자동 항목을 달력 칸에서 뺄지(목록에서만)
4. 생일·100일·돌을 자동 일정으로 넣을지
5. 매월 반복 추가(저장 규칙 변경) 여부
6. '자동 항목 접기' 스위치 기본값
7. 36개월 이상 지원금 허용 목록 확대 여부
8. 어디갈까를 임신 중에도 보여줄지
9. 교육 트렌드 최소 표본 기준(30/100 초안) 승인
10. 체크리스트 그룹의 완료/전체 개수 표시(이전 '달성률 제거' 방향과의 정합)
