# 07b. 6명 결과 검토 (hn_pm, 1-0 ④)

> 대상: `07-큐레이션-6명-결과.md`(md5 e74a487d…) · 기준: 지시서-1-0 §4의 7질문, 06 설계, 결정목록 D11~D16
> 결론 먼저: **구조(게이트→유형→시급성→슬롯)는 맞게 작동한다. 다만 지금 결과 그대로면 "부모가 먼저 볼 것"이 제대로 골라지지 않는다.** 원인은 숫자(30/45/60)가 아니다. ① 나이가 지난 항목을 거르는 게이트가 없다 ② 오래전에 기한이 지난 항목이 맨 위로 올라온다 ③ 묶음과 분류 데이터가 빠졌다. 고치는 순서는 값 → 예외 id → 규칙이다.

## 2. 원인과 수정안 (작은 변경부터)

### B. 사용자 확인 필요 — 화면에 보이는 규칙 변경
| # | 문제 | 제안 | 추천 |
|---|---|---|---|
| B1 | 완료 기록이 없으면 오래전 기한이 지난 접종·검진(L3)이 '지금 꼭'을 다 채움(21개월에 B형간염 1차·BCG). 실제로도 앱에 기록하지 않는 부모가 많음 | L3('늦었지만 가능')는 **기간이 끝난 지 60일(shortWindowDays) 안**인 것만. 더 오래된 것은 한 덩어리 '지난 접종·검진 기록 확인 N개'(확인형, '곧' 칸 1단위, 누르면 체크리스트로) | **적용**. 오래전 항목은 '할 일'보다 '기록 확인' 성격. 놓친 접종을 숨기지는 않음(한 줄로 남김) |
| B2 | urgentLongWindowIds(아동수당 등)가 4세·예비초에도 '지금 꼭'(L4) | 긴 창 상향은 **창 시작 후 60일(소급 기한) 안**에만. 이후는 L5('곧', 여유) | **적용**. 06 §3-3의 근거(미루면 손해)는 소급 기한 안에서만 성립 |
| B3 | 'N개 더'를 펼치면 21~36개가 나와 홈이 다시 목록 화면이 됨 | 펼침은 **최대 5개 + "전체 보기 →"**(지금 꼭·곧은 체크리스트, 혜택은 혜택 탭, 알아두기는 월령 탭으로 연결) | **적용**. 지난번 결정('N개 더' 펼치면 보여야 함)은 유지하되 상한을 둠 |

※ 숫자 값(30/45/60/7일·슬롯 3/2/1)은 **이번 결과로는 바꿀 근거가 없다**. 어색함은 모두 게이트·묶음·분류에서 생겼다. 45일은 A2 적용 후 다시 본다.
