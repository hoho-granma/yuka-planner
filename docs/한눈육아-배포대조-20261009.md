# 2026-10-09 배포 대조와 보완

대조 기준: origin/main 76ed2be, GitHub Pages v2.0.25. 실제 공개 파일의 버전, 교육정보·교육선택·성장기록·교과표·확인지 파일은 해당 커밋과 일치했다. 교육정보 조사·교과 초안·API 선행 검증은 이미 커밋된 상태다. 상세 조사 범위는 `한눈육아-교육기능-구현과조사-통합현황-20261009-codex.md`에 기록되어 있다.

## v2.0.26 보완

- 승인된 교육선택 과목 태그를 항상 표시하고 클릭 필터를 연결했다.
- 홈 일정·할일 제목은 가족 섹션 제목과 같은 17px, 할일 탭 제목은 18px로 확대했다. 교육 통계·성장기록 설명과 버튼도 소폭 확대했다.
- 음성 입력은 취소 이후 늦은 결과를 전달하는 문제와 대기 제한 누락이 확인되어 일정·할일 진입 버튼을 보류했다. 사진·메시지·직접입력은 유지한다. 실제 기기의 음성 인식 정상화는 완료하지 않았다.
- 메뉴 전체를 투명하게 시작하던 전환을 제거했다. 스와이프는 투명도를 건드리지 않는 12px/180ms 이동만 사용하고 연속 동작 시 이전 애니메이션을 취소한다. 동작 줄이기 설정에서는 애니메이션을 생략한다.
- 성장기록의 화면 확인 선택자 `.lc-page`를 실제 `.gr-page`로 바로잡았다. 아이·가족 또는 연결된 교육 일정이 변경되면 다시 그리되 일반 동기화에서는 불필요하게 마운트하지 않는다.
- 교육기관 조회는 사용자별 메모리 캐시 5분, 동시 요청 합치기, 교육정보 진입 시 선조회, 캐시 재사용 시 로딩 표시 생략을 적용했다. 로그아웃·계정 변경 시 캐시를 쓰지 않는다. 첫 조회는 SDK 로드·서버 시작·나이스 페이지 조회 시간이 남아 있다. 실측 응답시간 개선 수치는 확보하지 않았다.
- 교육기관·공공프로그램 JS가 오프라인 셸 목록에서 누락된 점을 보완했다.
- 월·주 캘린더에 2026·2027년 공휴일 명칭과 빨간 날짜를 기본 표시한다. 대체공휴일·선거일과 2026년 추가 지정된 노동절·제헌절을 포함한다. 개인 일정 개수·완료율에는 포함하지 않는다. 다른 연도는 공휴일 자료 미확인 안내를 표시한다.

## 아직 구현 범위에 포함되지 않은 내용

네이버 후기 검색의 사용자 화면 연결, 독립적으로 사용 허락된 후기 데이터 분석, 교습비의 지속 수집·정규화·비교, 전국 기관 데이터 확대는 완료하지 않았다. 공공프로그램은 일부 도서관 자료 범위다. API 호출 성공을 후기 원문 저장·AI 입력 권한으로 해석하지 않는다.

이번 수정과 무관한 RSV 데이터 초안, 중복 메시지 서버 초안, 환경변수·로그·www 복사본·과거 시안은 포함하지 않는다. Firebase 함수·Firestore 규칙 배포는 수행하지 않는다.

## 검증

교육정보·기관 조회·성장기록·입력 보류·일정 로직·공휴일·주 보기 날짜 로직 81개 통과. 스와이프 연속 취소·동작 줄이기 검증 2개 추가 통과. JS 문법과 diff 공백 검사 통과.

별도 과거 회귀 파일의 한계: `user-schedule-view.logic.test.js`의 시간 휠 관련 기존 2개 실패. `f2-week-view.test.js`에는 과거 커밋과 원문 일치·옛 클릭 호출·선택 CSS 문자열을 요구하는 실패가 있다. 공휴일에 따른 날짜 제목 변경은 의도된 변경이다. 이 파일이 발견한 셸 누락은 수정했다. 전체 테스트 통과를 주장하지 않는다. 실제 기기 브라우저에서 글자 배치·애니메이션·첫 서버 호출 속도는 추가 확인이 필요하다.
