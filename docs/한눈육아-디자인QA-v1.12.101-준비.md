### 1-7 예약 폼 '추천일로 하기' 후보 칩
진입: 캘린더 → 추천일 칩이 있는 자동 항목(예: 4개월 접종 묶음) → 상세 → '일정 넣기'(예약 폼)
| # | 요소 | 셀렉터 | 기대값 | 방법 |
|---|---|---|---|---|
| 1 | 후보 칩 존재 | `.us-field.us-recommend [data-us-recommend]` | 1개, 글자 "추천일 M/D로 하기", `data-us-recommend` = 달력 추천일(YYYY-MM-DD) | DOM |
| 2 | 칩 모양 | 위 요소 | 기존 `.us-chip`과 같음: 흰 면(#fff), 선 1px `--border`(#e1dfdb), r999, 13px 700. **새 색 없음** | computed |
| 3 | 위치 | `.us-recommend` 다음 형제 | 날짜 칸(`.us-field` 날짜 선택) 바로 위, 반복 선택 블록 아래 | DOM 순서 |
| 4 | 누른 뒤 | 날짜 칸 값 | 날짜만 채워짐. 시각·제목·메모 그대로(입력 중 글 보존), **저장은 안 됨**(I9) | DOM |
| 5 | 안 보여야 하는 경우 | `.us-recommend` | 날짜가 이미 있음 / 반복 일정 / 수정 모드 / 추천일 없음 → 없음 | DOM |
- 캡처 1: 칩이 보이는 예약 폼(누르기 전).

### 2-4 '2주마다' 반복
진입: + → 일정 추가 → 반복
| # | 요소 | 기대값 | 방법 |
|---|---|---|---|
| 1 | 반복 칩 | `.us-chips` 안 "안 함 / 매주 / 2주마다"(`data-us-repeat="BIWEEKLY"`) — 기존 `.us-chip` 모양, 선택 시 `.active`(기존 활성 모양) | DOM·computed |
| 2 | 요일 기본값 | 2주마다 선택 + 요일 미선택이면 시작 날짜의 요일이 자동 선택 | DOM |
| 3 | 요약 문구 | "2주마다 월 · 10/6~2027/2/26" 형식(R11) | DOM 텍스트 |
| 4 | 달력 칸 | 2주 간격으로만 칩, 사이 주는 없음 | DOM(두 달치 칸 확인) |
| 5 | '매월'·'매월 같은 요일' 칩 | **비활성 자리표시로 있음**(G13부터 의도, 기능목록 158행): `.us-chip.us-chip-soon[disabled]` + 작은 글자 "곧 추가돼요". 눌러도 선택되지 않음(D5: 매월 반복은 나중). *정정 2026-10-05: 처음 기준 '없음'은 잘못* | DOM |
- 캡처 3: 2주마다 선택한 폼(요약 문구 보이게).
