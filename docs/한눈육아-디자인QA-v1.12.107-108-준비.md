- 캡처 2: 상세 시트 위쪽 한 장(머리 + 단계 1~3).
- **[명세 정정 · data-as 이름]** 내 명세(통일-시트3종 §2 #10·#11)는 `[data-as="link"]`를 '안내 보기', 일반 행동을 '가족 캘린더에 넣기'로 적어 **이름이 반대로 매핑**돼 있었다. 코드(auto-steps.js 4행·125~126행)는 `data-as="apply"` = 안내 보기(href), `data-as="link"` = 가족 캘린더에 넣기다. **패치가 코드 기준으로 맞게 적용**했고(위 표 #9·#10), 명세 문서의 이름이 틀렸다 → 명세 §2 #10·#11을 위 표대로 고칠 것(색 값은 같음: 안내 보기 = 흰 + 인디고 선, 가족 캘린더에 넣기 = 인디고 면).
- **[사전 차이 4·중간]** 분류 뱃지: 앱 기본 규칙(`body.acct-design .modal-panel .acct-sub-head .cat-badge { background:#fff !important; color:var(--c-ink) }`)이 뱃지를 **흰 면**으로 만들어 두었는데(차콜 머리 위에서 보이게), 패치로 머리가 **흰 면**이 되어 뱃지가 흰 바탕 위 흰 알약이 되어 모양이 사라지고 글자만 남는다. 명세 #3은 '분류 뱃지 그대로'였으나 그대로 두면 보이지 않는 문제 → 머리 안 뱃지에 1px `--line` 또는 분류 색 면(`.cat-badge` 인라인 색) 복원이 필요(권장: `.modal-panel:has(.as-steps) .acct-sub-head .cat-badge { background: var(--bc-bg,#fff) !important; border:1px solid var(--line) }` 계열). 확인: 상세 시트 머리의 분류 뱃지가 알약 모양으로 보이는지.
- **[사전 차이 5·낮음]** '넣은 일정 보기'(`data-as="view"`)와 '완료 체크'(`data-as="toggle"`)는 기본 `.as-btn`(흰 + 선)이라 연달아 놓이면 주요/보조 구분이 약함(명세 범위 밖, 기록만).
