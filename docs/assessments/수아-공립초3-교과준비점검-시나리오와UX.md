# 수아 공립 초3 교과 준비 점검 시나리오와 UX

2026-10-08 사용자 변경사항 반영. **설계 문서이며 앱 구현·수아 실제 수행·자동 수준 판정을 완료한 상태가 아니다.**

수아는 국제초에 다니며 한국 공립 초등학교의 현재 교과서를 사용하고 있다는 전제가 없다. 사용자의 목표는 국어·수학·사회·영어·과학에서 공립 초3 교과 내용에 어느 정도 준비되어 있는지 점검하고, 필요한 경우 같은 영역의 이전 단계 내용을 확인하는 것이다. 이번 흐름은 상태 점검에서 끝낸다. 일정 등록·교사 질문·학원/활동 추천·가정 보완 처방은 넣지 않는다.

## 1 변경한 목적과 범위

진입 카드 제목은 **공립 초3 교과 준비 점검**으로 변경한다. ‘학교에서 배운 내용 확인하기’를 수아의 필수 시작 조건으로 사용하지 않는다. 교과서 출판사·학교 단원을 부모가 입력하지 않아도 점검을 시작할 수 있는 구조를 설계한다.

설명: “국어·수학·사회·영어·과학의 초3 참고 내용을 과목별로 살펴봐요. 어려운 항목은 기초 내용부터 다시 확인할 수 있어요.”

‘현재 공립학교 진도’는 전국 공립학교가 같은 날짜에 같은 단원을 끝냈다는 뜻으로 사용하지 않는다. 교육부 공식 기준에 공립학교 채택 교과서의 초3 배치를 대조하여 만든 **초3 참고 범위**를 표시한다. 기준을 제공하는 서비스가 배치/버전을 관리하고, 부모에게 수아 학교의 한국 교과서 진도를 찾도록 요구하지 않는다. 달력 날짜만으로 특정 단원이 이미 배워야 하는 내용이라고 확정하지 않는다.

현재 문항의 공식 성취기준은 3~4학년군이다. 어떤 내용이 실제 초3에 배치되는지는 공식 국정/검정 교과서의 학년·학기·목차 대조가 필요하다. 이 대조 전에는 ‘초3 후보/학년군 기준’으로 표시하고 ‘공립 초3 공통 진도’라고 공개하지 않는다. 초3 전범위 모드와 일부 항목 빠른 점검을 구분한다. 초기 30문항만으로 전범위 결과를 만들지 않는다.

자료가 없다/아직 접하지 않았다/한국어 용어가 낯설다는 상태와 수행이 어려운 상태를 분리한다. 국제초 여부만으로 한국어·학업 능력을 추정하지 않는다. 기관 진학·배정 판단이나 객관적 표준검사로 사용하지 않는다.

## 2 전체 시나리오

성장기록의 ‘현재 상태 점검’ → 공립 초3 교과 준비 점검 → 과목 선택 → 참고 범위 확인 → 초3 후보 문항 수행 → 필요한 항목 재확인 → 같은 영역 기초 단계 선택 → 과목 결과 → 전체 과목 현황.

- 성장기록이 없어도 시작 가능. 기존 학원 자료/레벨을 점검 답으로 대체하지 않는다.
- 과목마다 독립 진행. 국어 결과로 수학·사회·과학 상태를 자동 변경하지 않는다.
- 문제는 아이가 풀고, 부모는 필요할 때 구술 답/도움 조건을 확인한다. 부모가 아이의 이해도를 설문으로 대신 점수화하지 않는다.
- 처음에는 선택한 과목의 짧은 문항 묶음. 전체 5과목 완료·시간 제한·연속 기록을 요구하지 않는다.
- 어려운 문항이 하나 나왔다고 학년 전체를 낮추지 않는다. 해당 개념만 기초 단계로 이어간다.
- 답을 본 뒤 다시 풀기는 학습/연습 경험으로 구분한다. 최초 답과 정답 공개 여부를 보존하며 독립 확인 성공으로 집계하지 않는다.
- 중단·모름·처음 보는 내용·문장 뜻을 모르겠음을 허용한다. 중단한 항목을 오답으로 처리하지 않는다.

## 3 화면별 UX

### 화면 A 진입 카드

2026-10-08 구현 후보에서는 성장기록에 진입·답안·결과를 두고, 교육정보의 우리 아이 축은 이 화면으로 연결한다. 성장기록의 기존 나무·활동별 이력은 그대로 유지한다.


```
수아 · 초3
공립 초3 교과 준비 점검
한국 공립학교의 초3 참고 내용을 과목별로 확인해요.
기록이 없어도 시작할 수 있어요.

[과목별 점검 시작]
참고 기준 보기 >
```

초등학교 유형은 수아 테스트 맥락으로 반영하며 다른 가족 프로필 입력을 일괄 늘리지 않는다. 기준 상세에 교육과정 버전·학년/학기 참고 범위·국정/검정 교과서 대조 상태·문항 검토 상태를 제공한다.

### 화면 B 과목 선택과 진행 현황

```
어떤 과목부터 확인할까요?

국어  아직 점검하지 않았어요          [시작]
수학  진행 중 · 계산 항목 확인 중     [이어하기]
사회  아직 점검하지 않았어요          [시작]
영어  아직 점검하지 않았어요          [시작]
과학  아직 점검하지 않았어요          [시작]

각 과목은 따로 확인할 수 있어요.
```

이 화면의 상태는 예시이며 수아 실제 결과가 아니다. 종합 점수·평균·등급·빨간 부족 배지를 쓰지 않는다. 국어→수학 같은 강제 순서는 없다. 완료는 문항 응답/결과 확인 완료를 뜻하며 학습 숙달 완료가 아니다.

### 화면 C 과목 시작과 기준 범위

```
수학 · 초3 참고 내용
이번에 확인할 것: 계산 / 묶음과 나눗셈 / 분수 기초
점검하지 않는 영역도 결과에 표시해요.

[이 항목부터 확인하기]
[다른 항목 선택]
```

초기 후보의 범위가 일부라면 ‘부분 점검’ 표시가 필수다. 교과서명을 입력하는 단계 대신 서비스의 참고 범위를 보여준다. ‘배웠나요?’는 진입을 막는 필수 선택이 아니라 문항이 낯설 때 응답 가능한 맥락으로 바꾼다. 결과에서 처음 접한 내용과 이해가 확인되지 않은 내용을 구분한다.

### 화면 D 아이가 푸는 문항

```
묶음과 나눗셈 · 초3 참고 항목
[문제와 필요한 그림/자료]

[답 입력 또는 선택]
어떻게 생각했나요? [그림/풀이/짧은 설명]

[다음]
[처음 보는 내용] [문장 뜻이 어려워요] [잠깐 멈추기]
```

한 화면 한 문항. 정답·해설은 최초 응답 전 노출하지 않는다. 필수 풀이 입력은 이해 확인에 필요한 문항만 적용한다. 그림/수식/구술 등 과목에 맞는 답 형식을 제공한다. 구술·사진 입력은 기존 기능의 지원 여부를 확인하고, 준비되지 않은 기능을 제공 중이라고 표시하지 않는다. 사진 업로드는 실제 지원된 경로 재사용을 검증한다.

부모용 보조 영역에 ‘혼자 수행 / 문제만 읽어줌 / 단어 뜻 설명 / 풀이 도움 / 답 보고 다시 수행’을 기록한다. 도움을 요청할 때만 간단히 표시하고 매 문항마다 긴 체크리스트를 띄우지 않는다. 구술 전사 입력자는 부모, 수행자는 아이로 구분한다. 문제 읽어주기는 국어 읽기 자체의 평가와 다른 조건이다.

### 화면 E 다시 확인 또는 기초 단계

```
이 항목은 아직 설명이 충분히 확인되지 않았어요.
수학 전체 수준을 정한 결과는 아니에요.

[비슷한 내용으로 다시 확인]
[기초 내용부터 확인]
[이번에는 결과만 보기]
```

오답 하나로 자동 강등하지 않는다. 같은 개념의 새로운 예를 사용해 재확인하고 문제 이해·한국어 용어·단순 계산 실수·풀이 도움 등 맥락을 함께 본다. 시스템이 선택형 정답만 비교해 원인을 단정하지 않는다.

기초 단계의 제목은 ‘초2로 내려가기’보다 ‘두 자리 계산부터 확인’처럼 실제 확인 내용을 우선한다. 국어·수학의 이전 학년군 대응이 검증된 경우에만 ‘초1~2 참고 내용’ 보조 표기를 허용한다. 부모가 더 어려운 문제를 강제로 풀리거나 끝없는 하향 탐색을 하지 않도록 해당 과목의 기초 미확인에서 종료/보류 가능.

### 화면 F 과목 결과

```
수학 준비 점검 결과
이번에 점검한 초3 참고 내용에서는 이해가 대체로 확인됐어요.
※ 수학 전체나 초3 전범위를 확인한 결과는 아니에요.

계산                이번 문항에서 확인
묶음과 나눗셈       기초 내용부터 다시 확인
분수 기초           처음 접한 내용 · 아직 판단하지 않음
도형 / 측정 / 자료  이번에는 점검하지 않음

근거 답안 보기 >
[기초 내용 확인] [다른 과목 점검] [점검 마치기]
```

위 문구는 설계 예시이며 아직 판정 규칙이 승인되었거나 수아가 이 결과를 받은 것이 아니다. 항목 결과가 혼합된 경우 첫 문장은 ‘이해가 확인된 항목과 다시 확인할 항목이 있어요’로 바꾼다. ‘점검한 초3 내용은 대체로 이해’는 확인 영역/범위를 명시할 때만 후보 문구로 사용한다. ‘수아는 초3 수준이다/초2 수준이다’는 만들지 않는다.

근거 보기는 실제 답·설명·시도·도움·정답 공개/연습 여부·문항/기준 버전으로 연결한다. 결과 화면의 행동은 기초 항목 재점검·새 문항 재확인·다른 과목·종료뿐이다. 일정/교사 질문/추가 교육 추천은 이번 흐름에서 제외한다.

### 화면 G 전체 현황

과목별 결과를 병렬 표시한다. 점검 완료일과 부분 범위/미확인 영역을 보여준다. ‘5과목 평균 수준’이나 국어/영어 점수의 상호 환산은 없다. 다시 점검할 때 이전 답을 유지하고 새 경험으로 남기되 조건이 다르면 변화 비교를 보류한다.

## 4 과목별 하위 단계 연결

| 과목 | 초3 참고 내용 시작 | 어려울 때 이어갈 기초 | 금지할 표현/해석 |
|---|---|---|---|
| 국어 | 글 내용·중심 내용·의견과 이유 | 짧은 문장 의미→짧은 글 내용→중심 내용. 초1~2 국어 대응 기준 확인 | 한국어 문장 어려움=전체 사고력 부족, 단일 글=국어 학년 수준 |
| 수학 | 초3 배치가 확인된 계산·곱셈/나눗셈·분수 등 영역 | 해당 항목의 수 개념/두 자리 계산/묶음/등분할 등 선행 개념. 초1~2 수학 기준 대응 확인 | 계산 실수=개념 부족, 한 영역 오답=수학 전체 초2 |
| 사회 | 초3 교과서에 배치된 시간/지역/생활 이해 | 생활 속 장소·시간 흐름·주변 경험 등 관련 통합교과 기초 | 존재하지 않는 ‘초2 사회 교과 수준’ |
| 과학 | 초3 교과서에 배치된 관찰·분류·물질/소리 등 | 특징 관찰·같은 점/다른 점·기준으로 묶기 등 통합교과 관련 경험 | 존재하지 않는 ‘초2 과학 교과 수준’, 글 읽기=실험 역량 |
| 영어 | 초3 영어의 문자·소리·의미·표현과 듣기 | 글자/소리·친숙한 단어·짧은 표현 등 영어 기초 기능 | 존재하지 않는 ‘공립 초2 영어 교육과정’, 독서 레벨=영어 전체 준비 |

교육부 공통 교육과정에서 초1~2는 사회/과학을 독립 교과로 평가하는 대신 관련 통합교과 경험을 구분해야 하고, 영어는 초3 이전 공립 교과 학년 수준을 만들어내지 않는다. 기능별 기초 단계는 새 기준인 것처럼 포장하지 않으며 공식 기준 대응·교육 검토 상태를 명시한다.

국어와 수학에서도 공식 기준은 학년군으로 제시된 부분이 있어 ‘초1/초2’를 나누는 배치는 교과서 대조가 필요하다. 국제초 수업 언어/익숙한 표현과 다른 문항은 내용 이해와 한국어 용어/표현의 영향을 구분한다. 번역/낭독한 문항은 원문 조건과 동일 난이도/동등 검사가 아니다.

## 5 설명 가능한 분기와 결과 정책

상태 전이: 미시작 → 진행 중 → 초3 항목 확인 / 재확인 후보 / 처음 접함 / 조건 확인 / 중단 → 선택적으로 기초 확인 → 과목 부분 결과 → 종료 또는 다른 과목.

| 관찰 | 표시/분기 | 하지 않을 것 |
|---|---|---|
| 정답이지만 설명/맥락이 없음 | 답안 일치 기록. 이해 설명이 필요한 항목이면 짧게 확인 | 이해·숙달 즉시 확정 |
| 오답/말하지 못함 | 낯선 내용/문장 이해/도움 조건을 구분하고 새 사례 후보 | 곧바로 이전 학년 전체 테스트 배정 |
| 서로 다른 과제에서 관련 이해 근거가 나타남 | 그 기능과 해당 조건의 이해 확인 후보 | 학년 수준/전국 수준 확정 |
| 처음 접한 내용 | 초3 참고 내용 접촉 미확인. 관련 기초 확인 선택 가능 | 능력 부족·실패·오답으로 합산 |
| 같은 기능의 재확인에서도 설명 미확인 | 해당 선행 기능 점검 선택 | 원인/학습 결핍 단정 |
| 기초 항목에서는 이해 근거가 나타남 | 기초 기능 확인, 초3 항목은 재확인 필요 | ‘아이 수준은 초2’라는 포괄 판단 |
| 기초 항목도 미확인 또는 조건 불일치 | 현재 자료로 범위를 정하기 어려움. 결과 보류/종료 | 무한 하향·추정 레벨 표시 |
| 미점검 영역/음원 미준비/서술형 검토 대기 | 미확인/검토 대기 표시 | 0점 처리·임의 자동 채점 |

기초 분기는 교육적으로 검토된 prerequisiteRefs와 alternativeItemRefs로만 연결한다. 난이도를 임의 숫자 순서로 만든 뒤 성적 기반 강등하지 않는다. 초기 30문항 A/B가 동등 난이도이거나 독립 기회인 것은 아니다.

‘대체로 이해’ 요약 정책은 출제 범위의 대표성, 기능별 문항/조건, 수용 답 기준, 혼합 결과 처리, 중단/미학습 처리에 대한 교육 검토 후 확정한다. 지금 70%/80% 컷이나 정답 몇 개만으로 기준을 만들지 않는다. 선택형의 답 일치 채점은 가능 후보지만 서술형·구술·과정 평가에는 검토된 기준과 실제 수행 근거가 필요하다. AI의 텍스트 유사도만으로 의미 이해를 확정하지 않는다.

자동 분기/요약 검토 전에는 응답·해설·근거 비교·기초 항목 선택으로 UX를 시험할 수 있다. 그때 화면은 검토용 사례이며 ‘아이 상태 판단 완료’로 표시하지 않는다.

## 6 범위와 데이터 계약

새 목적은 ‘수아 학교 진도 확인’과 별개인 referenceTrack으로 저장한다.

- purpose: public-school-reference-readiness
- actualSchoolContext: international-school (사용자 확인 맥락)
- referenceGrade: 3, academicYear, referenceTerm/scopeVersion, scopeVerification
- subject/domain, itemId/itemVersion, curriculumVersion, policyVersion
- gradeAllocation: verified-grade3 / grade-band-only / prerequisite-skill
- administrationMode: reading/oral/listening/practical, language, help/translation/rehearsal
- originalResponse, reasoning, responseStatus, familiarityStatus (미접촉과 수행 미확인 분리)
- attemptId, experienceId, criterionEvidenceRefs, branchReason, chosenPrerequisiteRef
- coverage: checked/unattempted/not-applicable/not-ready, excludedDomains
- interpretationStatus: pending-review / limited-evidence / descriptive-result

기존 성장기록 정본과 evidenceRefs를 재사용한다. 새 테스트 화면이 원문을 별도 복사 저장하지 않는다. 같은 회차 여러 과목/문항의 독립성은 경험 연결로 판단하며 문항 수=독립 경험 수로 쓰지 않는다. 정확한 문서 내부 필드 배치/저장 한도는 개발 세션에서 기존 스키마와 대조한다. 민감한 학교명/언어 이력 전체 입력을 필수로 요구하지 않는다.

보호자는 기존 가족 권한으로 결과/원문을 본다. 기관 공유는 기본 제공하지 않는다. 답/근거 정정·삭제·권한 변경 시 파생 결과를 무효화한다. 수아 프로필이나 학년을 이번 기준으로 자동 수정하지 않는다.

## 7 기존 초안과 서비스 방향의 관계

사용자 지시에 따라 이번 점검에서는 일정·교사 질문·추천을 제외한다. 전체 서비스의 정보→행동→일정 철학을 폐기한 것이 아니라 이 단계의 ‘행동’을 실제 교과 점검/재확인/종료로 좁힌 것이다. 기존 교육정보 3축과 성장기록 별도 메뉴는 유지한다.

기존 30문항은 성취기준 연결 후보로 보존하되 초3 참고 배치와 대표성 검토가 필요하다. 기존 독립 HTML의 ‘학교에서 배웠나요’·교사 질문/가정 보완 안내는 새 시나리오와 일치하지 않아 이번 점검의 최종 화면으로 사용하지 않는다. 아직 새 UX를 앱에 적용하거나 문항 뱅크를 완성하지 않았다.

현재 문항에 부족한 핵심 영역: 수학 도형/측정/자료, 국어 영역별 대표성, 사회/과학 초3 단원 배치와 실제 탐구 구분, 영어 듣기/대화 등. 이 영역이 비어 있으면 과목 결과는 ‘부분 점검’에 제한한다.

## 8 다음 작업과 통과 조건

1. **참고 범위 표:** 공식 교육과정의 선택 기준을 공립 초3 국정/검정 교과서 학년·학기 배치와 대조. 특정 학교의 10월 진도처럼 표현하지 않음. 후속 고시 영향 확인.
2. **과목별 출제 설계:** 어떤 기능을 얼마나 대표하는지 정하고 초3 후보/새 사례/해당 선행 기능을 연결. 자료·음원·서술형 기준 마련. 문항 수/판정 컷은 편의로 정하지 않음.
3. **교육적 검토:** 초3 및 관련 기초 단계 검토자의 문항·조건·해석·분기 검토. ‘대체로 이해’ 요약 문구 적용 조건 확정.
4. **UX 시제품:** 위 7개 화면과 5과목 독립 상태, 중단/접촉 미확인/해석 보류/기초 재확인을 시험. 샘플 결과는 실제 수아 결과와 명확히 구분.
5. **수아 수행:** 대표 범위와 적용 조건을 확인한 문항부터 실제 응답 수집. 답과 도움 맥락 보존. 결과 근거 확인 후 앱 연결.

사용자에게 필요한 것은 수아의 실제 수행과 필요할 때 자료의 낯섦/도움 확인뿐이다. 한국 공립 교과서를 찾아 입력하는 일은 필수 선행조건에서 제외한다. 새 목적/범위는 결정되었지만 범위 배치·문항 대표성·교육적 타당성·요약 기준은 여전히 검증 대상이다.

## 구현 후보 v2.0.22와의 구분

- `js/learning-check-bank.js`는 기존 30개 원문 후보와 기초 재확인 초안 5개를 담는다. 교사 검토·초3 학기별 배치·2026 후속 고시 영향은 완료되지 않았다.
- 이번 구현은 테스트용 부분 점검이다. 위 설계의 초3 대표 범위 완료나 전체 수준 판정을 구현했다고 해석하지 않는다.
- 부모는 실제 아이 답을 남긴 후 문항 기준을 비교한다. 표시는 부모의 확인과 도움 맥락에 한정하며 자동 능력 진단·학년 판정·점수는 제공하지 않는다.
- 기초 재확인은 학년으로 하향하는 검사가 아니다. 사회·과학·영어에 초2 교과 판정을 만들지 않는다.
- 구조화 원천 답안은 계정·아이·가족별 IndexedDB에 보관한다. 서버 스키마 2 저장 차단을 우회해 자유텍스트나 첨부로 저장하지 않는다. 현재 기기 간 공유는 제공하지 않는다.
- 구체적인 구현·검증·배포 한계는 `../한눈육아-교과점검-교육정보-구현후보-검증결과.md`를 따른다.
