# 초3 주요 5과목 교과 이해 확인 진행과 연결 계약

2026-10-08. 교육부 배포 교육과정을 기준으로 한 자체 확인지 초안이다. 교육부 제작 시험지나 검증된 수준검사가 아니다. 공립학교의 국정/검정 교과서와 실제 배운 범위를 대조한 뒤 적용한다.

## 수아 테스트의 목적 변경

사용자 확인: 수아는 국제초 재학이며 한국 공립 초3 교과서를 알지 못한다. 수아 점검은 [공립 초3 교과 준비 점검 시나리오와 UX](수아-공립초3-교과준비점검-시나리오와UX.md)를 우선한다. 학교에서 배운 단원 입력을 시작 조건으로 요구하지 않고, 서비스가 확인한 공립 초3 참고 범위와 필요한 기초 기능을 점검한다. 이번 결과 화면에서는 일정 등록·교사 질문·보완 처방을 제외한다.

아래 30문항/독립 페이지는 이전 목적의 검토용 후보로 보존한다. 공립 초3 전범위 점검이나 ‘대체로 이해’ 자동 요약에 바로 사용하지 않는다. 아래 학원 기록/연결 계약은 재사용하되 수아의 이번 목적과 결과 UX는 새 문서가 우선한다.

## 1 현재 산출물과 진행 상태

| 단계 | 현재 상태 | 완료 조건 |
|---|---|---|
| 1 교과서/배운 범위 | 초3 사용자 확인. 공립 교과서 기준 요청 반영. 출판사/단원 미확인 | 학교 채택 도서·학기·배운 항목을 확인. 3~4학년군 전체를 초3 진도로 자동 배정하지 않음 |
| 2 문항/해설/관찰 기준 | 5과목 각 6개, 총 30개 자체 후보 작성. 기본/재확인 후보 15쌍 | 단원/교과서 대조와 후속 고시 영향 확인 후 대상 문항 선정 |
| 3 교육적 검토 | 성취기준 코드 확인과 내부 문구/정답/해석 제한 점검. 외부 교사 검토 미완료 | 초3 교육 경험 있는 검토자의 문항별 검토·수정·검토자/일시/정책 버전 |
| 4 수아 수행 | 미실시 | 배운 항목만 선택하고 응답·풀이·도움·날짜·중단 이유를 확인. 시간제한/전과목 완료 의무 없음 |
| 5 앱 연결 | 데이터/UX 연결 계약만 작성. 현재 앱 화면/DB 변경 없음 | 새 필드 보존·권한·근거 무효화 검증 후 연결. 자동 능력 판정 없음 |

## 2 공식 근거와 확인 제한

[교육부 고시 제2022-33호](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&m=040401&opType=N&page=1&s=moe)의 붙임2 원문 HWP를 직접 내려받아 별책5 국어, 별책7 사회, 별책8 수학, 별책9 과학, 별책14 영어에서 선택 기준 코드를 확인했다. 원문 파일 해시는 별도 확인 목록에 남겼다. 초3~4 적용일은 고시 본문의 2025-03-01이다.

문항/자료/해설은 자체 창작 초안으로 교과서 문제·지문·삽화를 복제하지 않았다. 확인한 성취기준과 문항의 연결은 해당 기능 일부를 살피는 후보이며 기준 전체 도달을 증명하지 않는다. 원문 HWP 텍스트 추출에서 표/제어 문자 일부가 훼손될 수 있으므로 학교 범위·후속 고시와 함께 최종 대조해야 한다.

[NCIC 공지 목록](https://www.ncic.re.kr/bbs/ncicnotice/list.do)에는 2026-1호 후속 고시가 있으나 상세 링크 열람 실패로 다섯 과목에 미치는 개정 영향은 미확인이다. 2022 원문을 ‘최신 개정까지 모두 반영한 기준’으로 표현하지 않는다. [교육부 교과용도서 관련 목록](https://moe.go.kr/boardCnts/list.do?boardID=316&lev=0&m=0302&opType=N&s=moe&statusYN=W)에서 2026-6호 국·검·인정 구분 안내가 검색되었으나 첨부/학교 채택 도서는 미확인이다. 따라서 모든 공립학교에 동일한 5과목 단원 순서가 있다는 전제를 두지 않는다.

학교 도서 정보가 없어도 공통 기능 문항 후보 준비는 가능하다. 사용자가 배운 범위를 모르면 교과서/학교 안내를 확인하거나 문항을 건너뛰며 미학습을 능력 부족으로 처리하지 않는다.

## 3 후보가 확인하는 범위

| 과목 | 이번 후보 | 확인하지 못하는 영역 |
|---|---|---|
| 국어 | 중심 내용, 사실/의견, 의견과 이유 표현 | 전체 듣기·말하기·문학·문법·쓰기 수준 |
| 수학 | 세 자리 계산, 곱셈/나눗셈 상황, 등분할과 분수 | 도형·측정·자료, 모든 연산/분수 수준 |
| 사회 | 시간 흐름, 과거 자료, 교통과 생활 변화 | 지역 실제 조사/전체 사회 이해 |
| 영어 | 대소문자 사례, 짧은 단어 읽기/의미, 주변 물건 표현 | 듣기, 상호 대화, 전체 쓰기·어휘·독서 레벨 |
| 과학 | 관찰 특징 분류, 물체/물질, 소리와 떨림 기록 해석 | 실제 탐구 설계/수행·전체 과학 개념 |

각 과목의 일부 항목만 확인하는 첫 묶음이다. 초3 전범위 확인을 원하면 검토된 단원별 문항을 점진 추가해야 하며 이 30개를 전범위 수준검사로 사용하지 않는다. 읽기 부담이 사회/과학/수학 결과에 영향을 줄 수 있으므로 읽어줬는지 기록한다. 영어 듣기는 음원이 준비/검증되지 않아 종이 읽기 문항으로 대체 평가하지 않는다.

## 4 결과와 다음 행동

원문 답안을 먼저 보존하고 교사/부모 관찰은 별도 근거로 저장한다. 해석은 이번 사례의 기능으로 제한한다.

- 확인된 내용: 실제 답/설명에서 무엇이 나타났는지와 근거 문항.
- 다시 확인할 부분: 오답 원인 추정 대신 설명/읽기/도움/과제 조건 중 무엇을 확인해야 하는지.
- 미학습: 학교에서 아직 다루지 않은 항목, 평가 제외.
- 정보 부족: 답/맥락 미확인, 결과 보류.
- 비교 보류: 조건/자료/난이도/도움이 달라 이전 수행과 직접 비교 불가.

A/B 답이 같거나 두 문항이 맞아도 객관적 숙달/유지/부족으로 확정하지 않는다. 재확인 후보는 별도 상황/시점과 비교 조건이 확인돼야 독립 근거가 된다. 다음 행동은 배운 자료 다시 확인, 다른 사례 설명, 교사 질문 등의 선택이며 기간/횟수·추가 교육을 자동 처방하지 않는다. 가정 지원안의 실제 적합성은 교사 검토 대상이다.

## 5 성장기록과 교육정보 연결

[통합 데이터 계약](../한눈육아-교육성장-통합데이터계약과검증기준.md)을 정본으로 사용한다. 이번 응답 JSON은 임시 독립 페이지 형식이며 그대로 서버 저장 가능한 스키마가 아니다.

- 활동: 새 학원 등록 없이 가정 활동의 교과 확인 활동으로 연결. 학원 자료와 별도 경험이되 관련 영역으로 함께 조회 가능.
- 실제 경험: childRef/childKey를 앱에서 확인한 뒤 experienceId, 실제 수행일, 과목/항목, 학기/단원, 자료 버전·도움 맥락 저장. 동일 회차 여러 답은 같은 경험.
- 근거: 아이 실제 답/풀이/결과물은 수행 근거, 부모의 전사/관찰은 별도 출처. 작성자·기관·발언자를 혼합하지 않음.
- 참조: itemId/itemVersion, standardCodes/curriculumVersion, educationRef/contentVersion, observerPolicyVersion. 현재 교사 검토 전 정책은 판단 활성화에 쓰지 않음.
- 교육정보: ‘이번에 확인한 항목’의 기준 설명 → 관련 답/기록 → 미확인 부분 → 다음 확인 후보 → 필요시 일정 확인 폼.
- 정정/삭제: 원문 revision과 evidenceVersion을 대조해 파생 설명/리포트의 참조를 무효화 또는 재계산. 아이 전환/권한 변경 시 기존 근거 재사용 금지.

독립 페이지는 입력을 서버에 전송하거나 앱 DB/스토리지에 저장하지 않는다. 새로고침 전 응답 JSON 다운로드를 제공하고 자동 점수는 만들지 않는다. 성장기록 연결 개발은 서버 이전 후 실제 필드 보존·권한을 검증한 다음 수행한다.

## 6 별도 개발 세션 인계

사용자가 서버 이전 완료 확인을 전달했다. 이는 이번 세션의 운영 재검증 결과와 구분한다. 별도 개발 세션은 현재 스위치·배포 규칙·본문/첨부 실제 재조회·Chrome/휴대폰 동일 아이 연결을 먼저 확인한다.

담당 범위는 기존 수아 자료 읽기, 출처/경험 메타데이터 보존, 아이별 읽기 인터페이스, 근거 변경 후 연결 무효화다. 이 세션의 문항/확인지 파일을 동시에 수정하지 않는다. 교과서 확인지의 자동 채점·객관적 수준 판단·학원 레벨 환산은 범위 밖이다. 외부 교사에게 자료를 전송하거나 문의하는 행동은 사용자가 별도로 지시하기 전 실행하지 않는다.
