# 교육정보 리서치 세션 전달 프롬프트

2026-10-08. 성장기록은 성장나무 중심 단일 화면으로 개인의 수행·경험·피드백을 축적합니다. 교육정보는 또래·지역 및 교육 선택을 제공합니다. 리서치는 코드 수정 없이 실제 데이터와 제공 조건을 검증하는 작업입니다.

## 세션 1 기관 공식정보

한눈육아 교육 선택에 필요한 실제 기관 데이터를 조사해줘. 코드 구현은 하지 말고 docs/research/교육선택-기관공식정보-검증.md에 결과를 작성해줘.

서비스 방향은 docs/한눈육아-서비스방향설계서.md와 docs/한눈육아-메뉴별UX지침.md, 기존 제한은 docs/한눈육아-교육트렌드-구현가능범위.md를 먼저 읽어라. 기존 나이스 운영 연동 미검증 등의 제한을 실제 증거 없이 해제하지 마라.

초기 지역은 경기도 성남시다. 아이는 초3이지만 국제초이므로 학교 진도를 추정하지 마라. 정확한 생활권은 아직 확정되지 않았으므로 특정 동네를 기본값으로 가정하거나 아이 주소·학교 위치를 수집하지 마라. 성남시 전체 조사에서 주소로 분당구·수정구·중원구 등 실제 구 단위를 구분해라.

1. 나이스/공공데이터포털/교육청의 학원·교습소 자료를 실제 제공 페이지에서 확인해라. API인지 파일인지, 신청/운영키 필요 여부, 실제 응답 구조, 기관 고유 식별자, 페이지 처리·호출 제한·업데이트 주기·이용조건을 기록해라. 실제 호출이 불가능하면 문서 확인과 운영 검증을 분리해라.
2. 수학/영어/과학/국어·독서/미술·음악 등의 분류가 응답에서 어떻게 표현되는지 확인해라. 줄넘기·체육은 학원 데이터에 포함되는지 검증하고 별도 체육시설·센터 공식 자료가 필요하면 표시해라.
3. 시안용 숫자를 채우지 말고 초등 대상이 확인되는 성남시 기관의 소규모 실제 표본을 분야별 최대 2곳 조사해라. 없어도 없다고 표시해라. 기관명·지점·주소·등록상태·과정·대상 연령/학년·시간·교습비 및 별도 비용·차량·상담/체험 링크를 각각 공식 공개 근거가 있는 범위에서 정리해라. 등록정원은 현재 반 인원·이용자 수가 아니다.
4. 교육청 등록정보와 기관 자체 안내를 출처별로 구분해라. 광고 문구를 효과·장점으로 단정하지 마라. 공개 교습비가 실제 수강 총액인지 별도로 확인해라. 동명 기관·지점·반을 구분할 키와 매핑 방법을 제안해라.
5. 지역 도서관·교육청·공공센터·방과후·체험 프로그램도 조사해라. 대상·장소·신청 기간·비용·공식 신청 링크·갱신 방식, 해당 학교 재학생만 가능한지 등의 조건을 확인해라.

최종 표: 데이터 항목 / 실제 확보값 / 출처 URL·확인일 / 제공 방식 / 지역 단위 / 자동 확보 가능 여부 / 미확인 조건. 끝에는 즉시 목록에 사용 가능한 필드, 기관 확인이 필요한 필드, 운영/API 검증 선행조건을 보고해라. 학원 인기·아이 적합도는 만들지 마라.

## 세션 2 맘카페와 이용자 의견

한눈육아 교육 선택에서 학원별 이용자 의견을 정리할 수 있는지 조사해줘. 코드 구현 없이 docs/research/교육선택-이용자의견-수집검토.md에 결과를 작성해줘.

docs/한눈육아-교육트렌드-구현가능범위.md 및 docs/한눈육아-아이중심-성장기록-교육정보-메뉴시안.md를 읽어라. 목적은 부모가 맘카페를 직접 돌아다니며 비교하는 부담을 줄이는 것이다. 특정 학원을 좋다/최고/아이에게 맞다고 판정하는 작업이 아니다.

1. 성남시 교육기관과 관련해 공개적으로 볼 수 있는 커뮤니티·후기 출처를 확인해라. 출처별 공개/로그인·가입 제한, 공식 API/제휴 경로, 검색 노출과 원문 열람 차이, 이용정책·자동 수집 허용 범위·보관/요약/링크 조건을 확인해라. 검색 결과에 보인다는 이유만으로 자동 수집이 가능하다고 판단하지 마라. 접근 제한 우회나 대량 수집은 하지 마라.
2. 실제 기관명·지점·주소 또는 맥락으로 의견을 연결할 수 있는지 검토해라. 같은 이름의 다른 지점 의견을 섞지 말고 일치가 불분명하면 제외해라. 세션 1의 결과 파일이 있으면 확인된 기관 표본을 사용하고, 없으면 독립 확인한 기관명/주소를 별도 표로 기록해라. 영도와 READ101 판교점은 자동으로 연결하지 마라.
3. 허용 범위가 확인된 공개 원문만 소규모로 검토해라. 숙제량·개별 진도·피드백·수업 분위기·차량·상담 등 주제를 정리해라. 근거가 한 글뿐이면 한 글의 의견이라고 표시하고 반복 특징으로 확대하지 마라. 수집 허용이 불명확하면 조사만 하고 의견 콘텐츠 보관·요약 배포를 진행하지 마라.
4. 원문 URL·게시 시점·확인 시점·실제 이용 주장 여부·중복/재게시·홍보 가능성·상반된 의견·지점 일치 여부를 분리해라. 공개 닉네임이나 아동 개인정보를 보고서에 복사하지 마라. 열람 가능한 글 수와 확인된 독립 작성자 수를 혼동하지 마라.
5. 카드의 요약 문장은 ‘숙제 관리가 꼼꼼하다는 의견이 언급됨’처럼 출처의 의견임을 유지해라. 같은 문장을 뒷받침하는 원문과 기간·건수를 연결할 수 있는지 검증해라. 건수는 실제 열람 검증된 범위만 사용하고 전체 맘카페 대표성·인기도로 해석하지 마라.
6. 수집이 어렵다면 공식정보+원문 검색 연결, 기관 확인 질문, 자발적 이용 후기, 제휴·동의 기반 수집 등 대안을 비교해라. 특정 사이트 정책상 허용 여부는 공식 정책 원문과 확인된 범위로 보고하고 법률 적법성을 단정하지 마라.

최종 결과: 출처별 수집 가능 조건표 / 기관 식별 방법 / 요약 예시와 근거(허용 시) / 현재 불가능한 것 / 사용자 부담이 적은 대안 / 구현 전 정책·법적 검토 항목. 앱의 현재 가상 후기 예시는 실제 후기라는 증거로 쓰지 마라.

## 세션 3 또래 지역 공식 통계

한눈육아 교육정보의 또래·지역 화면에 사용할 KOSIS 사교육 통계를 실제 응답 기준으로 검증해줘. 코드 구현 없이 docs/research/교육정보-KOSIS-실제응답검증.md에 결과를 작성해줘.

기존 docs/한눈육아-교육트렌드-구현가능범위.md와 관련 KOSIS 검증 문서를 먼저 읽어라. 운영키를 받은 사실만으로 데이터 검증 완료로 처리하지 마라. 키를 보고서·URL 출력·로그에 노출하지 마라.

1. 초등학교 사교육비 조사에서 학년별 참여율·시간·비용·교과별 참여 경향을 제공하는 실제 통계표를 찾아라. 기관/표 ID, 공식 설명, 최신 확정 조사연도·갱신일·수정 이력을 확인해라.
2. 실제 요청과 응답을 검증해라. 필요한 권한·파라미터·분류 코드·단위·기간·결측 표기·페이지/응답 제한·호출 제한·이용조건을 확인해라. 비밀키를 제거한 구조 예시를 남겨라. 문서만 확인한 것은 실제 응답 검증과 구분해라.
3. 초3×경기도×영어 같은 교차 조합이 실제 제공되는지 확인해라. 각각 제공되는 통계 항목을 임의로 결합하지 마라. 시도만 있으면 경기도로 표시하며 성남시 평균으로 추정하지 마라.
4. 비용이 전체 학생 평균인지 참여 학생 평균인지, 시간이 주당인지 월당인지, 조사대상·표본·가중치·기간·공교육/방과후/체육 포함 범위를 확인해라. 공개 메타데이터에 없는 값은 미확인으로 남겨라.
5. 화면에서 확인 가능한 수치 표본을 실제 API 응답 및 공식 통계표와 대조해라. 전체 응답 완전성, 모든 분류가 포함됐는지와 단위 일치를 검증해라. 불일치하면 이유를 보고하고 사용 가능으로 분류하지 마라.
6. 수아의 등록 일정 개수와 통계 참여율은 직접 비교할 수 없다. 참여 여부·실제 시간·비용의 어떤 개인 입력이 있어야 비교가 가능한지 최소 입력 계약을 제안해라. 학습 수준·학원 인기·추가 교육 필요성은 통계로 추정하지 마라.

최종 표: 지표 / 표 ID·분류 / 실제 응답 검증 / 지역·학년 단위 / 단위·분모 / 값 대조 / 사용 가능·조건부·불가 / 확인일·출처. 자동 확보 가능, 부모 최소 확인, 현재 비교 불가 항목을 분리해라.

## 결과 취합 기준

세 결과를 받은 후 기관 목록·후기 요약·통계의 실제 확보 수준을 확인하고 구현 범위를 확정합니다. 데이터가 없거나 수집 허용이 미확정이면 가상 예시를 실제 화면으로 옮기지 않습니다. API 이용 가능과 개별 데이터 완전성, 정보 존재와 자동 연동 가능성은 따로 판단합니다. 결제·광고·사업용 계측은 이번 범위에서 제외합니다.
