# 디자인 명세 — 1-3 월령 탭 + 1-5 달력 두 층

- 작성: hn_design, 2026-10-05 / 구현: hn_dev(1-0 actionType 확정 후) / 게이트: hn_pm / 화면 시안 없음
- 결정 근거: D3(정보·관찰형은 달력 칸에서 빼고 목록에만), D6(자동 항목 접기 기본 접힘, 일정형은 항상 보임), D10(완료/전체 개수 대신 '남은 N개' 또는 숨김), 06 §5·§6, docs/agents/dev-note-1-3-5.md(hn_dev 분석)
- **색·모양은 바꾸지 않는다**(캘린더·체크리스트 = 현재 앱 디자인 확정). 이 문서는 **배치·묶음·문구**만 정한다. 새 요소는 기존 클래스(`.ongoing-group-card`, `.event-item`, `.count-badge`, 자동 칩, `.fine-print`)의 모양을 재사용한다.
- 분류 기준은 정책 파일의 actionType 하나다(`curation.json`, 1-0). 미분류 id는 **ACT로 폴백**(지금 동작 유지, dev-note §6-3). 지원금은 지금처럼 별도 경로로 두고 actionType 접기를 적용하지 않는다.

## 0. 두 층 규칙(한 줄)
- **1층 = 날짜가 있는 행동형(ACT·CHECK)**: 달력 칸과 목록 위쪽에 항상 보인다.
- **2층 = 정보·관찰형(KNOW)**: 달력 칸에는 나오지 않고, 목록의 '이 시기 알아두기' 접힘 안에만 나온다(기본 접힘).

## 1. 월령 탭(체크리스트)

### 1-1. 5구분(actionType에서 파생)
| 구분(화면 이름) | actionType | 층 | 기본 상태 |
|---|---|---|---|
| 할 것 | ACT·BOOK / ACT·APPLY / ACT·SCHOOL, CHECK | 1층 | 항상 보임 |
| 곧 준비 | 위와 같은 유형 중 이 그룹 안에서 아직 시작 전(UPCOMING) | 1층 | 항상 보임('할 것' 아래) |
| 관찰 | KNOW·OBSERVE, KNOW·MILESTONE | 2층 | 접힘 안 |
| 해볼 것 | KNOW·TRY, KNOW·INFO | 2층 | 접힘 안 |
| 주의 | KNOW·CAUTION | 2층 | 접힘 안 |

- 1층 묶음 이름은 기존 앱 용어 **'이번 달 챙길 것'**, 안의 구분은 **'할 것 / 곧 준비'**(결정 1). 홈의 '지금 꼭 할 것'(L1~L4만)과 뜻이 달라 '지금 할 것'은 쓰지 않는다.

### 1-2. 그룹 카드(기존 `.month-group-card`) 안 배치
| 순서 | 요소(한국어 이름) | 마크업 단위(제안) | 모양 | 보이는 조건 |
|---|---|---|---|---|
| 0 | 그룹 머리(월령 이름) | 기존 `.ongoing-group-header` | 그대로 | 항상 |
| 0-1 | 개수 배지 | 기존 `.count-badge` | 그대로, **문구만 변경**: 1층 미완료가 있으면 "남은 N개", 없으면 배지 숨김(D10). 2층은 세지 않는다 | 1층 미완료 ≥ 1 |
| 1 | 1층 묶음 머리 '이번 달 챙길 것' + 구분 '할 것' | `.mg-sec-h` | `.fine-print` 크기·회색 글자, 왼쪽 정렬 | 1층 항목 ≥ 1 |
| 2 | 1층 항목 줄 | 기존 `.event-item`(compact) | 그대로 + 아래 '왜 지금' 한 줄 | — |
| 3 | 구분 머리 '곧 준비' + 항목 | `.mg-sec-h` + `.event-item` | 같음. 줄 오른쪽 기존 날짜 자리에 "M월 D일부터" | 해당 항목 ≥ 1 |
| 4 | 접힘 '이 시기 알아두기 N개' | `<details class="mg-know"><summary>` | summary = 기존 `.home-more`(또는 `.chip-all`) 모양 한 줄 "이 시기 알아두기 N개 ›" | 2층 항목 ≥ 1. **기본 접힘**(D6) |
| 4-1 | 접힘 안 구분 머리(관찰·해볼 것·주의) | `.mg-sec-h` | 1과 같음 | 그 구분 항목 ≥ 1 |
| 4-2 | 2층 항목 줄 | `.event-item`(compact) + '왜 지금' 한 줄 | 그대로 | — |
| 4-3 | 주의 '확인했어요' 버튼 | `.mg-ack` | 기존 작은 외곽선 버튼(`.acct-sm-btn` 모양), 줄 오른쪽 | 주의 항목만. 누르면 그 줄은 같은 접힘 맨 아래 **'확인한 것 N개' 접힘**(`<details class="mg-acked">`, 기본 접힘)으로 이동, 그 구간 동안 유지(06 §4, 결정 5) |
| 5 | 빈 그룹 | 기존 `.empty-month-note` | 그대로 "이 달에 새로 챙길 항목은 없어요" | 1층·2층 모두 0 |

- **'왜 지금' 한 줄**(`.ev-why`): 항목 제목 아래, `.fine-print` 크기, 회색, 한 줄 말줄임. 문장은 걸린 규칙/데이터 `why`를 그대로 쓴다(06 §3·§5). 예: "4개월 접종 기간이에요(10월 20일~)", "이번 달 새로 시작하는 관찰 항목이에요". 새 사실은 만들지 않는다.
- KNOW 목록 경로: **`monthlyInMonth` 경로**로 월령 탭 '이 시기 알아두기'에 넣는다(결정 3).
- **이정표(KNOW·MILESTONE)**: '관찰' 안에서 기존 기록 동작('시작했나요?' → 기록) 그대로. 새 버튼은 만들지 않는다.
- **완료 체크**: 1층 = 기존 체크 그대로. 2층 관찰·해볼 것은 체크 대신 줄을 누르면 상세(지금과 같음), 주의는 '확인했어요'.

### 1-3. 미래 그룹 접기
| 그룹 | 기본 상태 |
|---|---|
| 지금 그룹(`data-now`) | 열림, 1층 펼침 · 2층 접힘 |
| 지난 그룹 | 접힘(지금과 같음, `past-infant` 토글 유지) |
| 다음 그룹 1개 | 접힘. 머리에 "곧" 표시 없이 그대로(1층 '곧 준비'가 지금 그룹 안에 이미 나옴) |
| 그 뒤 그룹들 | 접힘. **목록 맨 아래 "나중 시기 N개 그룹 보기 ›" 한 줄로 묶어 숨김**(06 §4 '나중에'는 홈 0, 월령 탭은 접힘) |
| '그때그때 확인해요'·'학교·입학' | 지금 위치·접힘 그대로 |
- 열림 상태 저장: 기존 `openMonthGroups`, 2층 접힘은 기기 저장(dev-note §3, Firestore 변경 없음).

## 2. 달력(캘린더 탭) 두 층

### 2-1. 칸(1층만)
| 항목군(06 §6) | 칸 표시 | 모양 |
|---|---|---|
| 날짜가 필요한 행동형(VX, HC, OR-03·04) | 추천일 칸에 자동 칩 | 기존 자동 칩(옅은 칩+테두리) 그대로 |
| 마감이 있는 신청형(SB, PG, 지역 마감형, SC-03) | **마감일 칸**에 자동 칩(지금은 시작일 칸 — `schedule.js:299-300`) | 기존 자동 칩 + 칩 글자 앞에 "마감 " 두 글자(예: "마감 부모급여", 결정 4: 색이 아니라 글자로도 구분, D17 원칙). 색 변경 없음 |
| 기간이 정해진 학교형(SC-01·02·12~14) | 기간 막대 | 그대로 |
| 직접 입력(USER) | 꽉 찬 칩 | 그대로 |
| 정보·관찰·주의·해볼 것(KNOW) | **칸에 표시하지 않음**(D3) | — |
- 칸당 2개 + `+N` 규칙, `MAX_MARKS` 그대로. 칸 개수가 줄어드는 것은 의도된 변화다(dev-note §5).

### 2-2. 달력 위·아래 목록
| 순서 | 요소 | 지금 | 변경 |
|---|---|---|---|
| 1 | 이번 달 챙길 것(접이식 카드, 달력 위) | "이번 달 챙길 것 11개" — 모든 자동 항목 | **1층만** 목록 + 머리 문구 "이번 달 챙길 것 · 남은 N개"(D10, 0이면 "이번 달 챙길 것"만) |
| 1-1 | (신설) 그 카드 안 맨 아래 접힘 | — | `<details>` "이 시기 알아두기 N개 ›" — 2층 항목(기본 접힘, D6), 목록 출처는 `monthlyInMonth`(결정 3). 줄을 누르면 지금과 같은 상세 |
| 2 | 이번 달 추가 일정(구성원 칩·범례) | "이번 달 추가 일정 2개 (완료 0)" | "(완료 N)" 대신 "남은 N개"(D10). 구성원 칩·범례 문구 **유지** |
| 3 | 달력 | 그대로 | 칸 규칙만 §2-1 |
| 4 | 날짜 패널(하루 목록) | 그날 칸 항목 | 칸과 같은 출처라 1층만. 2층은 나오지 않음 |
| 5 | '직접 등록한 일정만 보기'·'카테고리별 색' 토글 | 유지 | 유지(dev-note §6-4, W0 '삭제 금지'). 문구 그대로 |
- 범례 "꽉 찬 칩은 직접 등록한 일정, 테두리만 있는 칩은 자동 일정이에요."는 그대로 맞다(1층 자동 칩이 남으므로). 수정 없음.

## 3. 앱과의 차이(모두 '이동')
| 지금 | 바뀐 뒤 | 이동처 |
|---|---|---|
| 관찰·생활·주의 자동 항목이 달력 칸에 추천일 칩으로 나옴 | **이동** | 달력 위 '이번 달 챙길 것' 카드 안 '이 시기 알아두기' 접힘, 월령 탭 그룹 카드 안 접힘 |
| 마감형 지원금 칩이 시작일 칸에 | **이동** | 마감일 칸 |
| 월령 탭 그룹 안 모든 항목이 같은 모양으로 한 줄 목록 | **이동**(묶음만 변경) | 1층 '이번 달 챙길 것'(할 것·곧 준비) + 2층 접힘(관찰·해볼 것·주의) |
| 그룹 배지 "완료/전체개" | **이동**(표기 방식) | "남은 N개" 또는 숨김 |
| 달력 '이번 달 추가 일정 N개 (완료 N)' | **이동**(표기 방식) | "남은 N개" |
| 먼 미래 월령 그룹이 목록에 펼쳐진 채 이어짐 | **이동** | 목록 맨 아래 "나중 시기 N개 그룹 보기" 접힘 안 |
| 넓은 기간 관찰·생활 항목의 달마다 반복 노출(`repeatMonthRangeOf`) | **이동** | 각 달 그룹의 2층 접힘 안(완료 공유 그대로) |
