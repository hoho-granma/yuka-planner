# 디자인 명세 — 2-1 붙여넣기 → 일정 후보 확인 화면

- 작성: hn_design, 2026-10-05 / 구현: hn_dev(공통 파서는 서버 없이 기기 안) / 게이트: hn_pm / 화면 시안 없음
- 근거: 방향설계서 §10(해석 → 일정 후보 → 사용자 확인 → 등록, AI·OCR·음성은 날짜를 임의로 확정하지 않음), UX지침 §6, ux-review/00 단계 2-1
- **기존 일정 폼(`.us-*`) 디자인과 클래스를 재사용**한다. 새 색은 없다. '확인 필요' 강조는 앱 기존 규칙(S5: 배경·뱃지 없이 글자만, style.css 1711행)과 선택칸 노랑 선(#f9cb34, 확정 디자인의 '선택·주의' 선)만 쓴다. 글자 뒤 배경색은 쓰지 않는다.

## 1. 흐름
1. 일정 추가 시트 → **'붙여넣기로 추가'**
2. 붙여넣기 입력 → [일정 찾기]
3. 후보 목록(0~N개): 칸마다 해석 결과 또는 **빈칸 + '확인 필요'**
4. 후보별 체크·수정·삭제 → **[N개 등록]**(체크된 것만)
5. 등록 결과는 일반 USER 일정이다(기존 저장 형식, Firestore 변경 없음). **원문은 저장하지 않는다**(결정 2). 원문 보기는 등록 전 확인 화면에서만.

## 2. 진입점
| 위치 | 요소 | 모양 |
|---|---|---|
| 일정 추가 시트 맨 위(제목 `h3` "일정 추가" 바로 아래) | 버튼 줄 **"붙여넣기로 추가"** + 보조 문구 "문자·가정통신문 문장을 붙여 넣으면 일정을 찾아 드려요" | 기존 `.us-chip` 1개(흰 면·선) + `.us-note` |
| 누르면 | 같은 시트 안에서 붙여넣기 화면으로 바뀜(새 시트 아님). 뒤로 = 일반 입력 폼 | — |

## 3. 화면 요소
### 3-1. 붙여넣기 단계
| 요소 | 마크업(제안) | 모양(재사용) | 내용 |
|---|---|---|---|
| 제목 | `h3` | 기존 | "붙여넣기로 추가" |
| 입력칸 | `textarea.us-paste` | 기존 `.rv-textarea`/`.us-field` 입력칸 모양, 최소 5줄 | placeholder "예) 10월 14일(화) 오후 3시 30분 하린 치과 예약입니다" |
| 안내 | `.us-note` | 기존 | "날짜가 분명하지 않으면 비워 두고 확인을 부탁드려요. 붙여 넣은 글은 저장하지 않아요." |
| 버튼 | `.btn-complete`(주요) | 기존 일정 폼 저장 버튼 모양 | "일정 등록" (입력이 비면 비활성) |

### 3-2. 후보 확인 단계
| 요소 | 마크업(제안) | 모양(재사용) | 내용·규칙 |
|---|---|---|---|
| 머리 | `.us-note` | 기존 | "일정 후보 N개를 찾았어요. 맞는지 확인해 주세요." / 0개면 "일정을 찾지 못했어요." + [직접 입력하기] |
| 후보 카드 | `.us-cand`(기존 일정 줄 카드 모양: 흰 면·선 1px·r12) | 기존 `.us-row` 계열 | 카드 1장 = 일정 1개 |
| 체크 | 카드 왼쪽 체크(기존 `.a36-cb` 또는 체크 버튼 모양) | 기존 | 기본 **체크됨**. 단 **날짜가 빈 후보는 체크 해제 + 체크 불가** — 날짜를 넣거나 기존 '날짜 미정(기간)'을 직접 고르면 체크 가능(결정 3) |
| 제목 | 한 줄 | 기존 제목 글자 | 해석한 제목(예: "하린 치과") |
| 날짜·시각 | 한 줄 "10월 14일(화) 오후 3:30" | 기존 | 해석 못 한 칸은 **빈칸 "날짜 선택"** |
| 대상 아이·담당·반복 | 한 줄 칩 요약 "하린 · 담당 미정 · 반복 없음" | 기존 `.us-chip`(작게) | 이름이 문장에 있고 등록된 아이와 정확히 같을 때만 채움. 담당은 항상 비움(문장에서 추측하지 않음) |
| 수정 | 카드 오른쪽 "수정" | 기존 `.us-chip-edit` | 누르면 **기존 일정 폼**(같은 시트, 값이 채워진 상태)으로. 저장하면 후보 목록으로 돌아옴 |
| 삭제 | 카드 오른쪽 "빼기" | 기존 `.us-chip-edit` | 목록에서 뺌(되돌리기 1회: 토스트 "되돌리기") |
| 확인 필요 표시 | 칸 글자 옆 **"확인 필요"**(S5 글자 규칙: 차콜 800, 배경·뱃지 없음) + 그 칸 테두리 **#f9cb34 1.5px** | 기존 S5 + 확정 선택선 | 아래 §4 규칙에 걸린 칸만 |
| 원문 보기 | 카드 아래 접힘 "원문 보기 ›" | `<details>` | 그 후보를 만든 문장 조각(사용자가 대조) |
| 등록 버튼 | `.btn-complete` | 기존 | **"N개 등록"**(체크된 수). 0이면 비활성 |
| 취소 | `.btn-close` | 기존 | "취소" — 아무것도 저장하지 않음 |

## 4. '확인 필요' 규칙(날짜를 임의로 확정하지 않음)
| 해석 상황 | 처리 | 표시 |
|---|---|---|
| 월·일이 모두 있음 | 채움. 연도는 **오늘 이후 가장 가까운 해**(오늘보다 이전이면 다음 해) | 연도를 넘겼으면 "확인 필요" |
| 요일만 있음("다음 주 화요일") | 붙여넣은 날 기준으로 계산해 채움(결정 1) | **항상 "확인 필요"** + 한 줄 "오늘(M/D) 기준 계산"(문자를 받은 날과 다를 수 있음) |
| 요일과 날짜가 서로 안 맞음 | **날짜 빈칸** | "확인 필요 · 요일과 날짜가 달라요" |
| 날짜 없음("다음 달 중") | **빈칸** | "확인 필요" |
| 시각 없음 | 종일 | 표시 없음 |
| "오후/오전" 없이 3시 | 빈칸 아님, **오후 3:00으로 채우지 않고 3:00** + "확인 필요" | — |
| 기간("10/14~10/18") | 시작·끝 채움(기간 일정) | 표시 없음 |
| 반복("매주 화·목") | 반복 칩 채움(매주/2주마다만, 매월은 D5 나중) | 시작일이 없으면 "확인 필요" |
| 아이 이름 없음/모호 | 대상 빈칸 | "확인 필요"(아이가 2명 이상일 때만) |

## 5. 예시 3개(화면 예시 — **예시 문장·결과이며 실제 파서 출력이 아님**)

|---|---|---|---|---|
| 1 | 하린 치과 예약 | 10월 14일(화) 오후 3:30 | 하린 | 없음 |

**예시 B · 유치원 행사 안내(가정통신문)**
> 10월 운영 안내: 10/17(금) 가을 소풍(도시락 지참), 10/24 학부모 상담 주간(개별 시간 추후 안내), 10월 말 할로윈 행사

| 후보 | 제목 | 날짜·시각 | 확인 필요 |
|---|---|---|---|
| 1 | 가을 소풍(도시락) | 10월 17일(금) 종일 | 없음 |
| 2 | 학부모 상담 주간 | 10월 24일 종일 | "확인 필요"(시간 추후 안내 — 원문 보기) |
| 3 | 할로윈 행사 | **빈칸** | "확인 필요"("10월 말"은 날짜가 아님) · 체크 해제 |

**예시 C · 학원 시간표**
> 하준 영어 화·목 4:00~5:00, 11월부터

| 후보 | 제목 | 날짜·시각 | 반복 | 확인 필요 |
|---|---|---|---|---|
| 1 | 하준 영어 | 시작일 11월 첫 화요일(11/3) · 4:00~5:00 | 매주 화·목 | "확인 필요"(시작일 계산, 오전/오후 없음) |
