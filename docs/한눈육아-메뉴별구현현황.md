# 한눈육아 메뉴별 구현 현황 (자녀 1명 기준)

작성 2026-10-12 · 현재 코드 기준이며 실기기 테스트를 새로 진행한 것은 아니다.
육아지기 워크보드 > 자체서비스 > 구현 체크리스트가 이 문서의 표를 읽는다. 표의 **현재 제공**(이미 체크됨)·**보완 필요**·**아직 미제공** 칸이 체크 항목(쉼표로 나눔)이 되므로, 항목을 추가·삭제하려면 표를 고치고 보드를 다시 만든다. 체크 상태는 보드 db에 따로 있다.

자녀 1명 기준으로, 부모가 각 메뉴에서 무엇을 해결할 수 있는지 중심으로 정리했다.

- 현재 제공: 앱에 연결된 기능
- 보완 필요: 제공 중이지만 데이터·정확도·사용 흐름을 더 완성해야 하는 부분
- 아직 미제공: 현재 사용자가 이용할 수 없는 기능

## 서비스 목표

- 우리 아이에게 지금 필요한 것을 먼저 찾아주고, 놓치지 않게 연결해준다.
- 차별점은 기능 수가 아니라 연결이다: 부모의 대표 고민 → 필요한 정보 → 실제 행동·일정(가족 캘린더).
- 최종 형태는 AUTO(자동 일정) + USER(직접 입력) + FAMILY(가족 공유)를 합친 가족 캘린더다.
- 진도율 = (현재 제공 + 완료로 체크한 보완 필요·아직 미제공) ÷ 전체 항목. 항목은 모두 같은 비중으로 센다.

## ① 36개월 미만 — “접종·검진·지원·발달 시기를 놓치지 않고 싶어요”

주요 메뉴는 홈 · 캘린더 · 체크리스트 · 육아 혜택 · 어디갈까입니다.

| 메뉴 | 부모의 이용 시나리오 | 현재 제공 | 보완 필요 | 아직 미제공 |
|---|---|---|---|---|
| 홈 | “우리 아이가 지금 챙겨야 할 게 뭐지?” | 월령에 맞는 챙길 것, 신청 가능한 혜택, 가족 일정·할일 확인 | 여러 항목 중 왜 지금 이것이 중요한지, 무엇부터 해야 하는지 더 명확하게 안내 | 아이 상태·기관·가족 상황을 종합한 대표 고민 자동 정리 |
| 캘린더 | “검진 예약과 가족 약속을 함께 보고 싶어요” | 접종·검진 등 자동 일정과 직접 등록한 가족 일정 통합, 담당자 지정, 반복 일정, 사진·메시지에서 일정 후보 등록 | 자동 일정의 권장 시기와 실제 예약일 관계를 쉽게 이해하도록 보강, 사진 분석·음성 입력의 기기별 정확도 확인 | 일정 알림, 네이버·구글 내보내기, 비공개 일정, 주 보기 |
| 체크리스트 | “이번 시기에 해야 할 일과 이미 한 일을 구분하고 싶어요” | 월령별 접종·검진·발달·식사·안전·생활 항목, 상세 설명, 완료일·해당 없음, 예약·공식 안내 연결, 가족 할일 | ‘해야 할 것’과 ‘알아두면 좋은 것’의 구분, 일부 발달 시기 근거 검증, 완료 후 다음 행동 연결 | 실제 접종·검진 이력의 외부 자동 불러오기 |
| 육아 혜택 | “우리 집이 받을 수 있는 지원을 놓치고 싶지 않아요” | 지역·아이 조건에 맞는 혜택, 신청 가능·예정·완료 구분, 대상·금액·기간·공식 신청 안내, 일정 연결 | 확인필요 자료의 공식 검증, 일부 신청처 보강, 가족 조건에 따른 대상 여부 설명 | 정책 변경 자동 갱신, 실제 신청 여부·처리 결과 조회, 마감 알림 |
| 어디갈까 | “아기와 갈 만한 가까운 곳을 찾고 싶어요” | 지역 기반 장소 목록, 실내·무료·예약·이동시간 필터, 나이 관련 안내, 지도·공식 페이지·방문 일정 등록 | 개별 시설의 공식 이용 연령·운영 정보 확인, 아기 동반에 필요한 시설 정보 보강 | 전국·민간시설의 충분한 목록, 오늘·이번 주말의 운영·예약 가능 여부 자동 확인 |
| 기록 보기 (가족/프로필에서 진입) | “검진이나 아이의 변화를 남겨두고 싶어요” | 완료한 항목의 기록, 직접 메모·사진 기록, 조회·수정 | 기록 종류별 사진 보관·다른 기기 복원 범위를 명확하게 안내 | 영아 기록을 종합한 변화 분석·개인화 리포트 |

이 시나리오의 핵심 보완은 “항목을 보여주기 → 지금 필요한 이유 설명 → 예약·신청 → 실제 일정 확인” 흐름을 더 매끄럽게 만드는 것입니다.

## ② 36개월 이상 — “학교·학원·가족 생활을 관리하면서 아이의 경험을 이해하고 싶어요”

주요 메뉴는 홈 · 캘린더 · 할일 · 교육정보 · 성장기록입니다.
현재 육아 혜택 탭은 숨겨지고, 어디갈까 자리는 성장기록으로 전환됩니다. 다만 접종·검진·취학 등 필수 자동 일정은 계속 유지됩니다.

| 메뉴 | 부모의 이용 시나리오 | 현재 제공 | 보완 필요 | 아직 미제공 |
|---|---|---|---|---|
| 홈 | “오늘 가족 일정과 아이에게 중요한 일을 확인하고 싶어요” | 가족 일정·할일, 놓치기 쉬운 필수 자동 항목, 성장기록 진입 | 3~5세·취학 전·초등 학년별 대표 고민을 더 뚜렷하게 구분하고 다음 준비 안내 강화 | 아이 기록을 근거로 ‘지금 확인할 것’을 자동 정리하는 개인화 요약 |
| 캘린더 | “학교 안내문·학원 시간표를 가족과 공유하고 싶어요” | 직접·반복 일정, 담당·대상 지정, 일정별 색, 사진·메시지 분석 후 여러 후보 확인·등록, 원본 사진 연결 | 복잡한 학사일정의 누락·날짜 해석 정확도, 수정·취소 안내문 처리, 등록된 활동과 성장기록 연결 보강 | 학교·학원 일정 자동 가져오기, 변경 사항 자동 반영, 알림·외부 캘린더 연동 |
| 할일 | “준비물·숙제·가족이 할 일을 잊지 않고 싶어요” | 가족 할일 등록·수정·완료, 기한·담당·대상, 홈에서 확인, 필수 시기성 항목 안내 | 안내문에서 일정과 준비할 일을 구분해 등록하는 흐름, 완료 이후 기록·후속 행동 연결 | 학교 숙제·준비물 자동 수신, 기한 알림 |
| 교육정보 | “또래는 어떻게 하고 있고, 어떤 기관을 비교하면 좋을까요?” | 공식 참여·비용 통계, 성남시 기관 탐색, 관심 저장·기관 비교, 공개 교습비, 일부 후기 근거, 공공 프로그램, 상담·방문 일정 연결 | 연령·학년별 선택 기준, 성남시 밖의 자료, 교습비 비교 단위, 후기의 지점·시점 확인, 관심 목록 기기 간 공유 | 우리 동네 동일 학년의 익명 이용 통계, 전국 기관 탐색, 아이에게 맞는 기관 자동 추천 |
| 성장기록 — 활동 기록 | “학교·학원에서 받은 사진과 선생님 메시지를 모아보고 싶어요” | 아이 중심 활동 나무, 활동별 날짜 기록·사진·메모, 등록 학원 일정 연결, 서버 저장·첨부 조회·기기 이전 | 실제 경험일과 메시지 수신일 구분, 출처·활동·같은 경험 연결을 쉽게 입력하는 화면, 동기화 실기기 확인 | 기록을 읽고 자동으로 관찰 특징을 추출하는 분석 |
| 성장기록 — 현재 상태 확인 | “학교에서 배운 내용을 아이가 이해했는지 살펴보고 싶어요” | 초3 참고 문항·문제지 인쇄·결과 기록, 학기별 배우는 내용 연결 | 교사 검토, 교과서·학기 진도 대응, 답변과 도움 조건의 구조화 | 전 학년 점검, 검증된 수준 진단, 자동 채점·해석 |

36개월 이상은 한 묶음으로 판단하면 안 됩니다.

| 아이 상황 | 현재 활용 가능한 중심 기능 | 특히 보완할 부분 |

| 3~5세 | 가족 일정·할일, 활동 기록, 지역 기관·프로그램 탐색 | 놀이·언어·사회적 경험과 기관 선택 안내. 초등 문항을 적용하지 않기 |

현재 구조에서 눈에 띄는 보완점은 36개월이 되면 혜택·어디갈까의 직접 진입이 사라진다는 점입니다. 이 나이에도 지원·체험 수요가 있으므로, 교육정보나 홈에서 관련 혜택·활동으로 이어지는 경로를 검토할 필요가 있습니다.

여러 자녀 등록·전환 기능은 코드에 있지만, 여러 자녀의 연령이 섞였을 때 메뉴·자동 일정·기록·가족 공유가 맞게 동작하는지는 이번 평가에서 제외하고 추후 테스트로 남깁니다.
