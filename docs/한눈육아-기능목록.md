# 한눈육아 기능 목록 (코드 기준)

기준: 앱 버전 1.12.63 · 2026-10-03 · `js/`·`index.html`·`sw.js`·`firestore.rules`·`data/`를 직접 확인한 것만 적었다(추측·기억 기반 내용 없음). 실서버·실기기 동작은 확인하지 않았다(자동 테스트 68개 파일은 통과).

**읽는 법**
- **OFF**: 플래그가 모두 꺼진 기본 상태(`js/feature-flags.js` 기본값 전부 꺼짐)에서도 보이는가. ○ = 보임, × = 안 보임(계정·가족 캘린더 기능을 켠 기기에서만).
- **켜는 법**: 첫 화면의 "새 버전 미리 써 보기(베타)" 카드, 또는 유효한 초대 링크로 들어오면 `hannun_feature_household`·`hannun_feature_accounts`가 이 기기에 켜진다. (accounts 를 켜면 household·autoLink 도 함께 켜진다.)
- **데이터 위치**: `local` = 기기 localStorage · `families` = Firestore `families/{아이 기록 코드}`(아이 프로필·완료·기록) · `households` = Firestore `households/{id}`(가구·아이 링크·구성원·일정)와 `householdCodes` · `accounts` = Firestore `accounts/{uid}` · `정적` = 앱에 들어 있는 JSON 파일 · `Auth` = Firebase Auth.
