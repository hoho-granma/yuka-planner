## 4. 하지 않는 것
- 구성원 색·카테고리 색 변경(사람·분류 정보, 카테고리는 사용자 선택 대기).
- 캘린더·체크리스트·혜택 탭 본문, 하단 탭 모양(단계 4 사용자 결정 범위).
- 글자에 배경 깔기(형광펜) — 선택 상태는 칩 면으로만.

## 5. 결정 필요
1. 상세 시트 면: 흰색 유지(권장, 읽는 화면) vs #f0f1ff(입력 시트와 통일).
2. 단계 '완료' 색: 인디고(권장, 진행 점 규칙과 같음) vs 초록 유지(완료 = 초록이라는 익숙함).
3. 착수 순서: 일정 시트 → 상세 시트 → 프로필 시트(자주 여는 순, QA 준비 문서와 같음).
