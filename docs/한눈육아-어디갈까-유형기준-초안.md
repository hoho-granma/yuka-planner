## 2. 반영 방식
- 공식 값(places.json ageMonths)과 구분한다: 공식 값이 없는 곳에만 '시설 유형 기준' 라벨로 안내하고 나이 필터 제외 기준으로 쓰지 않는다(정렬 감점·안내 문구만).
- ageMonths에 넣지 않은 이유: 스키마상 공식 표기 칸이고, places.js validatePlace가 정의되지 않은 필드를 거절한다. 화면 표시는 hn_dev가 기준표 파일을 읽는 코드가 필요하다.
