- 색·모양은 기존 캘린더·홈 디자인을 그대로 쓴다. 새 색은 없다.

## 1. 범위
| 포함 | 제외 |
|---|---|
| 등록된 **아이**(출생 완료)의 100일·돌·매년 생일 | 가족 구성원(엄마·아빠 등) 생일, 음력 생일, 임신 중 아이(예정일은 생일이 아님) |
| 계산해서 보여 주기만 함 | Firestore·기기 일정 저장, 알림(E 트랙) |

## 2. 계산식(날짜를 추측하지 않는다)
출생일 `B` = `profile.birthDate`(아이별). 날짜는 기기 현지 날짜 기준, 시간 없음(종일).

| 일정 | 계산 | 예(B = 2026-06-20) | 횟수 |
|---|---|---|---|
| 100일 | **B + 99일**(출생일을 1일째로 센다. 앱의 "출생 후 N일 이내 = 출생일+(N−1)일" 규칙과 같음, app.js 570행) | 2026-09-27 | 1회 |
| 돌 | **B의 1년 뒤 같은 월·일** | 2027-06-20 | 1회 |
| 생일 | **매년 B와 같은 월·일**(2년째부터. 1년째는 '돌'로 표시) | 2028-06-20, 2029-06-20 … | 매년 |

- **2월 29일생**: 평년에는 **2월 28일**에 표시하고, 날짜 패널 줄 아래에 "2월 29일생 · 평년은 2월 28일로 표시" 한 줄을 넣는다(계산 규칙을 밝힘, 결정 1).
- 표시 기간: 100일·돌은 지난 날짜도 달력에서 그날 칸에 보인다(기록처럼). 생일은 앱 대상 연령(초등 범위) 안에서 매년. 별도 끝 규칙을 만들지 않는다.
- 나이 표기는 하지 않는다("3번째 생일"·"N세" 없음). 세는 나이·만 나이가 섞이는 혼동을 피하기 위해서다.

## 3. 어디에 어떻게 보이나
| 위치 | 표시 | 모양(기존 재사용) | 출처 라벨 |
|---|---|---|---|
| 가족 캘린더 칸 | 그날 칸에 칩 1개: "하린 100일" / "하린 돌" / "하린 생일" | **자동 칩**(옅은 칩+테두리), 색 = 그 아이의 구성원 색. 칸당 2개+`+N` 규칙에 포함 | 칩에는 라벨 없음(범례가 '테두리 = 자동'을 이미 말함) |
| 날짜 패널(하루 목록) | 줄 1개: 제목 + 아래 회색 한 줄 | 기존 자동 항목 줄 | **"자동 계산 · 출생일 기준"** |
| 홈 '이번 주 · 우리 가족 일정'(7일 안) | 일정 줄 1개: "하린 생일 · 토" | 기존 일정 줄, 막대 = 아이 색 | 줄 끝 회색 작은 글자 **"자동"** |
| 홈 '지금 꼭 할 것'·'곧' | 나오지 않음 | — | 행동이 필요한 일이 아니다(06 슬롯 대상 아님) |
| 월령 탭·'남은 N개'·진행률 | 나오지 않음, 세지 않음 | — | 완료할 일이 아니다 |

- **누르면**(달력 칸·패널·홈 줄 공통): 작은 상세 시트
  - 제목 "하린 생일" + 날짜
  - 한 줄 "출생일(2026년 6월 20일)로 계산한 날이에요. 저장되지 않아요."
  - 버튼 1: **"이 날 일정 추가"** → 기존 일정 추가 시트를 날짜만 채워서 연다(예: 생일 파티). 만든 일정은 일반 USER 일정이다.
  - 버튼 2: **"생일·기념일 끄기"** → §4 스위치와 같음
- '직접 등록한 일정만 보기'를 켜면 다른 자동 칩처럼 숨는다.
- 같은 날 다른 종류의 USER 일정이 있으면 합치지 않고 둘 다 보인다. 같은 아이·같은 종류(생일/돌/100일)의 직접 일정이면 자동 칩을 숨긴다(§5).
