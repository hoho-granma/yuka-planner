# E0 '챙길 것'과 '일정'의 분리 — 계획 (코드 전, 가족 캘린더 활성 사용자만)

원칙: **챙길 것**=기한 안에 하면 되는 자동(AUTO) 항목(접종·검진·지원금), **일정**=날짜·담당이 정해진 것(직접 등록·예약). 둘은 **예약**(autoLink, 기존 C2)으로 잇는다. 범위는 `usActive()`(가구 활성)일 때만. 플래그 OFF·가구 없음 화면·체크리스트 탭은 불변(E5: 체크리스트 달성률 유지).

## 기존 테스트 영향
- E2: d3-accounts(기본 선택 [MEMBER:me] 기대), d4 일부(usSel stub) — 기대값을 []로 갱신. cal-chip/f2-week-view는 `usSel()` 문자열 고정 테스트라 소폭 갱신.
- E1: c2b1·c2b2는 autoLinkOn 조건 테스트라 '기본값 ON'만 맞춰 갱신(flag OFF 불변 테스트는 유지), f1(홈 카드)·cal-overflow는 영향 없음. 달성률 카드 숨김은 가구 활성일 때만이라 기존 cal progress 테스트(OFF) 불변.
- E3: f1-home-upcoming(홈 카드 마크업)은 순서만 바뀌므로 카드 내용 테스트는 유지, 순서 테스트 신규.
- E4: QUICK_TEMPLATES 개수·키를 보는 f3 테스트 갱신.

## autoLink 기본 ON 제안
`FEATURES.autoLink` 기본값을 `household && localStorage.hannun_feature_autolink !== "0"`으로: 가구 켜짐이면 ON, `"0"`이면 끄는 override. 규칙 배포·수동 검증 PASS 완료 전제. 가구 없는 기기는 영향 없음(autoLinkOn은 usActive 조건).

## 사용자 결정이 꼭 필요한 것
1. **autoLink 기본 ON 전환**(위 제안대로 해도 되는지).
2. 36개월 이상 캘린더 기본을 주 보기로 할지 — **의견: 기본 월 보기 유지 추천**(주 보기는 일정 위주 가정, 접종·혜택 같은 챙길 것은 월 단위로 훑는 편이 자연스럽고, 홈에서 '이번 주 우리 가족'이 이미 주 단위를 맡음). 제안만, 구현 없음.
3. '이번 달 챙길 것'의 범위: 이번 달에 걸친 자동 항목 전부 vs 마감 임박 우선 N개(제안: 전부, 마감 빠른 순, 완료는 접힘 아래).
