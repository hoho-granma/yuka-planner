## 1. 방향설계서 §15의 6요소와 지금 B의 대응
| §15 요소 | 지금 B 홈 | 차이 |
|---|---|---|
| ① 지금 우리 아이에게 중요한 것 | '지금 꼭 할 것'(L1~L4 행동) + '이 시기 알아두기' 대표 1 | 3세 이상의 '대표 고민'(교육·취학 등)은 데이터가 없어 비어 있음(06 §7 공백). 홈이 "지금 중요한 게 뭐지?"에 답하는 정도는 0~35개월이 가장 높음 |
| ② 이번 달 챙길 것 | 홈에서 **이동**(체크리스트 탭 '이번 달 챙길 것'), 홈에는 요약 안 둠(D16) | 의도된 차이. 4-1에서 "홈에서 이번 달 전체로 가는 길"(링크 한 줄)을 둘지 결정 |
| ③ 가족 일정 | '이번 주 · 우리 가족 일정'(7일) | 같음. 생일·100일·돌(2-5)은 홈 가족 일정에 아직 안 나옴(미연결) |
| ④ 곧 다가오는 것 | '곧' 배너(사용자 지정 6색) | 같음 |
| ⑤ 다음 단계 안내 | 남색 배너 1개 + 시트('무엇이 달라지나' 카드) | 같음 |
| ⑥ 어디갈까·교육·탐색 | 탐색 한 줄 2칸(조건부) | 3~5세·초등의 교육 탭 진입 칸이 있는지 최종 확인 필요 |

## 3. 4-1에서 사용자에게 물을 것(후보, ★ 권장)
1. **하단 탭 모양**: 알약형(시안 B) / 앱 기존 막대형. ★ 기존 막대형 유지(전체 통일 단계에서 탭 5곳과 같이 판단).
2. **'이번 달 챙길 것' 길**: 홈 아래 링크 한 줄("이번 달 챙길 것 전체 ›" → 체크리스트) 두기 / 두지 않기. ★ 두기(§15 ②를 홈에서 잃지 않게, 개수 요약은 아님).
3. **탐색 줄**: 어디갈까만 / 어디갈까 + 교육(3세 이상). ★ 어디갈까 + 교육(D2 결정과 맞춤, 임신 중엔 어디갈까 숨김 D8).
4. **카테고리 칩 색**: 보류 중인 3안 — 홈에서는 카테고리 줄이 사라져 **체크리스트·달력에만 영향**. ★ 4-2 시트 통일이 끝난 뒤 한 번에 묻기.
5. **통일 순서**: 시트 3종(완료) → 시트 밖 3곳(명세 완료) → 탭 머리(캘린더·체크리스트·혜택 + 버튼·버전 칩) → 탭 본문. 탭 머리·본문은 '현재 디자인 유지' 결정이라 **사용자 재확인 필요**.
