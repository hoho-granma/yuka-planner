## 조사 2: 시군구×학년 정적 파일로 현실적인 것 = 1번(KESS) + 2번(학교알리미)
- 확보: KESS 유초중등 데이터셋 연도 파일, 또는 학교알리미 "학사/학생 > 학년별학급별 학생수" CSV를 받아 학교 행을 시군구로 묶어 학년별 학생수·학급당 학생수 JSON을 만든다. 카드에 출처·기준일 표기.
- 개인정보: 학교 단위 집계 통계라 식별 정보는 없지만, 학생 수가 아주 적은 학년·학교는 소규모 셀이라 합치거나 가리는 규칙이 필요하다.
- 표본: 위 두 파일은 전수 공시·조사라 표본 문제 없음. 사교육비조사는 표본조사(2025년 약 3,000여 학급·7.4만여 명)이고 공표 단위가 시도라 시군구×학년 카드에는 쓰지 말고 시도 평균 참고용으로만.
- 최신성: KESS는 연 1회(8월경 발표), 학교알리미 정시공시는 연 4회. 최신 연도 파일 위치(KESS 2026년분 공개 여부, 학교알리미 파일명 20230531 표기 등)는 추가검증 필요.
- 라이선스: 학교알리미 파일은 제1유형(출처표시)이라 집계 가공해 쓰는 쪽이 안전. API는 제3유형(변경금지)이라 가공이 걸리는지 추가검증 필요.
- 학교 서열화 우려 문구가 제공 페이지에 있으므로 학업성취·학교폭력 등은 카드에 쓰지 않는 편이 안전.

- KESS 2026년 기준 공개 여부와 최신 파일 연도
