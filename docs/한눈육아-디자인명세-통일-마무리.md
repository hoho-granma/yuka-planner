## ② 가구 있는 계정의 '가족 추가 +' 원 인디고 1.5px
- 대상: `js/account-view.js` 415행 `.acct-face.acct-face-add > .acct-face-dot`(계정 + 가구 코드가 있을 때만 그려짐 — 그래서 가구 없는 hn_test 계정에서는 안 보임).
- 현재 CSS(style.css 1258~1259행): `.acct-face-add .acct-face-dot { background:#fff; color:var(--accent-dark); box-shadow:0 0 0 1.5px var(--accent-dark); font-size:22px }`, 이름 글자도 `color: var(--accent-dark)`.
- v1.12.107 패치가 프로필 시트 범위에서 `--accent-dark: var(--nd-indigo)`를 이미 다시 정의했다(`.modal-panel:has(.acct-prof-head) { --accent: …; --accent-dark: var(--nd-indigo); … }`). 따라서 **원 선(1.5px)·+ 글자·'가족 추가' 이름이 프로필 시트 안에서는 자동으로 인디고**가 된다. **추가 CSS 필요 없음.**
- 해야 할 일: **검증만**. 가구 있는 계정(가족코드 있음)에서 프로필 시트를 열어 `.acct-face-add .acct-face-dot`의 computed `box-shadow`가 `rgb(74, 69, 200) 0px 0px 0px 1.5px`, `color`가 rgb(74,69,200)인지 확인(hn_test, 캡처 1장 또는 DOM 값).
- 만약 값이 다르면(다른 위치에서 같은 컴포넌트를 쓰는 경우) 명시 규칙을 추가한다: `.modal-panel:has(.acct-prof-head) .acct-face-add .acct-face-dot { box-shadow: 0 0 0 1.5px var(--nd-indigo); color: var(--nd-indigo); }`.
