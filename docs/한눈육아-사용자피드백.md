# 한눈육아 사용자 피드백

사용자 피드백을 모아 두는 체크리스트. 체크하지 않은 항목은 미해결이며, 반영과 확인을 마친 뒤 체크하고 완료일·결과를 기록한다.

## 피드백 체크리스트

- [ ] **FB-001 · 창·메뉴 전환 애니메이션** — 창을 열고 닫거나 메뉴를 전환할 때 자연스러운 애니메이션이 추가되면 좋겠다. (등록: 2026-10-08)
- [ ] **FB-002 · 가족코드 관련 로직 점검** — 가족코드만 알면 다른 사람도 개인정보(일정, 상태)를 취득할 수 있다는 우려가 있다. 가족코드 관련 로직과 정보 접근 권한을 더 점검했으면 좋겠다. 실제 접근 가능 여부는 점검이 필요하다. (등록: 2026-10-08)
- [ ] **FB-003 · 작은 글씨 가독성 개선** — 일부 화면에서 글씨가 너무 작아 보기 불편하다. 해당 화면의 글씨 크기와 가독성을 개선했으면 좋겠다. (등록: 2026-10-08)
- [ ] **FB-004 · 일정 시간 입력 개선** — 일정의 시간 입력이 오전/오후로 나뉘어 있어 불편하다. 시간을 더 편하게 입력할 수 있도록 개선했으면 좋겠다. (등록: 2026-10-08)
- [ ] **FB-005 · 네이버·구글 캘린더 내보내기** — 추후 일정을 네이버/구글 캘린더로 내보내 해당 캘린더에 등록할 수 있으면 좋겠다. 관련 기능과 안내를 기존 사용 UI에 자연스럽게 추가했으면 좋겠다. (등록: 2026-10-08)

## 기록 규칙

- 사용자가 “피드백에 넣어줘”라고 요청하면 이 문서에 미체크 항목으로 추가한다.
- 항목에는 고유 ID(`FB-001`부터 순차 부여), 피드백 내용, 등록일을 기록한다.
- 같은 내용이 이미 있으면 중복 항목 대신 기존 항목에 추가 맥락을 기록한다.
- 피드백 등록은 구현 완료를 의미하지 않는다. 반영과 확인이 끝나기 전에는 체크하지 않는다.
- 사용자의 우려나 제안은 확인된 결함과 구분하여 기록한다.


## 2026-10-08 개발 진행 — FB-001 / FB-004

- FB-001: 모달 열기/닫기에 160ms 페이드·이동, 메뉴 전환에 160ms 페이드·이동을 추가했다. 기존 모달 상태/저장 흐름을 바꾸지 않는다. prefers-reduced-motion에서는 효과를 끈다. 모달 닫힘 효과는 CSS discrete display transition 지원 브라우저에서 적용되고 미지원 브라우저는 기존 즉시 닫힘으로 동작한다.
- FB-004: 오전/오후 휠 대신 시작/끝의 24시간 시·분 선택을 제공한다. 00~23시, 00~59분을 선택하고 HH:MM으로 저장한다. 선택 분을 15분 단위로 반올림하지 않는다. 시작 변경 시 기존 길이를 유지하고 끝이 시작보다 빠르면 기존 값을 유지하며 경고한다. 자정 이후로 넘어가는 범위는 자동 생성하지 않는다. 기존 종일/시간 저장 버튼은 유지한다.
- 코드/폼 연결 회귀와 새 시·분 선택 합성 이벤트·분 보존·자정 경계 검증을 수행했다. 실기기 UI 확인·배포는 아직 하지 않았으므로 체크리스트는 미완료 상태를 유지한다.
- 기존 성장기록/교육정보 미커밋 작업은 보존했다. 이번 FB-001/FB-004 변경은 사용자 요청으로 커밋한다. push·배포 및 운영 규칙 변경은 하지 않는다.
