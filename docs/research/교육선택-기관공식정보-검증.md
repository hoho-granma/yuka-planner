# 교육 선택 — 성남시 기관 공식정보 검증

확인일: 2026-10-08. 세션 1. 조사 중간 검색은 웹 검색 도구, 이후 공식 원문 및 실제 샘플 확인은 사용자 요청에 따라 Aside 브라우저로 수행했다. 운영 인증키를 사용하지 않았으며 기관 연락·신청·메시지 전송은 하지 않았다.

## 범위와 판정

성남시 전체를 검색하고 도로명주소로 분당구·수정구·중원구를 구분한다. 생활권 기본값·아이 주소·학교 위치를 수집하지 않는다. 국제초 초3의 진도·영어 레벨·기관 적합도를 추정하지 않는다. 아래 표본은 순위나 대표 표본이 아니다. 없다는 표현은 이번 공개 확인에서 확보하지 못했다는 뜻이다.

나이스 **키 없는 성남시 샘플 정상 응답**과 **Sheet의 실제 등록 행**은 확인했다. 운영키 전체 페이지·완전성·최신성 검증은 수행하지 않았으므로 기존 운영 연동 보류를 유지한다. 기관 자체 등록번호 표기는 교육청 원문 대조와 별개다.

## 응답 필드와 분야 분류

기관 식별: `ATPT_OFCDC_SC_CODE + ACA_ASNUM`. 이름 `ACA_NM`, 유형 `ACA_INSTI_SC_NM`, 등록상태 `REG_STTUS_NM`, 등록일 `REG_YMD`, 개설일 `ESTBL_YMD`, 휴원 `CAA_BEGIN_YMD/CAA_END_YMD`, 주소 `FA_RDNMA/FA_RDNDA`, 우편 `FA_RDNZC`, 전화 `FA_TELNO`, 연계일 `LOAD_DTM`을 명세에서 확인했다.

분류는 `REALM_SC_NM`(분야), `LE_ORD_NM`(계열), `LE_CRSE_NM`(과정), `LE_CRSE_LIST_NM`(과정목록)으로 나뉜다. 비용은 `PSNBY_THCC_CNTNT` 문자열과 `THCC_OTHBC_YN`이다. 학년·요일별 시각·차량·무료체험을 보장하는 전용 필드는 명세에 없다.
