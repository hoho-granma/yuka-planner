# 교육정보 KOSIS 실제 응답 검증

확인일: 2026-10-08. 세션 3, 또래·지역 공식 통계. 공개 웹 검증은 Aside 브라우저로 수행했다. 앱 코드·공통 설계·운영 데이터·규칙은 수정하지 않았다.

## 1. 결론과 검증 수준

**공식 웹 표와 조사 정의 검증은 진행했으나, 이번 세션의 발급키 대상 정상 응답·전체 셀 검증은 미완료다.** Aside의 KOSIS 공유서비스는 로그아웃 상태였고 ONE-ID 로그인 화면까지 확인했다. 사용자에게 로그인 요청을 전달했다. 기존 운영키 발급을 취소하거나 미발급으로 되돌려 해석하지 않는다. 키를 확보한 사실과 데이터 검증 완료를 분리한다.

기존 `docs/한눈육아-교육상태판단-교육및API검증.md` §6.6에는 2026-10-07 발급키로 4개 표의 제한 JSON 조회 성공, 발급일 2026-10-07·만료일 2028-10-07이 기록돼 있다. 이번에는 그 기록의 6개 수치를 현재 공식 웹 표와 표시 정밀도로 대조했다. 원본 응답을 재수집한 것은 아니므로 **기존 관찰값 대조**로 표시한다. 신규 경기도 초3·영어 셀을 정상 API 응답으로 확보했다고 주장하지 않는다.

| 구분 | 현재 판정 |
|---|---|

| 즉시 자동 연동 가능 | 없음. 발급키 정상 응답 재조회·전체 셀/주석 검증 전 |

## 5. 실제 요청·응답과 대조

이번 직접 호출은 **비밀키를 생략한 인증 오류 확인 1건**이다. G의 공식 API를 Aside의 동일 출처 GET으로 요청했다. 인증을 우회하거나 예제키로 대체하지 않았다.

```text
GET https://kosis.kr/openapi/Param/statisticsParameterData.do
method=getList
orgId=101
tblId=DT_1PE107_1
objL1=31
itmId=T04
prdSe=Y
startPrdDe=2025
endPrdDe=2025
format=json
smblChk=Y
apiKey: 생략

관찰 응답: HTTP 200
Content-Type: text/html;charset=UTF-8
본문: {err:"10",errMsg:"인증 KEY값이 누락되었습니다."}
```

본문은 strict JSON이 아니다. HTTP 200을 정상 배열 조회로 간주하거나 오류를 0·빈 자료로 치환하면 안 된다. 실제 키를 포함한 요청 URL, 키 값, 로그인 반환 토큰은 파일·로그에 남기지 않았다.

정상 요청의 **구조 예시**는 위 요청에 비공개 서버 메모리에서 `apiKey`를 추가하는 것이다. 이번 정상 요청 실행 결과가 아니다. P의 전국+시도 전체 `objL1=ALL`, `itmId=ALL`, 한 조사연도 선택은 운영키 접근 후 별도 검증한다. 매번 같은 연도/항목/지역을 고정해서 공식 화면과 대조하며, `newEstPrdCnt=1`을 쓸 때도 응답 연도가 2025인지 확인해야 한다.

이전 제한 조회에서 확인한 정상 출력 필드는 ORG_ID, TBL_ID, TBL_NM, C1, C1_OBJ_NM, C1_NM, ITM_ID, ITM_NM, UNIT_NM, PRD_DE, PRD_SE, DT, LST_CHN_DE이다. 다음은 **이전 기록에 근거한 일부 필드 구조 예시**이며 원본 JSON 복사본은 아니다.

```json
[
  {
    "ORG_ID": "101",
    "TBL_ID": "DT_1PE107_1",
    "C1": "00",
    "ITM_ID": "T02",
    "UNIT_NM": "%",
    "PRD_DE": "2025",
    "PRD_SE": "A",
    "DT": "83.9275",
    "LST_CHN_DE": "2026-01-21"
  }
]
```

요청 주기 Y와 기존 반환 PRD_SE=A는 동일 문자열이 아니었다. 수치는 문자열과 원래 소수 자릿수를 보존하고 표시만 공식 표의 소수 1자리로 반올림한다.

| 표·동일 셀(2025) | 기존 2026-10-07 API 관찰 DT | 이번 웹 표시 | 표시 반올림 대조 | 한계 |
|---|---:|---:|---|---|
| P 전국 초1 | 83.9275 | 83.9% | 일치 | 이번 정상 재조회 아님 |
| P 전국 초2 | 86.45997 | 86.5% | 일치 | 동일 |
| C 전국 초1 | 35.15435 | 35.2만원 | 일치 | 동일 |
| C 전국 초2 | 38.83892 | 38.8만원 | 일치 | 동일 |
| H 전체·초등 | 7.4029 | 7.4시간 | 일치, B PDF 9쪽도 일치 | 동일 |
| S 사교육 참여·초등 | 84.43935 | 84.4% | 일치, B PDF 9쪽도 일치 | 동일 |
| S 대상분포·초등 | 46.76656 | 46.8% | 일치 | 참여율 지표로 사용 불가 |

위 6개 지표 셀+대상분포 1개는 표시 자릿수 일치이고 원본의 모든 소수 자릿수 일치 검증은 아니다. 경기도 초3, CP, 신규 교과별 값은 **웹 값만 확인**했으므로 실제 응답 검증 완료 지표로 분류하지 않는다.

S 웹 초등 표본: 총 참여 84.4%, 일반교과 56.9%, 국어 20.3%, 영어 46.8%, 수학 44.8%, 사회·과학 8.9%, 논술 15.5%, 예체능·취미·교양 70.8%, 음악 29.0%, 미술 16.6%, 체육 50.8%, 취미·교양 7.0%. 각각 전국 초등 전체학생 기준 참고이며 특정 학년·지역·기관의 선택률이 아니다.

### 전체 응답 완전성: 남은 필수 검증

웹 P/C/CP는 각각 18지역×7학년 항목=126셀을 2025 화면에 표시한다. S는 29분류×5학교급=145셀을 표시한다. 이 수는 화면/선택 UI 구조의 기대 셀 수이며 API 실수신 행수가 아니다. H의 특성 전체 목록/API 행수, 모든 연도 전체 셀, 결측부호, 중복 셀·누락 코드·모든 단위의 일치는 미검증이다. S의 초등 항목만 요청하면 기대 29행이지만 아직 수신 확인하지 않았다.

발급키 접근 후 각 표에서 (표ID, 연도, C1, 항목)의 유일 키로 배열을 검사하고 UI 전체 코드 집합과 대조해야 한다. `ALL`이 상위 집계만 포함하는지 하위 분류도 포함하는지 실제 코드 집합으로 판단한다. 웹 표 표본 셀과 요청을 동일하게 고정해 대조하고, 불일치·누락·연도 차이가 있으면 해당 지표 사용을 보류한다. 처음 확인한 4개 표 외 CP/참여학생 시간 후보도 별도로 통과해야 한다.

## 8. 부모 최소 입력 계약과 화면 사용

공식 통계만 보기 위해 교육비나 일정 전체를 입력하게 하지 않는다. 기존 프로필의 **아이 귀속·실제 학년·시도**를 재사용하고 부모가 확인/정정한다. 생년월일만으로 학년을 확정하지 않으며 국제초라는 이유로 진도를 추정하지 않는다. 성남시 거주를 재사용해 시도=경기도로 연결할 수 있으나 제목은 반드시 ‘경기도 초3’로 표시한다. 주소·학교 위치·부모 학력·소득은 기본 입력으로 요구하지 않는다.

| 목적 | 부모 최소 확인 | 표시 계약 |
|---|---|---|
| 참여율 참고 | 실제 학년·시도. 개인 표시를 원할 때만 기준기간의 유료 사교육 참여 여부: 예/아니오/모름 | 한 아이의 참여 여부와 집단 참여율을 병기. 개인 ‘참여율’이나 백분위로 변환 안 함 |
| 교과 참고 | 전국 초등 전체라는 범위 확인. 개인 연결을 원하면 해당 교과 실제 유료 참여 여부 | 영어/수학 등 중복 허용. 등록 일정 개수로 참여 교과를 확정하지 않음 |
| 시간 비교 | 아이 1명, 기준기간/평소 주, 실제 참여한 사교육 수업시간 합계(분), 모든 대상활동 포함 확인. 미참여=0, 불명=미확인 | 시간으로 변환해 전국 초등 전체학생 주당 평균과 비교. 이동·숙제·독학·정규/방과후는 별도. 적정량 판단 금지 |
| 비용 비교 | 아이 1명, 기준월, 해당 월 실제 지출 총액(원, 교재비 포함), 전 활동 포함 여부, 사교육 참여 여부 | 전체학생/참여학생 평균 선택을 명확히 표시. 참여 여부 불명일 때 참여학생 기준 자동 선택 금지. 여러 달 선납·형제 공동비용은 월/아이 귀속 확인 전 비교 보류 |
