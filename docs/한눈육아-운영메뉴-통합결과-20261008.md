# 성장기록·교육정보 운영 메뉴 통합 결과

2026-10-08. 이번 작업은 로컬 운영 코드 통합이다. 사용자 요청에 따라 운영 메뉴 통합 코드와 관련 테스트를 커밋한다. push·운영 배포·Firestore 규칙 배포는 진행하지 않는다.

## 반영
- 운영 `growth-body`는 기존 GrowthRecords와 저장 백엔드를 유지하고 GrowthLearningView가 한 나무 화면에 연결한다.
- 활동기록은 처음 접힘. 같은 잎을 다시 누르거나 상세보기 버튼을 누르면 접기/펼치기 된다. 기존 활동 필터·수정·사진·기기 기록 이전은 유지한다.
- 현재 상태 확인은 별도 탭 없이 펼친다. 과목, 학년/학기 참고 표시, 기존 답안 기록, 문제지 보기/인쇄·결과 등록을 연결한다.
- 준비된 문항은 초3 참고용만 제공하고 다른 학년에는 문항 미준비를 안내한다. 공립 3~4학년군 부분 문항이며 학기별 대응·교사 검토 미완료를 접힌 안내에 명시한다.
- 인쇄 화면은 기존 문항 은행의 과목별 참고 문항 6개만 표시하며 정답·부모 판단 기준·기초 문항을 아이용 문제지에 노출하지 않는다.
- 결과 등록은 기존 성장기록 편집기에서 과목별 활동명·제목을 미리 채운다. 실제 날짜·답안 사진 또는 실제 답/도움 조건을 남긴다. 문항별 자동 채점이나 학년 수준 판정은 하지 않는다.
- 표시하는 이력은 해당 활동명으로 부모가 등록한 답안 기록이다. 객관적 측정 결과나 학습 능력으로 해석하지 않는다. 조회 실패를 기록 없음으로 표시하지 않는다.
- 교육 선택은 목록 하트와 기관 찾기/관심 학원 탭을 적용했다. 관심 학원은 계정·아이·가족 범위로 분리해 이 기기의 localStorage에 저장하며 가족/기기 간 공유는 아직 없다.
- 관심 목록에서 2~3곳 비교. 네 번째 선택 차단, 관심 해제 시 비교 선택도 제거, 관심 목록 진입 시 검색/필터 초기화. 공식정보·출처·미확인 항목을 표시한다.
- 사용 가능한 이용자 후기 근거는 여전히 미확보이며 후기 요약·인기·최적 학원 판단은 추가하지 않았다.
- 기존 상담/체험 일정 준비 연결은 유지한다. 상태 확인에는 일정 등록을 추가하지 않았다.

## 검증
- 관련 단위/회귀 테스트 43건 통과: 저장 범위·손상된 관심 데이터·3곳 제한·공식 데이터 성격·증거 보존·사진 업로드 실패·가족 전환·문항 판단 안전 기준 등.
- Chrome에서 실제 운영 모듈을 불러오는 격리 검증 화면으로 잎 재클릭 접기, 상태 카드, 가상 답안 저장과 이력, 관심 저장 후 재조회, 네 번째 비교 차단, 관심 해제 후 2곳 비교, 인쇄용 문항 표시를 확인했다.
- 격리 화면의 성장기록 백엔드는 메모리이며 실제 수아 DB에 가상 기록을 쓰지 않았다. 관심 저장도 별도 fixture 범위다.
- 격리 화면 캡처는 운영 CSS를 사용한 확인용이며 실제 앱 전체/휴대폰 화면 대조를 대신하지 않는다.
- 확인 화면: `design-previews/runtime-integration/index.html`. 문제지: `learning-check-paper.html`.

## 다음 확인
- 실제 로그인 계정의 운영 메뉴 진입·수아 서버 기록 재조회·휴대폰 UI 대조는 push 전 최종 확인 대상이다.
- 교사 검토와 학기/교과서 대응을 확인하기 전 문항을 검증 완료 시험지나 전체 수준 검사로 표시하면 안 된다.
- 구조화된 문항별 부모 관찰과 결과 해석을 종이 답안 등록에 연결하는 것은 후속 범위다. 현재 결과 등록은 기존 기록 구조를 재사용하며 자동 해석/리포트는 제공하지 않는다.
- 학년/학기는 기존 입학 정책·생년월일 계산을 참고한다. 국제학교의 실제 학기/진도는 자동 확정하지 않는다.
- 서버 확장 필드·V2 규칙·권한 전환 승인은 별도 절차를 유지한다.
