# 경기도 지원금·혜택 총정리 (2026-10-01 기준, 확인완료만)

앱에 노출되는 `확인완료` 항목 117건을 시·군별로 정리했다. 임신~36개월 부모가 신청·수령하는 제도만 담았고, 전국 공통(부모급여·첫만남이용권·아동수당·국민행복카드)은 제외했다. 금액·기한은 공식 사이트 원문 기준이며 원문에 없는 값은 '원문에 없음'으로 표시했다.

**표기:** 임신 중 = 출산 후 화면에서 숨김 / 조건 = 소득·장애·다자녀 등 해당자만(앱에서 접이식) / 기한 '상시(기한 원문 없음)'는 신청기한이 원문에 없다는 뜻.
