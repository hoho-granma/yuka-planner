# W2 보강: 영유아검진 7·8차 + 초등 학년별 (hn_research, 2026-10-04, Aside, 5분 상한×2)

## 조사 1: 영유아건강검진 월령 구간 — 확인됨 (공단·복지부 두 곳이 일치)
출처: 국민건강보험공단 https://www.nhis.or.kr/nhis/healthin/wbhaca04800m01.do, 보건복지부 https://www.mohw.go.kr/menu.es?mid=a10706020200 (최종수정 2026-06-30). 직접 열어 본문을 읽음(Aside 에이전트의 웹 요청으로 읽었고 브라우저 탭으로 연 것은 아님).

| 차수 | 건강검진 | 구강검진 |
|---|---|---|
| 1차 | 생후 14~35일 | 없음 |
| 2차 | 4~6개월 | 없음 |
| 3차 | 9~12개월 | 없음 |
| 4차 | 18~24개월 | 18~29개월 |
| 5차 | 30~36개월 | 30~41개월 |
| 6차 | 42~48개월 | 42~53개월 |
| 7차 | 54~60개월 | 54~65개월 |
| 8차 | 66~71개월 | 없음 |
- 8차 항목: 문진·진찰(예방접종확인), 신체계측, 발달선별검사 및 상담, 건강교육. 취학 전 준비 상담은 5차·8차에 있음.
- 구강검진은 4~7차 건강검진과 같은 시기에 받는 4회이고, 복지부 표의 구강 "1~4차"는 구강검진만의 번호임(공단 표와 대조한 해석).
- 비용 본인부담 없음. K-DST 대상 9~71개월. 발달 정밀검사비 지원은 거주지 보건소 문의.
- 추가검증 필요: 공단 페이지 자체의 수정일(복지부는 2026-06-30).
→ W2 문서의 HC-07·08·09(42~48 / 54~60 / 66~71)는 공식 값과 일치. 구강검진 구간은 현재 데이터에 별도 항목이 있는지 확인 필요.
