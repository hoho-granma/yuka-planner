# 신청 링크 조사 (단계 1-2 "신청하러 가기" 버튼용)

조사: 2026-10-02 · hn-research(curl 전수 + Aside 20여 개) + hn-main(Aside 브라우저, 읽기 전용, 로그인·신청 클릭 없음).

## 결론
- 지원금 데이터의 공식 링크 172개 중 죽은 링크는 1개(제주 JJ-005). 그러나 **신청 화면으로 바로 가는 링크는 없다.** 모두 안내·보도·생활법령 페이지다.
- 복지로 서비스 상세 페이지에는 **'신청하기' 버튼이 있다.** 버튼은 자바스크립트로 동작해 주소를 따로 얻을 수 없으므로, 상세 페이지 자체를 "신청하러 가기" 대상으로 쓴다(사용자는 그 페이지에서 '신청하기'를 누르고 로그인).
- 접종·검진 자동 항목에는 링크 필드가 없다 → 이번에 채운다.

- 버튼 이름: 신청 경로가 이어지는 페이지는 "신청하러 가기", 안내만 있으면 "안내 보기", 예방접종도우미는 그 이름 그대로.
- 기존 `officialUrl`(근거 출처)은 바꾸지 않는다. 신청용은 **별도 필드**로 둔다(근거와 신청 경로는 목적이 다름).
- 링크 표시 옆 문구: "공식 사이트에서 로그인 후 신청해요"(복지로 항목).
