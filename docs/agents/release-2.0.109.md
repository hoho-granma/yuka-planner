# 한눈육아 2.0.109

- 육아혜택·월령 체크리스트 상태/지역 탭은 연보라 배경과 보라 글자로 변경. 옛 베이지 !important 규칙 제거. 분류별 종류 색상은 유지.
- 할일 탭은 담당자·등록 순서보다 기한 오름차순을 우선하고 기한 없는 할일은 마지막에 표시. 제목·등록 버튼·완료 숨기기 스위치는 홈과 같은 로즈핑크.
- 홈 가족 캘린더/이번 주 챙길 것 헤더의 화살표는 각각 캘린더/할일 메뉴로 바로 이동.
- 온보딩 바탕·장식 원·제목의 보라색 비중 확대.
- 캘린더 일정 추가 버튼은 보라 배경·흰 글자. 날짜별 일정의 이름은 짙은 회색, 행 padding은 위아래 6px·행 간 gap은 0. 홈 목록 간격은 유지.
- 기존 주간 할일 범위·정렬, 홈 핑크색 등록 버튼, 업데이트 버튼의 투명 배경 및 업데이트 시 보라색 글자는 유지.
