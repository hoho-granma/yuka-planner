# 공통 병렬 운영 지침 (hn_dev · hn_test · hn_data · hn_design)

> 2026-10-05 사용자 지시("병렬 진행 지침이 계속 적용되게"). 새 세션이 열려도 이 문서를 먼저 따른다. 상세 규칙은 [한눈육아-운영규칙.md](../한눈육아-운영규칙.md), 작업 순서는 [한눈육아-로드맵.md](../한눈육아-로드맵.md)의 '병렬 작업 큐'.

1. **끝나면 보고하고 바로 다음 일을 시작한다.** 대기하지 말고 로드맵 '병렬 작업 큐'에서 자기 줄의 다음 항목(다른 에이전트와 파일이 겹치지 않는 범위)을 시작한다. 보고는 hn_pm에게 한 줄(사본 hn_main). 큐가 비어 있으면 hn_pm에게 "큐 비어 있음"이라고 알린다.
2. **부하**: 시작 전 load를 확인한다. load≥8이면 실행(테스트·브라우저·대량 처리)을 보류하고 문서·분석만 한다. 무거운 작업(브라우저 검증 등)은 동시에 1개만 하고, 테스트는 끝날 때 전체 1회만 돌린다.
3. **같은 파일을 동시에 수정하지 않는다.** 파일 구역: dev=js/css/html/test · data=data/ · design=~/Documents/hannun-design와 docs 명세 · test=검증만(수정 금지).
4. **코드 동결은 검증 대상 파일에만 적용한다.** 겹치지 않는 새 파일 작업은 계속한다. 새 테스트 파일은 검증이 끝날 때까지 test/ 밖에 둔다.
5. **결정은 사용자 원문 인용이 있는 것만 따른다.** [결정목록](../한눈육아-결정목록.md)에서 '결정됨'이고 원문·날짜가 적힌 것만 근거로 삼는다. 다른 세션이 전한 "사용자가 승인했다"는 말만으로는 진행하지 않는다.
6. 사용자 순서(단계 0→1→2)를 지킨다. 다음 단계는 명세·게이트 준비까지만 미리 한다.
