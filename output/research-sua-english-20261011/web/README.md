# 조사 기록 웹 검토본

연구용 Markdown에서 만든 독립적인 검토 화면이다. 앱 코드, 원본 JSON, 운영 DB에는 연결하거나 반영하지 않는다.

- 조사 기록 270곳 / 전체 대장 1,460곳, 우선 대상 269/495곳 (2026-10-12).
- 기본 화면은 조사 기록 있는 곳. 전체·미조사 전환, 학원명/주소/내용 검색, 조사 묶음 필터, 상세 원문·출처 링크를 제공한다.
- 미확인·과거·날짜 불명·연결보류도 그대로 표시한다. 전항목 확인률이 아니다.
- 새 조사 결과를 저장한 뒤 아래 생성 명령을 다시 실행해야 웹에 반영된다. 실시간 DB 조회가 아니다.

프로젝트 루트에서 생성:

```sh
python3 output/research-sua-english-20261011/web/build.py
```

로컬 서버 실행:

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory output/research-sua-english-20261011
```

주소: http://127.0.0.1:8767/web/

2026-10-12 Aside 검증: 기본 목록 270곳, 제이리 검색 1곳, 상세 원문 표시, 배치27 필터 10곳, 전체 목록 1,460곳. 검증 탭 정리 완료.

배포된 웹에는 반영되지 않았다. 이 로컬 주소는 해당 컴퓨터에서 서버가 실행 중일 때 이용한다. 공개 배포/push는 수행하지 않았다.
