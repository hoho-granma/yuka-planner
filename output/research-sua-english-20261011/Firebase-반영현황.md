- 문서 키: 교육청 기관 ID J10:숫자. 기관 ID가 정확히 같은 경우만 화면에 연결한다.

- 기존 기본정보 문서·후기 데이터는 수정하지 않았다.
- 저장 전 대상 문서 백업 및 동시 변경 방지 조건을 적용했다. 저장 후 270개 전 필드 재조회 일치 확인. 재실행 시 변경 0개 확인.
- educationDirectory 기존 로그인·가입 확인 callable에서 Firestore 기록을 기관 목록과 함께 조회한다. 클라이언트는 파일 fetch 없이 이 응답을 사용한다.
- 함수 educationDirectory 업데이트 성공 및 functions:list 확인. 배포 후 이미지 정리 정책 설정 실패로 CLI 종료코드는 1이었으나 함수 업데이트는 성공했다. 정리 정책은 별도 변경하지 않았다.
- Firestore 규칙 수정·배포 없음. 공개 직접 DB 읽기 권한 추가 없음.
- 앱 기관 목록의 추가 태그, 이름 클릭 후 조사 요약/비용·날짜/전체 원문/출처 표시 구현. 학원·교습소 화면을 검증 사본으로 Aside 확인. 실제 로그인 계정으로 배포 웹을 통한 전체 경로는 아직 검증하지 않았다.
- 관련 Node 테스트 26개 통과. 기존 글자 크기 검사 통과. 시간·기한 CSS는 이 작업에서 수정하지 않았다.
- 웹 코드 push 없음. 배포된 웹에서 새 상세 UI·태그를 사용하려면 해당 클라이언트 변경을 배포해야 한다.

추가 조사 저장 절차:

```sh
python3 tools/build-education-research.py
python3 tools/import-education-research.py --apply
```
