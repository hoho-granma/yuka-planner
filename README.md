# 한눈육아 (통합 육아 캘린더)

아이 생년월일과 거주 지역만 입력하면 건강검진·예방접종·성장발달·지원금을 하나의 캘린더로
보여주는 MVP. [지원금조회](../지원금조회/)의 후속작이자 상위 개념 — 지원금조회의 지역·지원금
데이터를 그대로 흡수하고, 여기에 국가검진·접종·발달 일정을 더했다.

사용자가 준 "육아지기 서비스 정의서"의 MVP 범위를 뼈대만 구현한 1차 버전이다.
**UX/디자인은 아직 다듬지 않았다** — 사용자가 "대략적 서비스 뼈대가 구현되면 알려주겠다"고
해서, 기능이 도는지 확인하는 데 집중했다.

## 1. 로컬 실행 방법

```bash
cd 육아지기
python3 -m http.server 8791
# 브라우저에서 http://localhost:8791 접속
```

## 2. 폴더 구조

```
육아지기/
├── index.html              # 랜딩(입력폼) + 캘린더 화면 + 상세 모달
├── css/style.css            # 지원금조회와 같은 톤(따뜻한 오렌지) + 카테고리 4색
├── js/schedule.js           # 핵심 로직: 생년월일·지역 → 검진·접종·발달·지원금 통합 일정 배열
├── js/app.js                # 화면 렌더링, 폼 처리, 캘린더 그리드, 완료 체크(localStorage)
└── data/
    ├── regions.json         # 지원금조회에서 복사 (시·도 → 시·군·구)
    ├── subsidies.json       # 지원금조회에서 복사 (지원금 데이터, verified/status 규칙 동일)
    ├── health_checkup.json  # 국가 영유아 건강검진 8차 일정 (국민건강보험공단)
    ├── vaccination.json     # 국가예방접종(NIP) 표준일정 — ⚠️ 아래 "데이터 신뢰도" 참고
    └── development.json     # 월령 밴드별 성장·발달·생활 정보 (질병관리청·소아청소년과학회)
```

## 3. MVP에서 임의로 정한 것 (다음 세션에서 재검토 필요)

- 서비스 정의서의 **A(건강)+D(이유식·생활)를 "성장·발달" 카테고리 하나로 합쳤다.** 이유식
  시작시기·구강관리·안전관리를 각각 검증된 출처로 채울 시간이 부족해, 이미 확보된
  월령별 성장발달 자료의 "생활" 섹션에 붙이는 선에서 멈췄다.
- **엄마 연락처는 수집하지 않는다.** 서비스 정의서 §7의 "초기 MVP에서 알림에 안 쓰면
  수집하지 않는 방안 검토"를 따른 것 — 이 MVP에는 알림 기능이 없다.
- 완료 체크·아이 정보는 **localStorage에만 저장**(서버 없음). 재방문 시 자동으로 복원된다.
- 카테고리 색: 건강검진(파랑) · 예방접종(보라) · 성장·발달(초록) · 지원금·제도(주황).

## 4. 데이터 신뢰도 — 항목별로 다르다

| 데이터 | 신뢰도 | 비고 |
|---|---|---|
| `subsidies.json`, `regions.json` | 지원금조회와 동일 | 경기도·서울(SEOUL-001~003)만 `verified:true`, 전국 공통 제도는 `확인필요`, 그 외 15개 시·도는 데이터 없음 |
| `health_checkup.json` | 검증됨 | 국민건강보험공단 공식 차수·시기 |
| `development.json` | 검증됨 | `01-카드뉴스/04-참고자료/월령별-성장발달-기준표.md`가 1차 자료 (질병관리청·K-DST) |
| `vaccination.json` | **미검증** ⚠️ | 질병관리청 예방접종도우미의 일반적으로 알려진 표준일정을 근거로 이번 세션에서 새로 작성. WebFetch로 원문 대조 안 함. **실사용 전 nip.kdca.go.kr 재검증 필요** |

## 5. 알아둘 것 — 지원금 리스트 노출 방식

지원금·제도는 검진·접종처럼 특정 날짜의 일정이 아니라 "연령 조건을 만족하는 동안 마감 전까지
계속 신청 가능"한 항목이라, 캘린더의 날짜 점(마감일)과 별개로 **"이번 달 챙길 일"에는 지금
연령·마감 조건을 만족하는 지원금이 캘린더 달과 무관하게 항상 뜬다.** 마감이 지나면
"지난 일정"으로 내려간다(`js/app.js`의 `subsidyIsActiveNow()`).

## 6. 구현됨 / 안 됨

### 구현됨
1. 생년월일·거주지역 입력, 회원가입 없음, localStorage 재방문 지원
2. 검진·접종·발달·지원금 통합 일정 생성
3. 월간 캘린더(카테고리별 색 점) + 카테고리 필터
4. 이번 달 챙길 일 / 다음 달 미리보기 / 지난 일정 리스트
5. 일정 상세 모달(카테고리별 다른 내용) + 완료 체크

### 안 됨 (다음 단계 후보)
- 이유식·구강·수면·안전 별도 카테고리 (현재 성장·발달에 흡수됨)
- 알림/푸시, 캘린더 앱 연동, 홈 화면 위젯
- 예방접종 데이터 공식 재검증
- 경기도 외 지자체 자체 지원금 (지원금조회와 동일한 제약)
