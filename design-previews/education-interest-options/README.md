# 관심 학원 비교 시안

A안에 관심 학원 모아보기의 비교 선택을 추가했습니다. 한 번에 2~3곳을 선택하며, 0~1곳이면 비교 버튼이 비활성화됩니다. 4번째 선택은 안내와 함께 차단합니다. 관심 저장을 해제하면 비교 후보에서도 제외합니다.

비교 화면은 분야, 지역·주소, 대상·과정, 수업 방식, 비용, 시간, 차량, 이용자 의견 확보 여부, 등록 확인과 공식 출처를 나란히 보여줍니다. 부족한 정보는 원자료의 미확인 표시를 유지합니다. 교육효과·적합도·순위를 만들지 않습니다.

관심 목록은 기기별 localStorage에 저장하며 비교 선택은 현재 화면에서만 유지합니다. 운영 앱·가족 계정 저장·commit·push는 이번 변경 범위가 아닙니다.

Chrome 검증: 0곳 비활성화, 3곳 선택, 4번째 차단, 비교 표 3개 기관 열, 선택 해제 후 2곳 버튼 표시.

커밋 전 의존성 점검: 다른 세션의 미커밋 `js/education-reference.js`를 운영 파일로 포함하지 않고, 기관·공공 링크만 독립 `reference.js`에 보존했습니다. KOSIS 통계 데이터는 포함하지 않았습니다. 미커밋 또래 화면으로 가는 링크는 독립 시안 범위를 설명하는 창으로 대체했습니다. 세 안의 저장 키는 별도로 구분돼 있으며 운영 저장과 연결되지 않습니다.
